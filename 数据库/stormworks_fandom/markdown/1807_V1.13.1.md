# V1.13.1

**V1.13.1** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on December 4th, 2024.

## V1.13.1

- Feature - [#24388](https://geometa.co.uk/support/stormworks/24388) Rotating warning light
- Fix - Resolved issues with large mod network payloads sometimes causing lockup
- Fix - [#26714](https://geometa.co.uk/support/stormworks/26714) Component translations loading issue
- Fix - [#26713](https://geometa.co.uk/support/stormworks/26713) Approved glslh files for modding
- Fix - [#25323](https://geometa.co.uk/support/stormworks/25323) C4 Damage behaviour on static vehicles
- Fix - [#25946](https://geometa.co.uk/support/stormworks/25946) Preset torpedo now spawns lower
- Fix - [#26056](https://geometa.co.uk/support/stormworks/26056) Lua Docs bracket mismatch
