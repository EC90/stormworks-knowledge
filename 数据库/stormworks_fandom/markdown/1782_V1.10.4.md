# V1.10.4

**V1.10.4** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on February 28th, 2024.

## V1.10.4

- Rework - [#21443](https://geometa.co.uk/support/stormworks/21443) Orientation is now sticky when placing components in the editor
- Fix - [#23076](https://geometa.co.uk/support/stormworks/23076) Leaks not using their bounding when resolving with the ocean (Boats not sinking)
- Fix - Crash fix for occasional issue with character input resetting
- Fix - Hand item not clearing when teleporting (Fishing rod physics issues)
- Fix - Seats applying an offset to character position when testing for drowning
- Fix - [#22332](https://geometa.co.uk/support/stormworks/22332) Advanced rotor counter-torque forces applying in space
- Fix - [#22419](https://geometa.co.uk/support/stormworks/22419) Waypoints are now grid based and distance restraint has been removed
- Fix - [#22457](https://geometa.co.uk/support/stormworks/22457) Removed inert electric node on liquid fuel rockets
- Fix - [#22601](https://geometa.co.uk/support/stormworks/22601) Addon references to removed node locationData.is_env_mod
- Fix - [#22652](https://geometa.co.uk/support/stormworks/22652) Fixed lights issues on the arid island
- Fix - [#22766](https://geometa.co.uk/support/stormworks/22766) Updated classic mode description
- Fix - [#22792](https://geometa.co.uk/support/stormworks/22792) Reworked raycast interactions to fix several issues with rays from recent character network physics changes
- Fix - [#22813](https://geometa.co.uk/support/stormworks/22813) Reworked visual effects of fluid jets
- Fix - [#22817](https://geometa.co.uk/support/stormworks/22817) Directional rx description error
- Fix - [#22845](https://geometa.co.uk/support/stormworks/22845) Distance sensor high electric consumption
- Fix - [#22916](https://geometa.co.uk/support/stormworks/22916) Resolved buoyancy mesh generation issue for gas tanks
- Fix - [#23184](https://geometa.co.uk/support/stormworks/23184) Enabled keypad waypoints to work on the moon (shows universal coordinates and not moon-relative coordinates, for lua addon compatability)
- Fix - [#24099](https://geometa.co.uk/support/stormworks/24099) Fishing rod inventory description
- Balance - [#22846](https://geometa.co.uk/support/stormworks/22846) Large solar cell price
- Balance - Rebalanced hopper mass
