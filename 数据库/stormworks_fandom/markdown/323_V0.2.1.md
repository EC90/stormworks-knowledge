# V0.2.1

**V0.2.1** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on May 9, 2018.

## v0.2.1

- Feature - new mission editor with Steam Workshop support
- Feature - new set of official missions content
- Feature - 10 new island locations including a 6 sq km mega island
- Feature - fire system including new water cannon component
- Feature - new icons set
- Fix - player positions now correct in beds and harness
- Fix - player now takes correct position when getting out of seat avoiding physics issues
- Fix - winch slip reduced
- Fix - missions now detect completion correctly
- Fix - money rewards now granted correctly
