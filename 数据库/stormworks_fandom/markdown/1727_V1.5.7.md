# V1.5.7

**V1.5.7** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on August 12th, 2022.

## V1.5.7

- Feature - New medium size tank track wheels ([#9371](https://geometa.co.uk/support/stormworks/9371) [#5466](https://geometa.co.uk/support/stormworks/5466))

- Rework - Updated dedicated server sorting algorithm to lower the priority of empty servers
- Rework - Amended multiplayer client event processing for more consistent ticking

- Fix - [#9783](https://geometa.co.uk/support/stormworks/9783) Adjacent hatch buoyancy generation preventing vehicle spawn
- Fix - [#5456](https://geometa.co.uk/support/stormworks/5456) An issue with door buoyancy surfaces with water entering
- Fix - [#10013](https://geometa.co.uk/support/stormworks/10013) Fix resize selection grid crash
- Fix - [#10794](https://geometa.co.uk/support/stormworks/10794) Lighting flare billboards are now based on light intensity
- Fix - [#11054](https://geometa.co.uk/support/stormworks/11054) Addon editor focus now raycasts correctly when the target point is below height 0
- Fix - Fix some components requiring more charge to activate than they use
- Fix - [#10716](https://geometa.co.uk/support/stormworks/10716) [#2622](https://geometa.co.uk/support/stormworks/2622) Special colours (orange) are now ignored for character meshes
- Fix - [#11365](https://geometa.co.uk/support/stormworks/11365) Removed input/output labels from two way logic node types
- Fix - [#11486](https://geometa.co.uk/support/stormworks/11486) Fixed some issues resolving refunded cost when removing asymmetric vehicle components in symmetry mode
- Fix - [#9657](https://geometa.co.uk/support/stormworks/9657) Fixed mirroring issues for the Fluid jet
- Fix - Prevented some cases where inputs can be sticky while interacting with buttons
- Fix - Crash caused by parsing states of vehicles with microcontrollers
- Fix - Crash when attempting to send data to a server that has been disconnected from
