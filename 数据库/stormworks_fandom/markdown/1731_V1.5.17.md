# V1.5.17

**V1.5.17** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on October 7th, 2022.

## V1.5.17

Feature - New Train Wheel Assemblies and Pistons ([#2393](https://geometa.co.uk/support/stormworks/2393) [#14402](https://geometa.co.uk/support/stormworks/14402))

In this update we have reworked our train bogie code and added a variety of new parts:

- - Added several new train assemblies of varying size
- - Added steam train assemblies and pistons that link together when placed in sequence
- - Updated the braking mechanic to prevent rolling on slopes
- - Updated how trains attach to the track for improved cornering
- - Added a derailing mechanic for train bogies turning through critical angles which are more sensitive at high speeds

- Fix - [#9407](https://geometa.co.uk/support/stormworks/9407) Fix pipe components being draggable in unintended axes
- Fix - [#10449](https://geometa.co.uk/support/stormworks/10449) Mesh error at Kalopsidiotis Chemical Storage
- Fix - [#10680](https://geometa.co.uk/support/stormworks/10680) Detonator antenna sticks out of the block
- Fix - [#10987](https://geometa.co.uk/support/stormworks/10987) AWACS radar has missing/transparent textures at certain angles
- Fix - [#12970](https://geometa.co.uk/support/stormworks/12970) Cable anchors received data issues when disconnected by players
- Fix - [#13178](https://geometa.co.uk/support/stormworks/13178) Logic slot name typo
- Fix - [#13224](https://geometa.co.uk/support/stormworks/13224) Memory Register typo
- Fix - [#13233](https://geometa.co.uk/support/stormworks/13233) Winch description semantics

- Fix - [#14291](https://geometa.co.uk/support/stormworks/14291) Incorrect Description for Laser Sensor (Missile)
