# V0.6.14

**V0.6.14** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 22nd, 2019.

## V0.6.14

- Feature - Added multi-selection to microcontroller editor (drag to select many components that can be moved and deleted as one)
- Feature - Added undo/redo to microcontroller editor
- Feature - Added copy/cut/paste to microcontroller editor
- Feature - 32 channel composite write component now has configurable number of inputs (deprecated single input composite write components as 32 channel version now serves the same purpose)
- Feature - Added 3 new instrument panel types (flip button, radial display, bar display)
- Feature - Radial and bar instrument segments can be painted individually
- Feature - Added number to composite binary converter (converts an input number to binary and then outputs the bits as on/off composite signals)
- Feature - Added composite binary to number converter (reads the on/off signals of a composite link and encodes them in the bits of an output number)
- Feature - Instrument panel component passes composite signals through to its output to allow them to be chained together
- Feature - Instrument panel arrow buttons have been condensed into a single button with direction option
- Feature - Instrument panel seven segment displays have been condensed into a single instrument with mode option
- Feature - Composite read microcontroller components now have the option for reading from a channel based on input logic ("varible" option in channel selector)
- Feature - Composite write microcontroller components now have the option to set which channel they start writing from (also can be controlled with logic if "variable" option is set)
- Feature - Added horizontal orientation option to instrument gauge

- Fix - Reduced physics shape of passenger seat so that characters can walk between rows of seats facing each other easier
- Fix - Dragging right mouse in microcontroller editor no longer rotates vehicle editor camera
- Fix - Removed unused fluid logic node from electric connector
- Fix - Fixed underwater rocks spawning in docks on some world seeds
- Fix - Fixed not being able to drag with additive paint tool
- Fix - Fixed single-clicking a component in the microcontroller editor inventory not selecting it
- Fix - Fixed dropdown boxes being cut off when inside some scrollable areas
- Fix - Dropdown lists flip direction if the bottom of them goes off-screen
- Fix - Fixed spotlight glass not rendering when switched on
- Fix - Fixed spotlight being able to rotate when not receiving electric in advanced mode
- Fix - Fixed rotors not rendering with the correct number of blades in select/logic mode in the vehicle editor
- Fix - Fixed rotors having a second black mesh visible when in logic mode in the vehicle editor
- Fix - Seat input for on/off hotkeys clears when getting out of the seat
- Fix - Added side door access to Arctic player base hangar
- Fix - Fixed pressing hotbar hotkey with component selected in microcontroller editor when trying to type in properties
- Fix - Fixed instrument panel buttons not having sound effects
