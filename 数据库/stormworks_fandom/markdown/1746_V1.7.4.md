# V1.7.4

**V1.7.4** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 28th, 2023.

## V1.7.4

- Fix - [#16528](https://geometa.co.uk/support/stormworks/16528) Diagonal surfaces interfering with surface culling
- Fix - [#16569](https://geometa.co.uk/support/stormworks/16569) Pistol inventory block weight
- Fix - [#16755](https://geometa.co.uk/support/stormworks/16755) Allow smoke colour effects when damage/overheating is off
- Fix - [#16942](https://geometa.co.uk/support/stormworks/16942) Flare gun firing twice
- Fix - [#9462](https://geometa.co.uk/support/stormworks/9462) Export 3D model crashing due to unsupported character glyphs
- Fix - [#17455](https://geometa.co.uk/support/stormworks/17455) Mounted welder functionality on servers
- Fix - [#16146](https://geometa.co.uk/support/stormworks/16146) Persisting issue with spawnVehicleRope not spawning as expected
- Rework - [#17394](https://geometa.co.uk/support/stormworks/17394) Added Oil trading to arctic refinery and simplified default resource trading script
