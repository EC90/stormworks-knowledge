# V0.1.28

**V0.1.28** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 23, 2018.

## V0.1.28

- Feature - Added labelling support to harness hotkeys in select menu
- Fix - Mag-all correctly attaches to moving island objects (e.g wind turbine blades)
- Fix - Improvements to performance when rendering lots of lights
- Fix - Fixed crash when loading invalid sized vehicle thumbnails
- Fix - Photo mode/creative menu hotkeys no longer cause invalid state when used while map is open
- Fix - Mag-all no longer creates unbreakable connections
