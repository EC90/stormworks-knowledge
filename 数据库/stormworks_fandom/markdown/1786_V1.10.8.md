# V1.10.8

**V1.10.8** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 28th, 2024.

## V1.10.8

- Feature - Added directional WASDEQ movement to vehicle editor and addon editor cameras
- Feature - [#20199](https://geometa.co.uk/support/stormworks/20199) Clear oil spills button
- Rework - [#22954](https://geometa.co.uk/support/stormworks/22954) [#23920](https://geometa.co.uk/support/stormworks/23920) Rescaled and rebalanced oil spills
- Rework - [#22954](https://geometa.co.uk/support/stormworks/22954) [#23920](https://geometa.co.uk/support/stormworks/23920) Fixed oil spill cleaning issues
- Rework - [#22954](https://geometa.co.uk/support/stormworks/22954) [#23920](https://geometa.co.uk/support/stormworks/23920) Fixed oil spill map edge coordinates wrapping crash
- Fix - Fix issue with fluid level resolving not respecting a to b oil resolution as expected with pressure leveling
- Fix - [#22814](https://geometa.co.uk/support/stormworks/22814) Handheld and vehicle mounted weapon projectile start positions at high speed
- Fix - [#23111](https://geometa.co.uk/support/stormworks/23111) Aljon hospital name
- Fix - [#23258](https://geometa.co.uk/support/stormworks/23258) Fix ocean water surface clipping for ultrawide aspect ratios
- Fix - Fixed arecibo observatory microcontroller
- Fix - [#24422](https://geometa.co.uk/support/stormworks/24422) Included missing Valve dedicated server files
- Fix - [#24574](https://geometa.co.uk/support/stormworks/24574) Diesel burner air consumption values
- Fix - [#24552](https://geometa.co.uk/support/stormworks/24552) Modular engines air consumption not reacting to pressure
