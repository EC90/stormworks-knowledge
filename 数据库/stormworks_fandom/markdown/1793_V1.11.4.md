# V1.11.4

**V1.11.4** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on June 19th, 2024.

## V1.11.4

- Fix - [#22548](https://geometa.co.uk/support/stormworks/22548) Refactored train braking code to fix mirroring issues
- Fix - [#23555](https://geometa.co.uk/support/stormworks/23555) Fix infinite fuel setting causing funnels to spawn infinite resources
- Fix - [#23864](https://geometa.co.uk/support/stormworks/23864) Fix DLC lock on uranium processing
- Fix - [#24094](https://geometa.co.uk/support/stormworks/24094) Corrected finned and non-finned solid rocket booster masses
- Fix - [#24196](https://geometa.co.uk/support/stormworks/24196) Refactored directional rx fov/falloff for more consistent behaviour
- Fix - [#23910](https://geometa.co.uk/support/stormworks/23910) Fixed issues with workshop vehicles thumbnails and tags
- Fix - [#23881](https://geometa.co.uk/support/stormworks/23881) Fixed weather map sampling
- Fix - [#23864](https://geometa.co.uk/support/stormworks/23864) Separated left and right train piston internal steam compartments
