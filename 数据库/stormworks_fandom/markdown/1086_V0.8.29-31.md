# V0.8.29-31

**V0.8.29-31** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on September 27th, 2019.

## V0.8.29

- Fix - Added fuel stores to the Multiplayer Island
- Fix - Fixed several rendering and physics bugs with the Multiplayer Island
- Fix - Soft-locking the game when fast travelling in multiplayer
- Fix - Ocean wave rendering being offset from their physics
- Fix - For sale sign not disappearing on Multiplayer Island
- Fix - Crash when the client tried to render unloaded tiles
- Fix - Moved Multiplayer Island higher in the selection screen

## V0.8.30

- Fix - Positional audio being played at 0,0

## V0.8.31

- Feature - Local Voice Chat (Talk with players in your immediate vicinity, default keybind: ' )

- Fix - Only impact damage is now ignored when entering/exiting seats/ladders
