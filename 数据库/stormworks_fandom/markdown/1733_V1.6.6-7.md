# V1.6.6-7

**V1.6.6-7** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on November 11th, 2022.

## V1.6.6-7

v1.6.6

- Fix - Negative integer table indices are now supported when saving addon script data

v.1.6.7
