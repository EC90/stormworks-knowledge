# V0.8.32-33

**V0.8.32-33** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on October 4th, 2019.

## V0.8.32

- Feature - Microphone Component
- Feature - 3 Speaker Components
- Feature - Audio Switchbox Microprocessor Component
- Rework - Radio Components V2 *

- Fix - Greatly reduced effect of FOV on radar range
- Fix - Voicechat and Quickchat can now be bound to inputs other than keyboard

-
  - Old Radio components are now depreciated, but will still continue to work.

## V0.8.33

- Fix - Resolved issue with vehicle edit grids from v0.8.32
