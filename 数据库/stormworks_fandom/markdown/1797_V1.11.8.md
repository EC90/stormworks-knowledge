# V1.11.8

**V1.11.8** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on July 31st, 2024.

## V1.11.8

- Feature - [#10360](https://geometa.co.uk/support/stormworks/10360) Beach and shallows mission locations

- Rework - [#25621](https://geometa.co.uk/support/stormworks/25621) Updated train wheels braking code
- Fix - [#24645](https://geometa.co.uk/support/stormworks/24645) Clients getting stuck in loading state after teleport
- Fix - [#24582](https://geometa.co.uk/support/stormworks/24582) Prevent scene vehicles ticking while simulation is paused (Jumping vehicles)
- Fix - [#24545](https://geometa.co.uk/support/stormworks/24545) Space station hatch logic wiring
- Fix - [#24608](https://geometa.co.uk/support/stormworks/24608) Fix sunken pseudo state AI boats loading inside seabeds
- Fix - [#24628](https://geometa.co.uk/support/stormworks/24628) Show a warning when invalid vehicle buoyancy errors occur and prevent vehicle entering an invalid state
- Fix - [#24675](https://geometa.co.uk/support/stormworks/24675) [#25491](https://geometa.co.uk/support/stormworks/25491) Minor addon lua documentation fixes
- Balance - Reduced weapon projectile spread x4
- Balance - Increased machine gun ammo box capacity to 100
