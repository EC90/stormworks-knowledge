# V1.11.6

**V1.11.6** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on July 3rd, 2024.

## V1.11.6

- Feature - [Industrial Frontier DLC] Animal Missions

- Transport farm animals
- Find a lost dog
- Rescue an animal to a sanctuary
- Hunt a dangerous animal [with Search and Destroy DLC]
- Rescue survivors from an animal attack [with Search and Destroy DLC]

- Fix - Persisting issues with train brake forces causing twilight zone bug
- Fix - [#24107](https://geometa.co.uk/support/stormworks/24107) Dropping fish duplicating in multiplayer
- Fix - [#24199](https://geometa.co.uk/support/stormworks/24199) Survivors picked up by two players at the same time bug
- Fix - [#24355](https://geometa.co.uk/support/stormworks/24355) Fixed issues with map border teleporting for vehicle groups with keep active blocks
- Fix - [#24344](https://geometa.co.uk/support/stormworks/24344) Map vehicle icon block data is now persistent when unloaded
- Fix - [#24131](https://geometa.co.uk/support/stormworks/24131) Minor fish art asset issues
- Fix - [#24217](https://geometa.co.uk/support/stormworks/24217) Minor control fin art asset issues

- Addon Lua:

- Feature - [#24344](https://geometa.co.uk/support/stormworks/24344) getVehiclesByName Addon Lua function
- Feature - getVehicleData now returns name and authors data
- Fix - Corrected some integer return value types
