# V0.1.20

**V0.1.20** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 29, 2018.

## V0.1.20 (The Essential Logic Update)

- Feature - 6 new logic components:
  - SR Latch
  - JK Flip-Flop
  - Abs
  - Capacitor
  - Greater-Than
  - Divide
- Fix - Fixed some ladder-related multiplayer crashes
- Fix - Handles attached to lighter bodies will pull the player again
- Fix - Reduced some camera jitter when attached to ladders in multiplayer
- Fix - Waves scale correctly around islands
