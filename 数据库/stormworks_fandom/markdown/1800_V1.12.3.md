# V1.12.3

**V1.12.3** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on September 25th, 2024.

## V1.12.3

- Feature - [#11450](https://geometa.co.uk/support/stormworks/11450) Winch speed input logic node for medium and larger winches
- Feature - [#5290](https://geometa.co.uk/support/stormworks/5290) Occupied bool logic node for handles
- Fix - Rotor light-grey accents rendering with colour in preview
- Fix - [#24690](https://geometa.co.uk/support/stormworks/24690) [#25665](https://geometa.co.uk/support/stormworks/25665) - Addons not defaulting to mission tag when uploading to workshop without any locations
- Fix - [#25455](https://geometa.co.uk/support/stormworks/25455) - Fixed positions of various mission zones
- Fix - [#25721](https://geometa.co.uk/support/stormworks/25721) - Reduced refuel mission fill requirement
- Fix - [#25763](https://geometa.co.uk/support/stormworks/25763) - Added old save compatibility for creature missions
