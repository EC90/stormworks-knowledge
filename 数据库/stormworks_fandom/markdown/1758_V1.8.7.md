# V1.8.7

**V1.8.7** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on August 18th, 2023.

- Rework - [#19596](https://geometa.co.uk/support/stormworks/19596) Updated default gantries and storage to be filter-less and instead delete incorrect fluids
- Fix - [#19846](https://geometa.co.uk/support/stormworks/19846) Train wheel functionality when mixing flipped and rotated wheels
- Fix - [#19636](https://geometa.co.uk/support/stormworks/19636) Reset explosion and fire buildup after repairing an engine, battery or furnace
- Fix - [#19748](https://geometa.co.uk/support/stormworks/19748) Sawyer island terrain issues at bridge entry/exits
- Fix - [#19541](https://geometa.co.uk/support/stormworks/19541) Emote menu background not filling wide aspect ratios
- Fix - [#19747](https://geometa.co.uk/support/stormworks/19747) Missing rock face at airstrip base
- Fix - [#19606](https://geometa.co.uk/support/stormworks/19606) Clear interactions when opening chat menu

- Fix - [#19602](https://geometa.co.uk/support/stormworks/19602) Mesh gap at Taijin dock
