# V0.1.16

**V0.1.16** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 21, 2018.

## V0.1.16

- Feature - creative mode menu now in multiplayer for setting weather
- Feature - photo mode now in multiplayer
- Feature - third person camera on spring no longer clips through walls
- Fix - removed unfinished island
