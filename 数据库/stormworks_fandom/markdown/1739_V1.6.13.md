# V1.6.13

**V1.6.13** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on February 3rd, 2023.

## V1.6.13

- Feature - 24 New Occupation Themed Outfit Items

- Rework - Steam Train Wheels balance and fixes ([#16227](https://geometa.co.uk/support/stormworks/16227) [#14723](https://geometa.co.uk/support/stormworks/14723) [#14697](https://geometa.co.uk/support/stormworks/14697) [#16960](https://geometa.co.uk/support/stormworks/16960))
- Rework - Updated and improved the default cargo containers ([#9615](https://geometa.co.uk/support/stormworks/9615) [#10724](https://geometa.co.uk/support/stormworks/10724))
- Rework - [#7841](https://geometa.co.uk/support/stormworks/7841) Updated the Helicopter preset vehicle and added a Default Container preset
- Fix - [#5126](https://geometa.co.uk/support/stormworks/5126) [#4135](https://geometa.co.uk/support/stormworks/4135) Fixed various hangar door sounds, indoor zones and airstrip lights
- Fix - [#12983](https://geometa.co.uk/support/stormworks/12983) Police station door and other physics fixed
- Fix - [#15564](https://geometa.co.uk/support/stormworks/15564) Fixed thin tile physics issue
- Fix - [#16221](https://geometa.co.uk/support/stormworks/16221) Prevented memory leak caused by LODS when there are no tile sin LOD range
- Fix - [#14595](https://geometa.co.uk/support/stormworks/14595) Rope length output node now updates dynamically
- Fix - [#15169](https://geometa.co.uk/support/stormworks/15169) Sync resource storage data on game join
- Fix - [#16146](https://geometa.co.uk/support/stormworks/16146) SpawnVehicleRope using the wrong data for loaded vehicles
- Fix - [#16288](https://geometa.co.uk/support/stormworks/16288) Respawn issues when respawning under delayed damage
- Fix - [#16404](https://geometa.co.uk/support/stormworks/16404) Ski mirroring issues
- Fix - [#16184](https://geometa.co.uk/support/stormworks/16184) Coal hopper network events for sub-bodies

- Added new sound effects for the Wildcat and [REDACTED]

Addon Lua:

- [#16090](https://geometa.co.uk/support/stormworks/16090) setVehiclePosSafe behavior reworked to avoid unreliable internal data

- [#3854](https://geometa.co.uk/support/stormworks/3854) Added setAudioMood which allows setting the audio mood to a higher level for a peer which naturally decreases over time
