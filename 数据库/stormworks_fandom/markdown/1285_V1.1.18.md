# V1.1.18

**V1.1.18** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 2nd, 2021.

## V1.1.18

- Feature - Impact sensor - triggers ON signal when acceleration exceeds the value set in properties
- Feature - Contact sensor - a physics based push button with adjustable stiffness

- Rework - Solid rocket nozzle parts now contain 25% fuel of a fuel part to discourage multi-nozzle rockets

- Fix - Empty add-on folders no longer show in the Add-on menu
- Fix - Emissive surfaces now render correctly underwater
- Fix - Resolved occasional crash after using select tool on the flare launcher
