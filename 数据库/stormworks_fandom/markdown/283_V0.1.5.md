# V0.1.5

**V0.1.5** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 1, 2018.

## V0.1.5

- Fix - ocean floor collision now works
- Fix - crash when running out of memory
- Fix - can now type punctuation in multiplayer chat
- Fix - added call buttons to nuclear island lift (top and bottom)
- Fix - corrected key command in tutorial to toggle camera mode
- Fix - plants no longer come above water level
- Fix - corrected GPU resource leak
