# V0.3.5

**V0.3.5** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on August 13, 2018.

## v0.3.5

- Fix - Fixed workshop upload name validation not working correctly
- Fix - Workshop uploads must have a minimum of 1 tag
- Fix - Workshop uploads must have a name
- Fix - Fixed crash when picking up characters and placing characters in seats
- Fix - Fixed stair top component's square surfaces not forming seal
- Fix - Small objects no longer fly away when being picked up
