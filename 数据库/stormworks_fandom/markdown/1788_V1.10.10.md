# V1.10.10

**V1.10.10** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 24th, 2024.

## V1.10.10

Feature - Man Overboard missions

- Fix - [#24563](https://geometa.co.uk/support/stormworks/24563) Aerial mobility issues at ground level
- Fix - [#24867](https://geometa.co.uk/support/stormworks/24867) Gas spawners now spawn at high pressure
- Fix - Internal issues caused by detecting ocean floor in unloaded tiles
- Fix - [#23286](https://geometa.co.uk/support/stormworks/23286) Furnace heating due to coolant loop pressure issues
- Fix - [#23430](https://geometa.co.uk/support/stormworks/23430) Fix radiation leaking for doors, fluid ports no longer create fallout
- Fix - [#23534](https://geometa.co.uk/support/stormworks/23534) Added additional server side checks for creative menu client events
- Fix - [#23564](https://geometa.co.uk/support/stormworks/23564) Ignore static vehicles when building unloaded radar data

Addon Lua:

- Default missions decorative NPC support
- GetTile no longer returns nil for unloaded ocean tiles
- GetComponentData now returns:
- Interactable
- Creature_type
- Animal_type
