# V0.1.12-13

**V0.1.12-13** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on March 9, 2018.

## v0.1.13

- Feature - climb action replaces jumping when in water
- Feature - game version now included in issue submissions
- Fix - missions now give the correct rewards
- Fix - placing characters now interacts safely with physics
- Fix - default value corrected for up/down gate
- Fix - ocean floor rocks no longer clip when in view
- Fix - resolved issue spawning boats in multiplayer

## v0.1.12

- Feature - multiplayer fast travel icons are now in multiplayer
- Feature - up down gate now has sensitivity setting
- Fix - server no longer crashes when closed
- Fix - resolved crash where tiles could leave range while still loading
- Fix - tilt sensors now work correctly with mirroring
- Fix - characters work properly in multiplayer immediately after disconnecting from ladder
- Fix - vehicles reset when returned to workbench from map
- Fix - buoyancy data for vehicles now works correctly in multiplayer
- Fix - minor physics fix for characters in multiplayer
