# V1.5.5

**V1.5.5** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on July 15th, 2022.

## V1.5.5

- Feature - Steam Piston Components ([#3043](https://geometa.co.uk/support/stormworks/3043))
- Feature - Steam Whistle

- A Steam powered tractor has been added to the preset vehicles list.

- Fix - [#10271](https://geometa.co.uk/support/stormworks/10271) Underwater lighting fog shaders
- Fix - Rocket fin mirroring not reflected correctly in mesh visuals when turning
- Rework - Add vehicle destroyed mission outcome to relevant default mission types
- Rework - Non-urgent mission types now display as orange instead of red
- Fix - [#11283](https://geometa.co.uk/support/stormworks/11283) Default underwater missions not using zone size offset
- Fix - [#10322](https://geometa.co.uk/support/stormworks/10322) Weather and Time overrides not persisting between save and load
- Fix - [#10856](https://geometa.co.uk/support/stormworks/10856) Updated default mission title generation
- Fix - [#11032](https://geometa.co.uk/support/stormworks/11032) Allow the Kraken to be placed in the addon editor
- Fix - [#11150](https://geometa.co.uk/support/stormworks/11150) Missing triangle on the medium control surface
- Fix - [#7705](https://geometa.co.uk/support/stormworks/7705) Added velocity limits to explosions to prevent twilight zoning the player
- Fix - [#11306](https://geometa.co.uk/support/stormworks/11306) Survivors not updating their constraints when revived in a bed
- Fix - [#11358](https://geometa.co.uk/support/stormworks/11358) Small fins editor mesh too big
- Fix - Minor addon lua documentation QOL changes
- Fix - [#11381](https://geometa.co.uk/support/stormworks/11381) Weather state reverts to start of game conditions on load
- Fix - [#11575](https://geometa.co.uk/support/stormworks/11575) Rotor mesh gap issue
- Rework - Updated network code to deal with cases where the thread sleeps for longer than expected
