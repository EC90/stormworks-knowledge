# V1.10.3

**V1.10.3** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on February 14th, 2024.

## V1.10.3

Feature - [#21954](https://geometa.co.uk/support/stormworks/21954) Map icon block

This new block allows the player to choose which vehicles in their vehicle-group should render on the map. If no map icon block is found the default behaviour will remain to be rendering all vehicles in the group.
