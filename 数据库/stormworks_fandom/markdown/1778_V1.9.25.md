# V1.9.25

**V1.9.25** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 19th, 2024.

## V1.9.25

- Feature - [#22081](https://geometa.co.uk/support/stormworks/22081) Added space and train tags to workshop uploads
- Feature - [#22258](https://geometa.co.uk/support/stormworks/22258) Added rotation, angular speed and tilt to the astronomy sensor
- Fix - Multiplayer rope render sync
- Fix - [#23781](https://geometa.co.uk/support/stormworks/23781) Winch speed setting appearing on rope hooks
- Fix - [#21497](https://geometa.co.uk/support/stormworks/21497) Hide addon popups during photo mode
- Fix - [#21797](https://geometa.co.uk/support/stormworks/21797) Disable editing of vehicles with passengers
- Fix - [#21815](https://geometa.co.uk/support/stormworks/21815) Skybox rendering issues
- Fix - [#22168](https://geometa.co.uk/support/stormworks/22168) DLC icons on server list overlapping
- Fix - [#22376](https://geometa.co.uk/support/stormworks/22376) Compartment internal fluid height issues (fires extinguishing under waterline)
- Fix - Fixed tractor and engine preset issues
- Balance - [#21773](https://geometa.co.uk/support/stormworks/21773) Reduced fire extinguisher force
