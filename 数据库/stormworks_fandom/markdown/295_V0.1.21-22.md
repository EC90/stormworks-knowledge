# V0.1.21-22

**V0.1.21-22** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on April 6, 2018.

## v0.1.22

- Fix - General increase to attraction strength of connectors
- Fix - Fixed hinge connector being difficult to connect
- Fix - Propellers visually rotate when not in water
- Fix - Fixed winches not working properly after loading a saved game
- Fix - Wind sensor now outputs number of turns correctly
- Fix - Wind sensor has correct description in vehicle editor
- Fix - Capacitor charge/discharge times work correctly
- Fix - Fixed pilot seat sensitivity not working for all axes

## v0.1.21 (The HOTAS Controller and Weather Logic Update)

- Feature - Improved controller support for vehicles. Toggle controller input with [j] (default), an icon will show above the minimap when enabled
- Feature - HOTAS controller support (up to 8 axis and 48 buttons)
- Feature - Can now map controllers from the "controller" section of the controls settings
- Feature - Added 4 environmental sensor components
  - Humidity sensor (outputs fog amount)
  - Rain sensor (outputs rain amount)
  - Wind sensor (outputs relative wind direction and relative wind speed)
  - Clock (outputs time of day)
- Feature - Added HOTAS pilot seat component with additional outputs for HOTAS controllers
- Feature - Added 4 modes to linear speed sensor (absolute, directional, horizontal, vertical)
- Fix - Removed rotation logic nodes from small wing components
- Fix - Fixed vehicles with lots rudders being unstable/teleporting around
- Fix - Clamped max acceleration of vehicles to improve stability of physics
- Fix - Fixed some vehicles appearing to spawn at world origin instead of edit grid
- Fix - Fixed crash with small wheels
- Fix - Wheels reset their steering rotation when respawning
- Fix - Airbase hangar doors now open wide enough to fit max vehicle size that can be spawned
