# V1.7.7

**V1.7.7** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on May 26th, 2023.

## V1.7.7

- Fix - [#13169](https://geometa.co.uk/support/stormworks/13169) Add-ons fail to upload to the Steam workshop on Mac
- Fix - [#18007](https://geometa.co.uk/support/stormworks/18007) Fix mixing inverted and non-inverted tank track wheels causing wheels to spin backwards
- Fix - [#18014](https://geometa.co.uk/support/stormworks/18014) Reversed srb fins animations and editor arrows to match their physics behavior
- Fix - [#18167](https://geometa.co.uk/support/stormworks/18167) Fix missing voxels on the large engine
- Fix - [#18589](https://geometa.co.uk/support/stormworks/18589) Updated clarke airfield road mesh
- Fix - [#18630](https://geometa.co.uk/support/stormworks/18630) Fix multi-segment rods being disconnected by rod connector component incorrectly
