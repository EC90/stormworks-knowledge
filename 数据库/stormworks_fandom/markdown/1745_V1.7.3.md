# V1.7.3

**V1.7.3** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 14th, 2023.

## V1.7.3

- Feature - Gimbal controlled light, camera and laser components

- Rework - [#12014](https://geometa.co.uk/support/stormworks/12014) Rescaled stabilized gimbal camera inputs after the deadzone to start from 0 (finer control)
- Fix - [#13615](https://geometa.co.uk/support/stormworks/13615) Third person vehicle camera fixed yaw jitter
- Fix - [#16495](https://geometa.co.uk/support/stormworks/16495) Fixed cooldown on MP Hangar glass door
- Fix - [#16724](https://geometa.co.uk/support/stormworks/16724) Fog / rain changing underwater lighting colours
- Fix - Fixed fog of war not correctly clearing beyond 256 tiles causing fogged regions to appear
- Fix - [#17263](https://geometa.co.uk/support/stormworks/17263) Resolved data issue parsing composite write microcontroller modules
- Fix - [#17439](https://geometa.co.uk/support/stormworks/17439) Fixed rotated edit grids detecting/reclaiming vehicles outside their bounds
- Fix - [#17857](https://geometa.co.uk/support/stormworks/17857) Fixed gimbal camera laser raycast interacting with non-colliding physics
