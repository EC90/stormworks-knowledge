# V0.2.2-5

**V0.2.2-5** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on May 12, 2018.

## v0.2.5

- Fix - Fixed toggle active mission button not un-toggling
- Fix - Reset vehicle screen now visible again
- Fix - Fixed spelling in sea fort tourist mission

## v0.2.4

- Feature - Added creative mode mission spawn menu (on missions screen, singleplayer only)
- Feature - Added button in creative mode for removing a mission in the world (on mission information screen when mission is selected)
- Feature - Added button to test a mission from the editor (displays next to mission edit/delete buttons)
- Feature - Added editbox in mission editor to set playlist name
- Fix - Fixed oil rig ladder not having physics
- Fix - Fixed hole in runway on military island
- Fix - Added names to all official mission playlists
- Fix - Fixed movable objects not spawning in the correct places
- Fix - Fixed crash when destroying vehicles/objects attached to other vehicles/objects
- Fix - Improved nuclear forklift mission
- Fix - Text prompting to sleep in bed now shows when no missions are available
- Fix - Fixed player waypoint colour

## v0.2.3

- Feature - sea floor physics optimization
- Feature - oil refinery island updated
- Feature - added 2 new missions for the Sea Fort tour company
- Fix - all uploaded workshop vehicles now show in vehicle editor workshop menu
- Fix - mission objective UI state icon position fixed
- Fix - game no longer gets stuck in broken tutorial state when loading causing workbench to break
- Fix - removed placeholder missions playlist
- Fix - avoid unlocking same component twice in rewards
- Fix - carrying characters while swimming no longer has weight issues
- Fix - interacting with mirrored parts like throttle lever while mirrored now works correctly
- Fix - harness now highlights correctly
- Fix - medium sized oil rig physics corrected so vehicles won't get stuck

## v0.2.2

- Feature - objectives now shows target count on UI
- Feature - missions now spawn slower (a few per month)
- Fix - delivery zone on Skye Power Company nulcear island corrected for forklift mission
