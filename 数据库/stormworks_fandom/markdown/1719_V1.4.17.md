# V1.4.17

**V1.4.17** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 22nd, 2022.

## V1.4.17

- Feature - New casual outfits and youtuber outfits
- Feature - Auto physics quality (Steps up and down based on fps)

- Fix - Frequent crash caused by destroying physics objects
- Fix - [#2196](https://geometa.co.uk/support/stormworks/2196) Characters do not clear ragdoll on revive
- Fix - [#2190](https://geometa.co.uk/support/stormworks/2190) Characters get of beds on death for clients
- Fix - [#1860](https://geometa.co.uk/support/stormworks/1860) Player can return mission objects set as 'show on map' to workbench, but get sent to 0,0
- Fix - [#1427](https://geometa.co.uk/support/stormworks/1427) Coal duplication glitch
- Fix - [#567](https://geometa.co.uk/support/stormworks/567) [#6913](https://geometa.co.uk/support/stormworks/6913) Monitor block rendering flickers when it moves
- Fix - [#4924](https://geometa.co.uk/support/stormworks/4924) Whale animation issue
- Fix - Static vehicle behavior inconsistencies with electric
- Fix - [#5113](https://geometa.co.uk/support/stormworks/5113) Door tooltip at hospital island
- Fix - [#5330](https://geometa.co.uk/support/stormworks/5330) Wave patch issue for sealed volumes in whirlpools
- Fix - Light and billboard light distance rendering re-balance
- Fix - [#6455](https://geometa.co.uk/support/stormworks/6455) Ocean draws over elements like HUD or light halo
- Fix - [#5611](https://geometa.co.uk/support/stormworks/5611) Vehicles Fall Through the Ground in Low Physics
- Fix - [#6305](https://geometa.co.uk/support/stormworks/6305) Crankshaft Converters do not output RPS value
- Fix - [#6367](https://geometa.co.uk/support/stormworks/6367) Fish spawning upright at save load
- Fix - [#6377](https://geometa.co.uk/support/stormworks/6377) Radio RX composite descriptions are switched
- Fix - Ladder climbing now respects the inverted movement setting
- Fix - Fixed fog/water attenuation for light sources
- Fix - Fixed volume lights using atmospheric fog values when underwater
- Fix - [#6712](https://geometa.co.uk/support/stormworks/6712) Swimming direction inverted on controllers
- Fix - [#6718](https://geometa.co.uk/support/stormworks/6718) Increased catalytic converter conversion speed
- Fix - [#6701](https://geometa.co.uk/support/stormworks/6701) Updated property slider description in micro-controllers
- Fix - [#7185](https://geometa.co.uk/support/stormworks/7185) [#6761](https://geometa.co.uk/support/stormworks/6761) All controllers are now activated on any controller button press
- Fix - [#6802](https://geometa.co.uk/support/stormworks/6802) Added several missing localizations
- Fix - [#4968](https://geometa.co.uk/support/stormworks/4968) Removed dynamic icebergs
- Fix - [#6808](https://geometa.co.uk/support/stormworks/6808) Missing face on battle-cannon
- Fix - [#7165](https://geometa.co.uk/support/stormworks/7165) Vehicle spawned by script does not have a peer_id of -1
- Fix - [#7415](https://geometa.co.uk/support/stormworks/7415) being unable to heal survivors while in seats and stuff
- Fix - [#7469](https://geometa.co.uk/support/stormworks/7469) Guns don't deal damage to other players
- Fix - Main menu settings not saving correctly
