# V1.4.15

**V1.4.15** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 8th, 2022.

## V1.4.15

- Feature - Improved crash dump reporting system
- Feature - [#5247](https://geometa.co.uk/support/stormworks/5247) [#6364](https://geometa.co.uk/support/stormworks/6364) [#6221](https://geometa.co.uk/support/stormworks/6221) Multiplayer time dilation algorithm overhaul
- Feature - Multiplayer bandwidth optimization

- Fix - [#6770](https://geometa.co.uk/support/stormworks/6770) [#6862](https://geometa.co.uk/support/stormworks/6862) Two sided buttons now use the correct color zones and are paintable on both sides
- Fix - [#6765](https://geometa.co.uk/support/stormworks/6765) Door color changes after saving and reloading vehicle
- Fix - [#6777](https://geometa.co.uk/support/stormworks/6777) Window inverse pyramid 2x2x2 mesh offset
- Fix - [#6764](https://geometa.co.uk/support/stormworks/6764) Instrument panel bar and radial indicators are now unpaintable
- Fix - [#6757](https://geometa.co.uk/support/stormworks/6757) Door frame edge and corner component coloring not working

- Fix - [#6465](https://geometa.co.uk/support/stormworks/6465) [#7029](https://geometa.co.uk/support/stormworks/7029) Gamepad sensitivity issues on varied framerates
- Fix - Controller Axis settings getting reset
- Fix - Small inputs on controllers when leaving the dead-zone not registering correctly

- Fix - [#369](https://geometa.co.uk/support/stormworks/369) Menu Audio Glitching
- Fix - [#106](https://geometa.co.uk/support/stormworks/106) Clients moving while in workbench
- Fix - [#1365](https://geometa.co.uk/support/stormworks/1365) Rotor blades don't snap off
- Fix - [#3920](https://geometa.co.uk/support/stormworks/3920) Small Engine sound inaudibly quiet
- Fix - [#2797](https://geometa.co.uk/support/stormworks/2797) Mirrored barrel extensions for rotary canon rotate incorrectly
- Fix - [#2762](https://geometa.co.uk/support/stormworks/2762) Editor tooltip sometimes get stuck
- Fix - [#4885](https://geometa.co.uk/support/stormworks/4885) Wind sounds when submerged
- Fix - [#5140](https://geometa.co.uk/support/stormworks/5140) [#6673](https://geometa.co.uk/support/stormworks/6673) [#7044](https://geometa.co.uk/support/stormworks/7044) Environment sounds no longer play in editor
- Fix - [#5098](https://geometa.co.uk/support/stormworks/5098) Laser beacon not rendering glass/additive mesh
- Fix - [#5527](https://geometa.co.uk/support/stormworks/5527) Character deforming when emoting in photo mode
- Fix - Tornado wind affecting enclosed compartments
- Fix - [#5235](https://geometa.co.uk/support/stormworks/5235) Meteors show in editor

- Fix - [#6100](https://geometa.co.uk/support/stormworks/6100) Very tall tornadoes

- Fix - [#6210](https://geometa.co.uk/support/stormworks/6210) 3x3 and 5x5 Fluid Heat Radiator (electric) missing faces

- Fix - Kraken sometimes refusing to let a ship go
