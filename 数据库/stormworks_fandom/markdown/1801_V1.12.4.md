# V1.12.4

**V1.12.4** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on October 9th, 2024.

## V1.12.4

- Feature - [#4418](https://geometa.co.uk/support/stormworks/4418) Dual Wheels
- Dual wheels are now available as a property on advanced wheel components
- Fix - [#20107](https://geometa.co.uk/support/stormworks/20107) AI Helicopters no longer try to land while unloaded
- Fix - [#25242](https://geometa.co.uk/support/stormworks/25242) Orbital emergency missions now expire
- Fix - [#25308](https://geometa.co.uk/support/stormworks/25308) Winch audio now stops when disconnecting a rope
- Fix - [#25781](https://geometa.co.uk/support/stormworks/25781) Chat triggering radio item sound effect
- Fix - [#25745](https://geometa.co.uk/support/stormworks/25745) Network connect event ordering now allows for kicking a player in onPlayerJoin
- Fix - [#25843](https://geometa.co.uk/support/stormworks/25843) Dynamic objects initial network data (Fish/Creature ball at starter base)
