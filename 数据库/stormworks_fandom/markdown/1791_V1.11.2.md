# V1.11.2

**V1.11.2** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on June 5th, 2024.

## V1.11.2

- Feature - Refuelling Missions
- Fix - [#21006](https://geometa.co.uk/support/stormworks/21006) [#23999](https://geometa.co.uk/support/stormworks/23999) Several trainline junctions inverted or derailing
- Fix - [#21640](https://geometa.co.uk/support/stormworks/21640) AI mission vehicle spawning in floor
- Fix - [#21708](https://geometa.co.uk/support/stormworks/21708) AI boats spawning in the Beginner Island floor
- Fix - [#23191](https://geometa.co.uk/support/stormworks/23191) AI boat horn stuck on with inf-electric
- Fix - [#22066](https://geometa.co.uk/support/stormworks/22066) Scaled vehicle handle counter force with atmosphere factor
- Fix - [#22250](https://geometa.co.uk/support/stormworks/22250) Adjusted rope forces in space
- Fix - Crash caused by physics data access by projectiles after an object was destroyed
- Fix - Missions do not despawn full vehicle groups
- Fix - Fixed some missions missing names
