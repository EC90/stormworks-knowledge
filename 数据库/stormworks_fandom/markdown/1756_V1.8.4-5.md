# V1.8.4-5

**V1.8.4-5** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on July 21st, 2023.

## V1.8.4-5

- Fix - Added protective code to address recent crashing issues related to oil spill data
- Rework - [#18678](https://geometa.co.uk/support/stormworks/18678) Physics sensor angular velocity calculation updated and added additional tilt/compass outputs
- Fix - [#17556](https://geometa.co.uk/support/stormworks/17556) Crash when teleported by an addon while in the workbench
- Fix - [#18474](https://geometa.co.uk/support/stormworks/18474) getVehiclePos and addDamage now work with sub-bodies and returns the correct voxel transform
- Fix - [#18673](https://geometa.co.uk/support/stormworks/18673) Chaff clouds not spawning in multiplayer
- Fix - [#18683](https://geometa.co.uk/support/stormworks/18683) Flashlight rendering in photo-mode
- Fix - [#18846](https://geometa.co.uk/support/stormworks/18846) - Updated Hyanen garage mission zone survivor transform
- Rework - [#19327](https://geometa.co.uk/support/stormworks/19327) Disabled broken blue van mission location
