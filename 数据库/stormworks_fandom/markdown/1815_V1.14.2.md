# V1.14.2

**V1.14.2** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 9th, 2025.

## V1.14.2

- Feature - API to allow NPCs to be equipped with specific items
- Feature - API to allow NPCs to be set to hostile state
- Feature - (Search and Destroy DLC) Enemy AI infantry added to combat add-on
- Feature - (Search and Destroy DLC) Enemy AI vehicles may now be equipped with missiles / rockets
- Fix - Resolved grenade being paintable
- Fix - Lobsters and crabs can now be caught on dedicated servers
- Fix - potential crash fix related to ropes
- Fix - (Search and Destroy DLC) Fixed one of the enemy AI vehicles sometimes not being able to reload cannon
