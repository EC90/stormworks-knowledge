# V0.1.19

**V0.1.19** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 27, 2018.

## V0.1.19

- Feature - photo mode can now be paused/unpaused in singleplayer
- Feature - doubled range of photo mode camera (80m)
- Feature - photo mode camera is now relative to player
- Feature - softer button click sound in vehicle editor
- Feature - updated tags of wing and control surface components, will now show in inventory when searching "airplane" or "aeroplane"
- Fix - fixed crash when hovering textboxes on select panel and pressing tab
- Fix - fixed crash when clearing vehicle with select panel open
- Fix - getting out of upside-down vehicles no longer causes the player to be flung into space
- Fix - buzzer pitch now works correctly with pitch > 100%
- Fix - movable objects no longer show an empty tooltip when hovered on the map
- Fix - fixed missions sometimes causing large framerate drops
- Fix - improved performance of error logging
- Fix - fixed inventory playing extra sounds when clicking/double-clicking components
- Fix - jump sound no longer plays unless jump was pressed
- Fix - land sound plays far less frequently and is quieter
- Fix - land sound no longer plays when going from swimming to walking
- Fix - fixed not being able to cancel the overwrite/delete vehicle dialog if delete button was double-clicked
- Fix - improved performance of rendering transparent UI elements
- Fix - pressing H in photo mode no longer toggles pilot seat UI when exiting photo mode
- Fix - pilot seat UI hides correctly in photo mode
- Fix - attaching to seat/ladder/handle cancels climbing out of water behaviour
