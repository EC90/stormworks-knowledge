# V0.5.9-11

**V0.5.9-11** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 4th, 2019.

## V0.5.9-11

- Feature - 5 new window types
- Fix - reduced lens glare effect on spotlights to fix AMD graphics issue
- Fix - flow dynamics change to reduce fluid flow oscillation
- Fix - stopped cleaning backup files to fix crash for some users
