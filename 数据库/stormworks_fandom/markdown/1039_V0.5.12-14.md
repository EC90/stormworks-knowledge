# V0.5.12-14

**V0.5.12-14** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 11th, 2019.

## V0.5.12

- Feature - Added paintable sign component with no backlight (existing paintable signed renamed to "Paintable Indicator")
- Feature - Added new creative island crane created by XFury and Gardiner
- Feature - Added variable braking to wheels
- Feature - Added "General" tab to settings menu
- Feature - Moved options for showing the clock and objectives on the HUD to general settings
- Feature - Added options to general settings to hide the minimap and hide player names in multiplayer

- Fix - Vehicle/microcontroller backups are now limited to 10 and will no longer be auto-deleted after 24 hours
- (PLEASE NOTE: Players on MacOS will need to manually delete their old backup folders to clean files created by the previous system (~Library/Application Support/Stormworks/data/vehicle_backups and microprocessor_backups). For the majority of Windows users the old backup folders will be cleaned up automatically, but they can safely be deleted manually if you want to clear the space taken up by the vehicle files by removing %appdata%/Stormworks/data/vehicle_backups and microprocessor_backups)

- Fix - Physics stability improvements when creating constraints between objects (fixes "crocodile death roll" with custom doors, should improve occasional issues when placing characters in seats)
- Fix - Player no longer gets stuck/falls through seat when exiting seat at high speed
- Fix - All logic gates are now unlocked from the start of a new career game
- Fix - Disabled "press R to return to workbench" for static vehicles spawned from structure workbenches
- Fix - Survivors no longer take damage when picked up at high speed
- Fix - Fixed typo in small porthole description
- Fix - Reduced giant prop mass from 500 to 100
- Fix - Fixed spotlights having infinite distance when shining onto some surfaces
- Fix - Fixed multi-tile islands not lining up properly on the map
- Fix - Players who leave a multiplayer game while dead and then rejoin will be correctly respawned
- Fix - Added check on game start to verify files can be written
- Fix - Game will try to start in windowed mode after crashing on startup
- Fix - Mechanical components no longer go floppy when they run out of electric
- Fix - Disabled spotlight volumes on Vega GPUs

## V0.5.13

- Fix - Fixed crash when hosting a multiplayer game

## V0.5.14

- Fix - Fixed 1x3 hinge on existing vehicles having collision disabled when spawned
- Fix - Fixed wheel brakes not working when no engine is connected to wheel
- Fix - Fixed microcontroller composite switchbox having wrong icon
