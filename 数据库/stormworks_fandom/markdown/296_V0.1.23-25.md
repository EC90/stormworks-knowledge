# V0.1.23-25

**V0.1.23-25** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 14, 2018.

## v0.1.25

- Fix - climb animation no longer uses 3rd person camera
- Fix - controller button input now works correctly
- Fix - hotkey buttons now labelled correctly in seat controls guide
- Fix - helm logic now works correctly
- Fix - helm moved to vehicle control category

## v0.1.24

- Fix - various fixes to new seats including medical bed weight

## v0.1.23 (The Seat Update)

- Feature - new seat types - harness, stretcher, helm, bed, medical bed
- Feature - new climb animation for climbing out of water
- Feature - updated throttle lever with up and down buttons
- Feature - multiple controller support so you can now bind multiple controllers
- Fix - AND, OR, XOR gates now work correctly when both inputs are modified in the same tick
- Fix - controllers now work correctly in multiplayer
- Fix - controller hotkeys 7+ now release correctly
- Fix - robotic pivot now outputs unwrapped total rotation
