# V1.11.1

**V1.11.1** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on May 22nd, 2024.

## V1.11.1

- Feature - [#5278](https://geometa.co.uk/support/stormworks/5278) Added workbench to military base

- Fix - [#23929](https://geometa.co.uk/support/stormworks/23929) Fixed the spawn area for the existing military base workbench
- Fix - [#23893](https://geometa.co.uk/support/stormworks/23893) Resolved invalid link creation issues with logic node link undo-redo
- Balance - [#23266](https://geometa.co.uk/support/stormworks/23266) Greatly increased catalytic converter rate
- Balance - [#23876](https://geometa.co.uk/support/stormworks/23876) Updated cargo rewards
- Rework - Unloaded cargo items now despawn when under half the remaining delivery time to reduce undeliverable packages
- Fix - [#23872](https://geometa.co.uk/support/stormworks/23872) First person items always rendering orange
- Fix - [#23753](https://geometa.co.uk/support/stormworks/23753) Defibrilator not recharging
- Fix - [#23797](https://geometa.co.uk/support/stormworks/23797) Starter Boat instrument radio values not clamped
- Fix - [#23900](https://geometa.co.uk/support/stormworks/23900) Fixed various addon documentation
- Fix - [#24901](https://geometa.co.uk/support/stormworks/24901) Fixed return values for several addon lua functions
- Fix - [#23936](https://geometa.co.uk/support/stormworks/23936) Crash when loading a vehicle during a merge-tool operation
