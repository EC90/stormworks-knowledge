# V0.1.17-18

**V0.1.17-18** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 23, 2018.

## v0.1.18

- Feature - added camera mode to options menu with fixed, yaw and free options for controling vehicles in third person
- Fix - winch cables are no longer too heavy to lift
- Fix - modified memory allocation strategy for the scene to greatly reduce chance of running out of memory
- Fix - Windows version now uses extended memory address support so more memory is available to the application
- Fix - third person camera no longer collides with movable objects
- Fix - first person camera no longer jitters in multiplayer while in moving vehicle
- Fix - fallback added for creating the game window to retry in windowed mode if window creation fails
- Fix - connectors always activate as white color rather than painted color

## v0.1.17 (The Speakers and Propellers Update)

- Feature - new components: azimuth propeller, large propeller
- Feature - new components: small tyre, large tyre
- Feature - new components: foghorn, buzzer
- Feature - multiplayer now has "waiting for server" screen when server is working
- Feature - updated the tugboat vehicle asset with new components
- Fix - altitude sensor now gives accurate reading
- Fix - vehicles now consistently return to workbench using R even when their multi-bodies are unfolded larger than edit grid
- Fix - rotors no longer spin immediately when spawning
- Fix - multiplayer player positions are corrected with vehicle position corrections
- Fix - multiplayer no longer crashes when a player disconnects
- Fix - multiplayer player names now disappear when players fast travel
- Fix - resolved crash when teleporting vehicle to workbench when carrying a character
- Fix - rebalanced small propeller force
- Fix - third-person camera no longer obstructed by other vehicles
