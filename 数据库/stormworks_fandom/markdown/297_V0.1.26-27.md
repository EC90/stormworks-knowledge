# V0.1.26-27

**V0.1.26-27** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on April 20, 2018.

## v0.1.27 (The Mag-All Update)

- Feature - Added Mag-All component - A new type of magnet that will attach to any object (except characters), good for tethering, anchors, and securing cargo!
- Feature - Added heavy duty winch with 100m spool length
- Feature - Can now grab handles while attached to harness
- Feature - Harness now has logic for hotkeys 1 - 6
- Fix - Fixed vehicles crashing server when initially spawning in multiplayer
- Fix - Fixed vehicle files becoming unusable due to vehicle author data
- Fix - Fixed incorrect/duplicate names being written to vehicle author data
- Fix - Server will prevent players from connecting if they're running an incompatible game version
- Fix - Fixed characters not attaching to new seats correctly in some orientations
- Fix - NPCs detach from seats correctly
- Fix - Fixed new seat types missing buoyancy data
- Fix - Third-person vehicle camera no longer obstructed by harness physics
- Fix - Fixed gap in HOTAS seat mesh
- Fix - Harness renders correctly in vehicle editor
- Fix - Rotating photo mode camera with RMB no longer broken when zoom has been rebound
- Fix - Mission map now blocks interaction with objects in the world if interact has been rebound to a mouse button
- Fix - Fixed upside down pistons causing vehicles to break/spawn at origin

## v0.1.26

- Fix - AND logic gate now works as expected
