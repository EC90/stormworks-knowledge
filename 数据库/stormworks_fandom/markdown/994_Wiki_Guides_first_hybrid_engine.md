## first hybrid engine

With the vehicle you have chosen, Grab a small engine or build a small modular engine, connect the modular clutch to a generator using pipes. Add/Connect a battery, then using logic connect the electricity where required. Put down an electric circuit breaker if you want to toggle the electric engine or just add an electric motor and use pipes to connect it to what you are powering. go to logic and connect the desired controls to the electric motor(What drives the vehicle) and controls for the modular engine(What generates electricity).

if you want an engine that is using both motors to power the car, connect both motors to what you are powering
