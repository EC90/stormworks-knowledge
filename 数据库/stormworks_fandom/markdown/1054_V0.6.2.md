# V0.6.2

**V0.6.2** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 1st, 2019.

## V0.6.2

- Fix - Fixed arctic missions spawning before purchasing an arctic base
- Fix - Fixed edit grid being in the wrong place on custom boat player base
- Fix - Fixed seal and penguin idle animation positions
- Fix - Slowed down penguins and seals forward speed to prevent them from beaching so often
- Fix - Fixed some map labels not rendering
- Fix - Waypoint no longer floats high in the air
- Fix - Fixed cable length node missing on large winch
- Fix - Fixed logic links not rendering when dragging
- Fix - Fixed logic node jittering when in the arctic with TAA enabled
- Fix - Dynamic icebergs now cause vehicle damage
- Fix - Reworked trainline generation to no longer fail to link some terminals
- Fix - Added more information to log.txt file when starting the game to diagnose some startup issues
- Fix - Updated plane crash mission to make it harder to get stuck in the plane's pilot seat
- Fix - Added signals to fork train piece and Arctic terminals
- Fix - Fixed characters spawned with special outfits sometimes rendering accessories in the wrong place
- Fix - Fixed not being able to select animals in the mission editor after they've been deselected
- Fix - Added some missing islands to mission editor
- Fix - Fixed arctic airstrip dock not having spotlights
- Fix - Fixed arctic mining island not having spotlights
- Fix - Fixed some terrain issues at container depot, shipbreaking yard and arctic outpost
- Fix - Added physics to ramps at arctic outpost train terminal
- Fix - Fixed walls of railway at shipbreaking island being too close on corners
