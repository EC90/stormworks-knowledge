# V1.10.5

**V1.10.5** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 13th, 2024.

## V1.10.5

- Feature - Added search filters for workshop upload screens
- Fix - Particle manager buffer allocation crash
- Fix - [#22715](https://geometa.co.uk/support/stormworks/22715) Removed deprecated steam boiler pressure logic node
- Fix - [#22890](https://geometa.co.uk/support/stormworks/22890) Fixed issues with engine fuel consumption
- Fix - [#23096](https://geometa.co.uk/support/stormworks/23096) Updated approach to exhaust production and exhaust color
- Fix - [#23178](https://geometa.co.uk/support/stormworks/23178) Increased threshold for exhaust rendering from ports
- Fix - [#23237](https://geometa.co.uk/support/stormworks/23237) Diesel burner fuel consumption issues
- Fix - Improved modular engine stability
- Fix - [#23029](https://geometa.co.uk/support/stormworks/23029) Disabled look-direction forces when surface swimming
- Fix - [#23040](https://geometa.co.uk/support/stormworks/23040) Inventory and space seat fluid slot resolving issues
- Fix - [#23240](https://geometa.co.uk/support/stormworks/23240) Fixed unload islands from massive structures generating over vehicles within load range causing infinite saving/invisible vehicle issues (e.g. Donkk Isle Catenaries Addon)
- Fix - [#23169](https://geometa.co.uk/support/stormworks/23169) Temperature and radiation probes breaking
- Fix - Removed outdated helicopter and steam presets
- Rework - [#23051](https://geometa.co.uk/support/stormworks/23051) [#23128](https://geometa.co.uk/support/stormworks/23128) Astronomy coordinates system reworked:
- Astronomy coordinates are now in meters.
- Directional RX behavior is now more consistent.
