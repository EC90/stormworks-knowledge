# V1.4.19

**V1.4.19** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on May 20th, 2022.

## V1.4.19

In this update we have reworked the sound library that underlies all of Stormworks' audio effects, these changes should result in a much more stable experience especially for MacOS players.

- Fix - [#756](https://geometa.co.uk/support/stormworks/756) Sound library rework
- Fix - [#2765](https://geometa.co.uk/support/stormworks/2765) Sliding Connector not connecting in certain circumstances
- Fix - [#2852](https://geometa.co.uk/support/stormworks/2852) Train wheels now activate when applying torque
- Fix - [#1899](https://geometa.co.uk/support/stormworks/1899) Water falling effect render issues around turret ring
- Fix - [#6636](https://geometa.co.uk/support/stormworks/6636) Vehicle overwrite save file warning was case insensitive
- Fix - [#7154](https://geometa.co.uk/support/stormworks/7154) Time and weather overrides not saving correctly
- Fix - [#6995](https://geometa.co.uk/support/stormworks/6995) Prefab rocket launchers mirror incorrectly
- Fix - [#7388](https://geometa.co.uk/support/stormworks/7388) Npcs not taking vehicle fire damage
- Fix - [#7473](https://geometa.co.uk/support/stormworks/7473) Terrain issues near Mount Goldblum
- Fix - [#7524](https://geometa.co.uk/support/stormworks/7524) Clouds / Lightning not generating correctly
- Fix - [#7555](https://geometa.co.uk/support/stormworks/7555) Fixed mesh issues with monitors
- Fix - [#7558](https://geometa.co.uk/support/stormworks/7558) Audio settings not updating
- Fix - [#7615](https://geometa.co.uk/support/stormworks/7615) Laser point stops showing when moving 170m away
- Fix - [#7673](https://geometa.co.uk/support/stormworks/7673) Updated small warhead meshes to match with SRBs and radar
- Fix - [#7690](https://geometa.co.uk/support/stormworks/7690) Several minor component graphical defects
- Fix - [#7692](https://geometa.co.uk/support/stormworks/7692) SRB nozzles using wrong force direction when flipped
- Fix - [#7705](https://geometa.co.uk/support/stormworks/7705) Corrected cannon belt mass values
- Fix - [#7854](https://geometa.co.uk/support/stormworks/7854) Voice chat range issues
- Fix - [#7868](https://geometa.co.uk/support/stormworks/7868) Propellers repair
