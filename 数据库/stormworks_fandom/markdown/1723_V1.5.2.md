# V1.5.2

**V1.5.2** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on June 17th, 2022.

## V1.5.2

- Feature - [#587](https://geometa.co.uk/support/stormworks/587) Mounted Welder and Mounted End-Effector components
- Feature - [#656](https://geometa.co.uk/support/stormworks/656) Solid Rocket Nozzle Max Power slider

- Fix - [#8588](https://geometa.co.uk/support/stormworks/8588) [#8613](https://geometa.co.uk/support/stormworks/8613) Fixed default damage values for collisions
- Fix - [#7101](https://geometa.co.uk/support/stormworks/7101) [#7505](https://geometa.co.uk/support/stormworks/7505) [#7619](https://geometa.co.uk/support/stormworks/7619) Natural disasters sirens can now be disabled globally with a button on them
- Fix - Old saves will now initialize damage_tracker in mission lua script

- Rework - [#8717](https://geometa.co.uk/support/stormworks/8717) Sonar active ping reworked*
- Fix - [#8838](https://geometa.co.uk/support/stormworks/8838) [#8728](https://geometa.co.uk/support/stormworks/8728) Radar does not detect tilted vehicle
- Fix - [#8790](https://geometa.co.uk/support/stormworks/8790) Inactive sonar jammer consumes power
- Fix - [#8562](https://geometa.co.uk/support/stormworks/8562) Sonar Jammer node mislabels
- Fix - [#8593](https://geometa.co.uk/support/stormworks/8593) Sonar description spelling mistake
- Fix - [#8668](https://geometa.co.uk/support/stormworks/8668) Sonar Data node info

- Fix - [#7633](https://geometa.co.uk/support/stormworks/7633) Fix being able to save while dead when quitting to main menu
- Fix - [#7640](https://geometa.co.uk/support/stormworks/7640) Scroll bar not appearing for updated ui containers
- Fix - [#7650](https://geometa.co.uk/support/stormworks/7650) C4 placement rendering when in a seat
- Fix - [#7827](https://geometa.co.uk/support/stormworks/7827) C4 placement on moving vehicles for clients
- Fix - [#7652](https://geometa.co.uk/support/stormworks/7652) Pilot mask rendering issue with some outfits
- Fix - [#7702](https://geometa.co.uk/support/stormworks/7702) Wrong editor mesh for Camera Gimbal and Stabilizer Camera
- Fix - [#7862](https://geometa.co.uk/support/stormworks/7862) Floating terrain at Terminal Trinite
- Fix - Optimized parsing for some scene values
- Fix - Coaxial rotor entire mesh rotating

- Fix - State data network messages being sent for vehicles with no stateful components
- Fix - [#1197](https://geometa.co.uk/support/stormworks/1197) Game occasionally getting stuck on audio mutexes

*Sonar ping input must now be held to continue receiving information from that ping; passive data is no longer output while actively pinging.
