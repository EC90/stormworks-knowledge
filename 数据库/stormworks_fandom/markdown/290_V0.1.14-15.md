# V0.1.14-15

**V0.1.14-15** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on March 16, 2018.

## v0.1.15 (The Fixed Wing Update)

- Feature - 3 new aerofoil control surfaces
- Feature - 5 new aerofoil wing sections
- Feature - 3rd person vehicle camera is now free-orbiting
- Fix - resolved crash when using ladders in multiplayer
- Fix - MacOS added missing audio frameworks

## v0.1.14

- Fix - placing characters in seats no longer causes physics error
- Fix - hiding character in camera mode no longer causes player to disappear in game
