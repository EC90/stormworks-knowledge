# V1.5.15-16

**V1.5.15-16** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on September 23rd, 2022.

## V1.5.15-16

- Feature - Missile Laser Sensor ([#5754](https://geometa.co.uk/support/stormworks/5754) [#6954](https://geometa.co.uk/support/stormworks/6954))

- Fix - [#3713](https://geometa.co.uk/support/stormworks/3713) Game music doesn't stop when returning to main menu
- Fix - [#7177](https://geometa.co.uk/support/stormworks/7177) Charger sometimes not functioning as intended due to block placement order
- Fix - Rope states not updating on client join
- Fix - Held rope animation not matching hand position
- Fix - [#13070](https://geometa.co.uk/support/stormworks/13070) Removed non-functional MC editor 'Don't show in inventory' option
- Fix - [#2633](https://geometa.co.uk/support/stormworks/2633) Removed arrow rendering from logic links for improved performance
