# V1.3.21

**V1.3.21** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 21st, 2022.

## V1.3.21

- Fix - [#756](https://geometa.co.uk/support/stormworks/756) Fix macos audio issues with sounds not playing
- Fix - [#207](https://geometa.co.uk/support/stormworks/207) prevent no sleep vehicles from unloading
- Fix - [#4022](https://geometa.co.uk/support/stormworks/4022) onPlayerUnsit now returns peer_id as expected instead of object_id
- Fix - [#4145](https://geometa.co.uk/support/stormworks/4145) fixed missing faces on barrels for heavy autocannon
- Fix - [#3835](https://geometa.co.uk/support/stormworks/3835) compass ball additive layer rendering
- Fix - [#3735](https://geometa.co.uk/support/stormworks/3735) floating trees fixed on multiplayer base
- Fix - [#4454](https://geometa.co.uk/support/stormworks/4454) auto cannon ammo drum fixed mirroring
- Fix - [#4446](https://geometa.co.uk/support/stormworks/4446) resolve fluid slots even when off
- Fix - [#4313](https://geometa.co.uk/support/stormworks/4313) clear network requests when disconnecting from a server
- Fix - [#4298](https://geometa.co.uk/support/stormworks/4298) hosts now send map update lua events when closing the map
- Fix - [#4023](https://geometa.co.uk/support/stormworks/4023) onPlayerUnsit() and onCharacterUnsit() now trigger on ladders
- Fix - [#3029](https://geometa.co.uk/support/stormworks/3029) allow crouch animation to override jump animation to keep camera aligned with physics hitbox during crouch jump
- Fix - [#4453](https://geometa.co.uk/support/stormworks/4453) fixed gaps in the air ram model
- Fix - [#4311](https://geometa.co.uk/support/stormworks/4311) hole in oil refinery fixed

- Added ?mclear alias for ?mclean
