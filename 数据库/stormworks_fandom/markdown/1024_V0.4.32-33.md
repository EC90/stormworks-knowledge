# V0.4.32-33

**V0.4.32-33** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on October 29th, 2018.

## V.04.32

- Fix - Decreased jet fuel consumption slightly

## V0.4.33

- Fix - Fixed medium battery mesh
- Fix - Fixed centre of mass of buoyancy volumes calculated incorrectly
- Fix - Strip particles line up correctly with regular particles
- Fix - Fixed parts of suspension component not rendering
- Fix - Jet engine thrust spoiler will now block all thrust at a value of 1
- Fix - Updated description for jet engine exhausts
- Fix - Added blue editor-only arrows to gearbox indicating placement direction
- Fix - Fixed custom fuel tanks having incorrect volume compared to fuel tank components
- Fix - Custom fuel tanks and fuel tank components transfer fluid at the same rate
- Fix - Fixed player occasionally exiting spawning screen when islands were still loading
- Fix - Fixed electrical links between batteries and buttons disappearing when cutting and pasting battery
- Fix - Fixed player not going into spawn screen after dying or when fast-travelling vehicles
