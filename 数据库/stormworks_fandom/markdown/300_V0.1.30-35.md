# V0.1.30-35

**V0.1.30-35** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on May 1, 2018.

## v0.1.33-35

- Fix - Fixed crash when starting new game without finishing tutorial
- Fix - Fixed typo in heavy rotor description
- Fix - Minor changes to error logging

## v0.1.32

- Feature - Winches will now extend when pulled with enough force
- Fix - Fixed small winch cable position
- Fix - Resolved mission related crashes (issues when autosaving, loading saved games, sleeping)

## v0.1.31

- Feature - Added collective to huge rotor and large rotor
- Feature - Escape key now closes map/missions screen
- Fix - Fixed NOT gate not always working
- Fix - Blade pitch renders in vehicle editor
- Fix - Fixed rendering of flipped rotors
- Fix - Fixed initial state of logic systems not working correctly

## v0.1.30

- Fix - Resolved occasional CTD when using text input boxes in the vehicle editor
- Fix - Fixed fans not working
- Fix - Increased max power of titan propeller by x5
- Fix - Fixed rendering of rotors in vehicle editor
