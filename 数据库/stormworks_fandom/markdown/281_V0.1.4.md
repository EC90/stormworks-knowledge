# V0.1.4

**V0.1.4** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 1, 2018.

## V0.1.4

- Fix - nuclear island and other island physics now works correctly
- Fix - can no longer walk through some doors
- Fix - camera no longer clips though objects
- Fix - removed help popups from game
- Fix - mission condition where vehicle despawning no longer causes crash
