# V1.6.11

**V1.6.11** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 26th, 2023.

## V1.6.11

- Feature - Multiplayer client physics optimization

- Fix - Several gameplay managers ticking their state while simulation is paused
- Fix - [#15336](https://geometa.co.uk/support/stormworks/15336) Arid map colour discrepancies, added lua functions to support rock and gravel map colours
- Fix - [#14792](https://geometa.co.uk/support/stormworks/14792) Default cargo container timer displaying negative values
- Rework - [#14626](https://geometa.co.uk/support/stormworks/14626) Visually revised the mating surfaces for steam train parts to clarify that they need to be the same size and also oriented correctly to connect
- Balance - [#14967](https://geometa.co.uk/support/stormworks/14967) Increased despawn times for processed metals dynamic objects
- Fix - [#14996](https://geometa.co.uk/support/stormworks/14996) setTileInventory lua documentation
- Fix - [#15088](https://geometa.co.uk/support/stormworks/15088) [#15570](https://geometa.co.uk/support/stormworks/15570) Lua documentation content issues
- Fix - [#15210](https://geometa.co.uk/support/stormworks/15210) Updated default resource storage vehicle
- Fix - [#15142](https://geometa.co.uk/support/stormworks/15142) Updated missiles on default weapons AI destroyers
- Fix - [#15371](https://geometa.co.uk/support/stormworks/15371) Default rescue scripts showing decimals for some numbers
- Fix - [#1554](https://geometa.co.uk/support/stormworks/1554) Re-exported Warner docks map tile geometry
- Fix - [#15655](https://geometa.co.uk/support/stormworks/15655) Observatory landmark vehicle guard rail updates
- Fix - [#15683](https://geometa.co.uk/support/stormworks/15683) Removed newlines from dog whistle description
- Fix - [#15688](https://geometa.co.uk/support/stormworks/15688) Fixed block damage not parsing correctly (and optimized empty value parsing)
- Fix - Optimized trainline generation speed
- Fix - [#16044](https://geometa.co.uk/support/stormworks/16044) Updated desalinator description

A high volume of reports on the issue tracker have made us aware of a multiplayer issue regarding the old style wheel components. While we hope players are very happy with today's performance improvements we were unable to fix this issue for this release and hope to resolve it for a future update.
