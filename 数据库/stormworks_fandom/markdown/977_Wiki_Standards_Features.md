## Features

Every Standard Label/Badge can have multiple feature codes. If you meet the rules for the features you can add them to your badge.

### Example

You have the Standard:

Standard

AP1

You now add a stabilizing system and waypoint travel system, allowing you to use the badge:

Standard

AP1 sw

### Global feature rules

- a this vehicle uses the advanced mode/advanced engines
- l this vehicle has a winch or extendable pole with a connector (usually the small connector) to connect to other things and transport them
- s this vehicle has a stabilizing mode (e.g. keep speed, altitude, direction)
- w this vehicle can travel to a waypoint autonomously
- r this vehicles movement can be controlled remotely (remotely means by connector composite or radio communication! For example: brakes, speed, steering, ...)
- + this vehicle has some crazy autonomous functionality (e.g. autonomous takeoff/waypoint/landing)
- x this vehicle provides emergency exit procedures. For example: escape door, life raft, parachutes

### Local feature rules

- b Used by [Land vehicles](https://stormworks.fandom.com/wiki/Wiki/Standards/Land)
- c Used by [Land vehicles](https://stormworks.fandom.com/wiki/Wiki/Standards/Land)
- t Used by [Trucks](https://stormworks.fandom.com/wiki/Wiki/Standards/Land/Truck)
- o Used by [Water vehicles](https://stormworks.fandom.com/wiki/Wiki/Standards/Water)
