# V0.1.6

**V0.1.6** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 2, 2018.

## V0.1.6

- Fix - now save sensitivity value for throttle lever
- Fix - waves no longer go max size next to islands (max size occurs 3km from nearest island)
- Fix - oil rig crane buttons no longer get stuck in flashing state
- Fix - ends of winches no longer float around in low gravity
- Fix - magnetic force of connectors increases with the mass of the object they are part of
- Fix - minor performance improvements for connectors and mass calculation
- Fix - small coaster wheels now spin freely
- Fix - menu shadows minor improvement
- Fix - object placement with openable surfaces fixed to avoid invalid buoyancy
