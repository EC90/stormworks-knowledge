# V0.8.20-21

**V0.8.20-21** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on September 6th, 2019.

## V0.8.20

- Fix - Updated radar descriptions

## V0.8.21

- Feature - 3 New Radar Types

- Fix - Radar descriptions updated to be more intuitive
- Fix - Radars output angles are no longer 0.25 turns offset
- Fix - Radar freezing game when two objects are at the same distance
- Fix - Radars now have blue arrows in editor for ease of use

- Fix - Center of Mass calculations
- Fix - CTD caused by audio

- Fix - Research values being offset
- Fix - Large dock doors being allowed to connect at 90 degrees
