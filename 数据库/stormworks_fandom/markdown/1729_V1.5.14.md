# V1.5.14

**V1.5.14** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on September 9th, 2022.

## V1.5.14

- Feature - Military Uniform Outfits

- 20 New military themed clothes and hats available for all players in the wardrobe.

- Feature - [#7836](https://geometa.co.uk/support/stormworks/7836) Added a new custom menu setting to disable lightning for accessability
- Fix - Lightning sound now respects the environment master audio slider
- Fix - [#12176](https://geometa.co.uk/support/stormworks/12176) Diagonal sloped block faces not being repairable with the welding torch
- Fix - [#12263](https://geometa.co.uk/support/stormworks/12263) Mesh issues at train terminal
- Fix - [#12347](https://geometa.co.uk/support/stormworks/12347) Radars now ignore rotor child physics
- Fix - [#12355](https://geometa.co.uk/support/stormworks/12355) Medium Turret Ring mesh issue
- Fix - [#12397](https://geometa.co.uk/support/stormworks/12397) Clutches no longer instantly engage/disengage
- Fix - [#12398](https://geometa.co.uk/support/stormworks/12398) Unable to detach ropes while both rope anchors are within max equipment rope length
- Fix - [#12489](https://geometa.co.uk/support/stormworks/12489) Impact detector typo
- Fix - [#12622](https://geometa.co.uk/support/stormworks/12622) Boiler's light goes through blocks
- Fix - [#12654](https://geometa.co.uk/support/stormworks/12654) Spelling issue in piston description
- Fix - [#12675](https://geometa.co.uk/support/stormworks/12675) Renamed Megalodon button to Sea Monsters to indicate that it also disables the Kraken
- Fix - [#12812](https://geometa.co.uk/support/stormworks/12812) Characters accumulating speed from nearby tornados while being carried
- Fix - [#12838](https://geometa.co.uk/support/stormworks/12838) Characters with invalid outfit values appearing invisible
- Fix - [#13590](https://geometa.co.uk/support/stormworks/13590) Torque crank buoyancy missing surface
