# V1.7.2

**V1.7.2** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 31st, 2023.

## V1.7.2

- Fix - [#18587](https://geometa.co.uk/support/stormworks/18587) [#18618](https://geometa.co.uk/support/stormworks/18618) Fix client sync issues with dynamic objects causing twilight-zone(lag/damage)
- Fix - Added default oil survey addon to dedicated server default config
- Fix - Several new outfit animation issues
- Fix - [#17620](https://geometa.co.uk/support/stormworks/17620) Only reset display resolution after a crash
- Fix - [#17617](https://geometa.co.uk/support/stormworks/17617) Display warnings when missing fuels on vehicle spawn
- Fix - [#17617](https://geometa.co.uk/support/stormworks/17617) Update fuel rod description to mention uranium ingots
- Fix - [#17533](https://geometa.co.uk/support/stormworks/17533) Adjusted small steam train piston mesh
- Fix - [#17336](https://geometa.co.uk/support/stormworks/17336) Fixed Example Nuclear Reactor rods not dropping if spawned with inf-power enabled
- Fix - [#16470](https://geometa.co.uk/support/stormworks/16470) [#16380](https://geometa.co.uk/support/stormworks/16380) Buzzer sound effect improvements
- Fix - [#16463](https://geometa.co.uk/support/stormworks/16463) Added creature support to lua seat functions and callbacks
- Fix - [#11024](https://geometa.co.uk/support/stormworks/11024) Speedster mission beacon not working correctly
- Fix - [#17564](https://geometa.co.uk/support/stormworks/17564) Add safeguards to captain teleports for ai vehicles
- Fix - [#17794](https://geometa.co.uk/support/stormworks/17794) Amended a minor typo

- Rework - Moved welding goggles and head-mirror to glasses category (you may need to re-equip your outfits)

- Addon Lua:

- Added seated_peer_id to seat data for seated players

- Updated setVehiclePosSafe documentation
