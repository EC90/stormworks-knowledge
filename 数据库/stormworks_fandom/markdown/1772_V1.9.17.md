# V1.9.17

**V1.9.17** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on November 10th, 2023.

## V1.9.17

- Feature - Rope anchor "release rope" logic node

- Fix - [#22825](https://geometa.co.uk/support/stormworks/22825) Resolved door/turret-ring flow and pressure issues
- Fix - [#22287](https://geometa.co.uk/support/stormworks/22287) Default missions tow mission spawning error without DLC
- Fix - [#22483](https://geometa.co.uk/support/stormworks/22483) Default missions repair missions using outdated function call
- Fix - [#21092](https://geometa.co.uk/support/stormworks/21092) Crash when attempting to carry a creature-dragged character
- Fix - [#20876](https://geometa.co.uk/support/stormworks/20876) Fix pressVehicleButton behaviour for toggle buttons
- Fix - Predators no longer attacking
- Fix - [#20988](https://geometa.co.uk/support/stormworks/20988) Default secondary equipment binding to R (prev B)
- Fix - [#21069](https://geometa.co.uk/support/stormworks/21069) Fix buzzer audio layer volume initialization
- Fix - [#21117](https://geometa.co.uk/support/stormworks/21117) Prevent vehicle fire damage ignoring vehicle damage setting when enabled
- Balance - [#21843](https://geometa.co.uk/support/stormworks/21843) [#21853](https://geometa.co.uk/support/stormworks/21853) Balanced heat sources (Firebox no longer kills you, heaters twice as effective, burn damage and radius balanced)
- Fix - Crash which rarely occurred when creating ropes
- Balance - [#21952](https://geometa.co.uk/support/stormworks/21952) Adjusted liquid rocket fuel consumption
- Balance - [#22120](https://geometa.co.uk/support/stormworks/22120) [#22803](https://geometa.co.uk/support/stormworks/22803) Rebalanced RCS thrust and consumption and clamped flow
- Fix - [#22799](https://geometa.co.uk/support/stormworks/22799) Antennas not highlighting when in logic placement mode
- Balance - [#22849](https://geometa.co.uk/support/stormworks/22849) Rebalanced diesel burner consumption and max temperature
- Rework - [#22911](https://geometa.co.uk/support/stormworks/22911) Rescaled maximum ocean pressure to 30atm
