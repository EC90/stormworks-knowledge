# V0.1.7-9

**V0.1.7-9** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on March 6, 2018.

## v0.1.9

- Feature - multiplayer refactor so clients move smoothly and no longer rubber band
- Fix - loading games where islands no longer appear is fixed
- Fix - replaced fire on oil rig
- Fix - crash fixes for internal systems
- Fix - MacOS server now launches correctly
- Fix - physics and geometry for one of the islands (island 4)
- Fix - fishes no longer come out of the water in high seas

## v0.1.8

- Fix - water pumps no longer break
- Fix - duplicate characters no longer spawn when loading game
- Fix - pilot seat controls no longer show for other players in multiplayer

## v0.1.7

- Fix - center of mass now recalculates correctly
- Fix - oil rig crane buttons now function correctly
- Fix - increased surface brightness of omni lights and reduced their volume halo light
- Fix - improved multiplayer performance and fixed issues where players didnt move correctly
- Fix - resolved multiplayer crash when player disconnect
- Fix - players now despawn when disconnected
- Fix - black terrain graphics issue resolved
