# V0.4.29-30

**V0.4.29-30** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on October 19th, 2018.

## V.04.29

- Feature - Added 14 advanced modular jet engine components (advanced mode only)
  - Small intake
  - Large intake
  - Basic exhaust
  - Rotating exhaust
  - Afterburner exhaust (can consume large amounts of fuel for increased propulsion)
  - Small turbine
  - Medium turbine
  - Compressor
  - Combustion chamber
  - 5 duct pieces (similar to pipes but used for connecting jet engine parts)
- Feature - Added advanced jet example to the presets tab in the vehicle editor (Eurofighter)
- Feature - Added RPS limiter slider to engine property panel (from 5 to 100. Engine will ignore throttle when rps goes over the limit)
- Feature - Minor QoL improvement - save game dialog will have name of current save by default after loading a game

- Fix - Rebalanced engine temperature, propellers and rudders
- Fix - Improved the balance of aerodynamics and planes
- Fix - PID controller no longer outputs incorrect derivative value on first tick of activation
- Fix - Updated loading screen with SW logo
- Fix - Fixed immediate crash on startup in the event of corrupted save file
- Fix - Resolved some desync issues with advanced vehicles in multiplayer

## V0.4.30

- Fix - Updated Eurofighter preset with throttle management
- Fix - Rebalanced air and water propellers in non-advanced mode
- Fix - Fixed large jet intake
- Fix - Removed audio on jet compressor when there's no electric
- Fix - Increased jet fuel consumption rate
