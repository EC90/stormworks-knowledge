# V0.2.8-9

**V0.2.8-9** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on May 25, 2018.

## v0.2.9

- Feature - Missions can repeat in career mode if there are no more missions left
- Feature - Added 2 new missions to Skye Power Company playlist
- Feature - Added Fishing Community playlist with 4 new missions
- Feature - Improved lightning effects with greater intensity and sound effects
- Feature - Added triggers to mission editor (4 new trigger events and 7 new trigger actions. Triggers can be used to create complex mission logic - trigger vehicle buttons, send messages to the player, make custom objectives, show/hide markers)
- Feature - Objectives can now have their markers hidden by default
- Feature - Objectives can now be marked as inactive until triggered
- Feature - Empty objective can now be used for showing markers on objects that are not part of a regular objective
- Feature - Collapsible UI for mission objectives in editor
- Feature - Added new objective type for missions (press vehicle buttons) for making missions that require deeper integration with vehicles
- Feature - Vehicle buttons can now be added to missions (set display name of button then parent to the vehicle with the button. Can be used in triggers and new objective)
- Feature - Added a crane to the medium oil rig
- Fix - Fixed several crashes when spawning vehicles in multiplayer
- Fix - Active mission button no longer off-screen on 4:3 aspect ratio monitors
- Fix - Fixed divide by zero in float modulo component
- Fix - Resolved some physics mesh issues on the sea fort and aircraft base islands
- Fix - Handle labels no longer display in photo mode
- Fix - Pressing tab in photo mode no longer toggles first/third person camera
- Fix - Water particles flow in correct direction when water components are mirrored
- Fix - Scrollbars work correctly when being dragged
- Fix - Minor changes to tonemapping to add more vibrance to the world
- Fix - Fixed crash when completing tutorial in creative mode

## v0.2.8

- Fix - Fixed paintable sign rendering
