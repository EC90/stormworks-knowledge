# V0.6.9-13

**V0.6.9-13** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 18th, 2019.

## V0.6.9

- Fix - Game saving on Mac now works correctly
- Fix - Reduced main save file size by 70% to reduce crashing during saving

- (Also note v0.6.9 changes are likely to fix many users issues when starting a new game or spawning a vehicle)

## V0.6.10-12

- Fix - saving and loading now works correctly on Windows and Mac

## V0.6.13

- Fix - Fixed microcontrollers showing in the vehicle load screen and not appearing in the component inventory
- Fix - Fixed occasional crash in vehicle editor since v0.6.8
- Fix - Fire missions now require the large pump to be unlocked to spawn
- Fix - Fixed tooltip missing from RGB indicator
