# V0.4.31

**V0.4.31** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on October 26th, 2018.

## V0.4.31

- Feature - 2 hats and 2 new clothing items equippable from 24th October until the end of Halloween on the 31st (witch hat, pumpkin hat, zombie clothes, skeleton clothes)
- Feature - Various spooky decorations on the creative island and starter island
- Feature - The NPCs appear to enjoy Halloween as well
- Feature - Added thrust spoiler logic input to jet engine exhausts (value from 0 to 1, 0 has no effect and 1 blocks all thrust)
- Feature - Added heavy large rotor component (larger variation of the heavy rotor)
- Feature - Added giant propeller component (smaller variation of the titan propeller)
- Feature - Fluid meter now outputs fluid amount in litres and has a second output to measure the total capacity of an enclosed volume
- Feature - Sharks can spawn in different size, from half the existing size to double

- Fix - Fixed docking doors not forming a seal when connected
- Fix - Fixed framerate drops with vehicles that have lots of propellers
- Fix - Fixed being able to interact with vehicle components when deceased
- Fix - Added blue rotation arrows to rotating jet exhaust to conform with other pivots
- Fix - Fixed not being able to interact with buttons/keypads when vehicles are moving at high speed
- Fix - Fixed taking damage/dying when fast travelling from a moving vehicle
- Fix - Fixed disappearing electrical connections when cutting/pasting with selection grid
- Fix - Fixed advanced vehicle difficulty setting not always being correctly saved
- Fix - Replaced selectors in character editor with drop-down lists for convenience
- Fix - Updated nuclear pool gantry to work with current waste barrels
- Fix - Reduced jet engine thrust to 60% to behave more realisticly on larger vehicles
- Fix - Fixed receiving no money rewards for missions in advanced mode
- Fix - Fluid other than water will pass through engine coolant systems instead of blocking them
- Fix - Fixed jet engines not producing exhaust particles when many are enabled
- Fix - Removed TAA antialiasing option
- Fix - Fixed detaching from ladder when crouched causing player to take damage when inside a 3x3 shaft
- Fix - Deprecated gearbox component and added new version with mesh facing the correct direction (existing vehicles will still have the old version but it is no longer accessible)
- Fix - Deprecated titan propeller
- Fix - Fixed pressure and flow of fluid nozzle not behaving correctly
- Fix - Fluid port no longer shows water particles when not dispensing fluids
- Fix - Fixed gearbox feedback loop when toggled on and off causing engines to increase their RPS uncontrollably
- Fix - Added extra surfaces to many components to make it easier to place them without needing to build scaffold/support blocks first
- Fix - Fixed missing labels for collapsible headings on properties window for HOTAS pilot seat
- Fix - Fixed being able to pump more water into a compartment than there was capacity for
- Fix - Filled compartments no longer drain slightly after closing doors in some cases
- Fix - Optimised tile loading to reduce stutter/delay when crossing tile boundaries
- Fix - Fixed player occasionally exiting the spawning screen before islands have finished loading
- Fix - Fixed player drowning whilst wearing diving gear with oxygen if breath meter had already been depleted
- Fix - Corrected typos in circuit breaker and relay descriptions
- Fix - Tail rotor visibly spins in correct direction
- Fix - Updated mesh for large propeller to look more consistent with the giant propeller
- Fix - Scaled fluid capacity of enclosed volumes to correctly match up with capacities of placeable fluid tanks
- Fix - Reduced electrical consumption of magall
- Fix - Fixed engine max power slider not working in normal mode
- Fix - Increased jet engine fuel consumption by x10 to make jet engine vehicles less overpowered
- Fix - Fixed incorrectly aligned mesh on medium battery component
- Fix - Fixed not being able to paint enclosed pipe pieces after placing them
- Fix - Camera resets to first person after dying and respawning
- Fix - Improved some components such as propellers being difficult to paint after being placed
