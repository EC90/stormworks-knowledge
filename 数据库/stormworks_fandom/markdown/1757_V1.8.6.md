# V1.8.6

**V1.8.6** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on August 4th, 2023.

## V1.8.6

- Feature - Gila Monster and Tortoises
- Fix - [#17064](https://geometa.co.uk/support/stormworks/17064) Aerodynamics surface processing issues causing unexpected behavior especially with small vehicles (missiles pitching up)
- Fix - [#17520](https://geometa.co.uk/support/stormworks/17520) Rocket launcher weapon now respects relative velocity when fired from a vehicle
- Fix - [#17771](https://geometa.co.uk/support/stormworks/17771) Fixed modular engine audio position and balance the effect radius
- Fix - [#18543](https://geometa.co.uk/support/stormworks/18543) Centred oil rig base workbench
- Fix - [#18946](https://geometa.co.uk/support/stormworks/18946) Fixed ocean_milani_explorer mission spawning inside physics (causing heavy lag in a specific area of the world)
- Fix - [#19418](https://geometa.co.uk/support/stormworks/19418) Structure workbenches ignoring fuel requirements when infinite_fuel is disabled
- Fix - [#19534](https://geometa.co.uk/support/stormworks/19534) Fixed LUA editor copy+paste for Mac
- Fix - [#19643](https://geometa.co.uk/support/stormworks/19643) Player names not cleared from the server list if kicked during server join
