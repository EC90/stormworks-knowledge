# V1.12.1

**V1.12.1** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on August 26th, 2024.

## V1.12.1

- Feature - [#24896](https://geometa.co.uk/support/stormworks/24896) DLC items are now marked in the component inventory
- Fix - [#2873](https://geometa.co.uk/support/stormworks/2873) Improved multiplayer rope sync
- Fix - [#25994](https://geometa.co.uk/support/stormworks/25994) Random bug where engines stopped transferring exhaust and blocked flow
- Fix - [#25338](https://geometa.co.uk/support/stormworks/25338) Corrected net drag effects
- Fix - [#25024](https://geometa.co.uk/support/stormworks/25024) Updated preset oil rig example
- Fix - [#25347](https://geometa.co.uk/support/stormworks/25347) Improved surface swimming behavior with ropes
- Fix - [#24891](https://geometa.co.uk/support/stormworks/24891) Fix map labels not showing on moon
- Fix - [#25254](https://geometa.co.uk/support/stormworks/25254) Fix clear oil spill crash and improved clearing
- Fix - [#25272](https://geometa.co.uk/support/stormworks/25272) Updated descriptions for breathing equipment/outfits to indicate oxygen must be piped into the inventory to refill them
- Fix - [#25598](https://geometa.co.uk/support/stormworks/25598) Updated onVehicleSpawn documentation to indicate that unloaded vehicles report the shared "group-origin" position
