A 'seat' which is intended to be used at the end of a winch so that it can be lowered from a hovering aircraft and then raised again. It has built-in configurable controls through six hotkey buttons. A typical setup is to use the harness to directly control the winch, so you can raise or lower the harness while being seated in it. Note that there is currently no way to automatically get passengers out of seats, so to rescue people with a helicopter and harness setup, you'll either need two harnesses (one for you, one for passengers), or you'll need to be playing in multiplayer with a friend so you can have one person on the ground and at least one person in the helicopter (assuming you've setup a good autopilot for hovering).
