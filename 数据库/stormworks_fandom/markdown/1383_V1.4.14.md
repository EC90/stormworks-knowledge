# V1.4.14

**V1.4.14** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 25th, 2022.

## V1.4.14

- Fix - [#6405](https://geometa.co.uk/support/stormworks/6405) [#6369](https://geometa.co.uk/support/stormworks/6369) Seats displaying wrong tooltips

- Feature - [#2885](https://geometa.co.uk/support/stormworks/2885) Multiple component paint colours
- Feature - [#5693](https://geometa.co.uk/support/stormworks/5693) Re-painted and optimized ai/mission vehicles

- Rework - [#2878](https://geometa.co.uk/support/stormworks/2878) Ammo drums now lose their ammo when exploding
- Rework - [#502](https://geometa.co.uk/support/stormworks/502) The chat window no longer shows up over other UI
- Rework - [#5514](https://geometa.co.uk/support/stormworks/5514) Fish no longer spawn under island meshes
- Rework - [#5257](https://geometa.co.uk/support/stormworks/5257) The tutorial will now end when moving away from the starter island
- Rework - Disabling vehicle damage now also disables engine overheat effects
- Rework - Passworded servers have been pushed to the bottom of the server list
- Rework - Servers now sort by network quality
- Fix - [#3472](https://geometa.co.uk/support/stormworks/3472) Clients not taking damage from explosions
- Fix - Fixed some code causing weather desync ([#4881](https://geometa.co.uk/support/stormworks/4881) [#5245](https://geometa.co.uk/support/stormworks/5245) [#6138](https://geometa.co.uk/support/stormworks/6138) [#6204](https://geometa.co.uk/support/stormworks/6204) [#6251](https://geometa.co.uk/support/stormworks/6251))
- Fix - [#4880](https://geometa.co.uk/support/stormworks/4880) Wind override slider inverting its value
- Fix - [#4795](https://geometa.co.uk/support/stormworks/4795) Gap in rail-line near O'neill base
- Fix - [#5480](https://geometa.co.uk/support/stormworks/5480) Disaster Sirens now take into account tsunami travel distance
- Fix - [#3087](https://geometa.co.uk/support/stormworks/3087) Lowered some dock mission zones for boats with origins below the waterline
- Fix - [#5818](https://geometa.co.uk/support/stormworks/5818) Players lose their hair when in the seat
- Fix - Buoyancy surfaces added to the air and liquid exchanger components
- Fix - UI focus not clearing in certain situations
- Fix - [#6495](https://geometa.co.uk/support/stormworks/6495) [#6471](https://geometa.co.uk/support/stormworks/6471) Fix Kraken data for saving/multiplayer
- Fix - Ping always displaying as 0ms in multiplayer

- New packet loss network graph has been added to the F1 menu

- Addon Lua:
- Feature - [#5307](https://geometa.co.uk/support/stormworks/5307) Added setWeather lua function
- Rework - [#715](https://geometa.co.uk/support/stormworks/715) onButtonPress() now returns the type of interaction (press/release)
- Fix - [#4588](https://geometa.co.uk/support/stormworks/4588) parented server.spawnFire only spawning at vehicle center
