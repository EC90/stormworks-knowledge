# V1.5.3

**V1.5.3** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on July 1st, 2022.

## V1.5.3

- Feature - [#2181](https://geometa.co.uk/support/stormworks/2181) Train Signals Addon

- The default train signals have now been converted to an addon, with an updated default signal. This conversion much like the other default playlists makes it very easy for players to replace with their own and upload to the workshop to share with the Stormworks community.
- Additionally, in this update we have reworked ropes and winches to fix several longstanding issues including crashes, freezes and unexpected rope based deaths.

- Fix - [#3360](https://geometa.co.uk/support/stormworks/3360) [#8720](https://geometa.co.uk/support/stormworks/8720) Winch lengths reverting to default length on vehicle load (sometimes crashing/freezing the game)
- Rework - Winches now auto spool back to their max length and winch max length no longer includes the attached rope's current dynamic length
- Rework - Slightly increased winch rope max lengths to compensate for the above change
- Rework - Players can no longer detach ropes that are longer than the first-person-rope maximum (40m)
- Fix - [#5016](https://geometa.co.uk/support/stormworks/5016) Held ropes no longer detach when a vehicle spawns

- Fix - Damage rendering desync issues for clients when loading vehicles
- Fix - [#8391](https://geometa.co.uk/support/stormworks/8391) Fixed Host voice chat not working
- Rework - [#4903](https://geometa.co.uk/support/stormworks/4903) [#9022](https://geometa.co.uk/support/stormworks/9022) Greatly improve multiplayer fire sync

- Rework - Rail signals now toggle their state client-side to improve sync
- Rework - Added size=null tags to certain default ocean path nodes to prevent bad paths generating under diagonal train bridges
- Rework - [#8185](https://geometa.co.uk/support/stormworks/8185) Updated workbench disabled messages to indicate if the setting is disabled or the client is unauthorized
- Balance - [#1829](https://geometa.co.uk/support/stormworks/1829) Rebalanced the repair speed of the handheld welding torches

- Fix - [#258](https://geometa.co.uk/support/stormworks/258) Vehicle editor undo not remembering sub-component colours
- Fix - [#7749](https://geometa.co.uk/support/stormworks/7749) [#8972](https://geometa.co.uk/support/stormworks/8972) Updated some default mission zones that were too close to terrain
- Fix - Path node tags are now correctly combined for overlapping nodes that get merged
- Fix - [#7737](https://geometa.co.uk/support/stormworks/7737) Flares black square graphical glitch
- Fix - [#8052](https://geometa.co.uk/support/stormworks/8052) Moon glare rendering issue
- Fix - [#8156](https://geometa.co.uk/support/stormworks/8156) Lightning intensity visual glitches
- Fix - [#8194](https://geometa.co.uk/support/stormworks/8194) Buttons no longer trigger the lua event when the player is out of interact range
- Fix - [#8394](https://geometa.co.uk/support/stormworks/8394) Updated logic node descriptions for coaxial rotors
- Fix - [#8419](https://geometa.co.uk/support/stormworks/8419) [#8689](https://geometa.co.uk/support/stormworks/8689) Fixed several issues around floating geometry
- Fix - [#8742](https://geometa.co.uk/support/stormworks/8742) Fixed Nataera ruins physics mesh height issue
- Fix - [#8716](https://geometa.co.uk/support/stormworks/8716) Passive sonar hits no longer have a projected y bounds of 5m
- Fix - [#8731](https://geometa.co.uk/support/stormworks/8731) Fixed turret ring mesh issues
- Fix - [#8781](https://geometa.co.uk/support/stormworks/8781) Fixed search light odd coloured mesh
- Fix - Fixed additive rendering as yellow in the component inventory
- Fix - Fixed train-line geometry at Terminal Trinite
- Fix - End effector no longer triggers onButtonPress when releasing for all dynamic components
