# V0.1.29

**V0.1.29** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 27, 2018.

## V0.1.29 (The Propeller Update)

- Feature - Added Titan Propeller - A tital class propeller for ships
- Feature - Added Heavy Rotor - A heavy duty rotor with thrust vectoring
- Feature - Updated existing rotors to have customisable number of blades. Blade count affects force applied with 4 blades providing the same force as before. This can be doubled by selecting 8 blades.
- Feature - [-] and [] can be used for zooming vehicle editor camera
- Feature - Handle holding is stronger and hold position has been raised
- Fix - Fixed lighting performance issues
- Fix - Fixes waves jumping when turning off weather override in creative menu
- Fix - Hinges now much stronger when geared
- Fix - Pumps no longer works without water input
- Fix - Water in sealed compartments no longer renders through vehicles
