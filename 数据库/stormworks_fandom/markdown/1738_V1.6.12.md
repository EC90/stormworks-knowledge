# V1.6.12

**V1.6.12** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 20th, 2023.

## V1.6.12

- Todays update features various bugfixes and quality improvements.

- Misc - [#3755](https://geometa.co.uk/support/stormworks/3755) Display a warning when spawning vehicles with large file sizes
- Fix - [#14986](https://geometa.co.uk/support/stormworks/14986) Replaced old benchmarks with a single new benchmark with updated AI vehicles
- Fix - [#14293](https://geometa.co.uk/support/stormworks/14293) Missile laser sensor erroneously culling data points
- Fix - [#14597](https://geometa.co.uk/support/stormworks/14597) Search filtering including filepath as vehicle name
- Fix - [#14677](https://geometa.co.uk/support/stormworks/14677) [#14784](https://geometa.co.uk/support/stormworks/14784) [#14751](https://geometa.co.uk/support/stormworks/14751) Improved editor arrows for steam train pistons to indicate orientation
- Fix - [#15079](https://geometa.co.uk/support/stormworks/15079) Audio playback rates for some sound effects differing from preview
- Fix - [#15769](https://geometa.co.uk/support/stormworks/15769) Render eyebrows in armor outfits
- Fix - [#15827](https://geometa.co.uk/support/stormworks/15827) Editor symmetry erase highlighting
- Fix - [#15817](https://geometa.co.uk/support/stormworks/15817) Addon editor issues with cyrillic/unicode filepaths
- Fix - [#14678](https://geometa.co.uk/support/stormworks/14678) Removed bottom voxels from train wheels and pistons to reduce collision issues
- Fix - [#8603](https://geometa.co.uk/support/stormworks/8603) Fix Magall light not updating for multiplayer clients
- Fix - [#15828](https://geometa.co.uk/support/stormworks/15828) Remove parented addon zones when their parent despawns
- Fix - [#15863](https://geometa.co.uk/support/stormworks/15863) Restock tooltips now show the correct item name
- Fix - [#16013](https://geometa.co.uk/support/stormworks/16013) Update Spycakes hangar resource storage placement
- Fix - [#16062](https://geometa.co.uk/support/stormworks/16062) Fix localization generation for files with missing xml nodes
- Fix - [#16075](https://geometa.co.uk/support/stormworks/16075) [#16983](https://geometa.co.uk/support/stormworks/16983) Fix mesh and physics issues at North Harbor
- Fix - [#16127](https://geometa.co.uk/support/stormworks/16127) Vehicle selection grid lists no longer reset scroll on open
- Fix - [#16178](https://geometa.co.uk/support/stormworks/16178) Fix creatures being spawnable without the DLC (and crashing)
- Fix - [#16186](https://geometa.co.uk/support/stormworks/16186) Fluid nozzle description update
- Fix - [#16258](https://geometa.co.uk/support/stormworks/16258) Fix physics mesh at Donkk Ruins
- Fix - Fix addons not rebuilding internal locations correctly on reload, fixed these cases in default missions and weapons dlc scripts
