# V1.4.11

**V1.4.11** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 11th, 2022.

## V1.4.11

- Controller support updates:
  - Character controller support
  - [#466](https://geometa.co.uk/support/stormworks/466) Vehicle controller support
  - Characters/Vehicles no longer move while in map/photo/creative menu
  - B button now acts as a generic back button for all UI screens
  - Creative menu day/night slider support
  - Research screen controller support
  - Photo-mode controller support
  - Sunrise-Sunset slider support
  - Back button keeps getting selected when scrolling a list
  - Pad input key-binds now work for UI navigation ([#6070](https://geometa.co.uk/support/stormworks/6070) [#6081](https://geometa.co.uk/support/stormworks/6081) [#6206](https://geometa.co.uk/support/stormworks/6206) [#6264](https://geometa.co.uk/support/stormworks/6264) [#6001](https://geometa.co.uk/support/stormworks/6001))
  - [#6000](https://geometa.co.uk/support/stormworks/6000) Rebinding menu can no longer be backed out of except with 'Esc'
  - Photo-mode hotkey tips now display their bound keys
  - Reset button now works correctly for bindings

- Rework - Iceberg tiles now have more room between bergs for ships
- Rework - [#1553](https://geometa.co.uk/support/stormworks/1553) Force non-combat AI vehicles to despawn if they sink
- Rework - [#5262](https://geometa.co.uk/support/stormworks/5262) Catalytic converter now converts exhaust to air rather than destroying exhaust

- Fix - [#5871](https://geometa.co.uk/support/stormworks/5871) Edge-case logic thread lockup caused by setVehiclePosSafe

- Fix - [#5441](https://geometa.co.uk/support/stormworks/5441) Crash on vehicle despawn while interacting
- Fix - [#5122](https://geometa.co.uk/support/stormworks/5122) Prevent vehicle fires when damage is toggled off, vehicle invulnerable flag is now checked for all damage systems
- Fix - [#4926](https://geometa.co.uk/support/stormworks/4926) Objects removed via lua now force an update to despawn them
- Fix - [#3615](https://geometa.co.uk/support/stormworks/3615) Make radar ignore trees
- Fix - [#2792](https://geometa.co.uk/support/stormworks/2792) Fix setVehiclePosSafe getting stuck when targeting an area between two vehicles (occasionally caused game lockup)
- Fix - [#793](https://geometa.co.uk/support/stormworks/793) [#728](https://geometa.co.uk/support/stormworks/728) Language workshop uploading disabled
- Fix - [#3924](https://geometa.co.uk/support/stormworks/3924) Added buoyancy surfaces to heat exchangers

- Fix - [#5254](https://geometa.co.uk/support/stormworks/5254) Missing collision mesh for filing cabinet
- Fix - [#5891](https://geometa.co.uk/support/stormworks/5891) Missing Face on Fluid Hose Anchor
- Fix - [#4981](https://geometa.co.uk/support/stormworks/4981) Floating tree cluster
- Fix - [#4940](https://geometa.co.uk/support/stormworks/4940) Foghorn model issues
- Fix - [#4930](https://geometa.co.uk/support/stormworks/4930) Mute sirens when damaged
- Fix - Short Tornadoes
