# V1.11.7

**V1.11.7** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on July 17th, 2024.

## V1.11.7

- Fix - [#25352](https://geometa.co.uk/support/stormworks/25352) Resolve microcontroller logic links sometimes disappearing on undo/redo
- Fix - Grounded network vehicle desync when teleporting off of a vehicle (characters vibrating)
- Fix - [#24400](https://geometa.co.uk/support/stormworks/24400) Resolved RCS thruster mirroring issues
- Fix - [#24489](https://geometa.co.uk/support/stormworks/24489) Corrected typos in large and huge tank wheels
- Fix - Space transport missions spawning at low difficulty
- Fix - Missions not respecting spawn biome
- Rework - [#24316](https://geometa.co.uk/support/stormworks/24316) Simplified Day/Night duration back to a single value
