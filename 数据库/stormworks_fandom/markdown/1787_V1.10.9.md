# V1.10.9

**V1.10.9** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 10th, 2024.

## V1.10.9

- Feature - [#21752](https://geometa.co.uk/support/stormworks/21752) Added air, oxygen and hydrogen spawning to fluid spawners
- Fix - [#24716](https://geometa.co.uk/support/stormworks/24716) Remove ctrl+s opening save menu from vehicle editor
- Fix - [#23301](https://geometa.co.uk/support/stormworks/23301) Fixed handheld gun inventory mesh issues
- Fix - [#23351](https://geometa.co.uk/support/stormworks/23351) Fixed throttle lever clicking noise when no power
- Fix - [#23657](https://geometa.co.uk/support/stormworks/23657) Fluid compartments default air is now spawned after resolving fluid spawners
- Fix - [#23419](https://geometa.co.uk/support/stormworks/23419) Initialize vehicle positions with their physics position before triggering lua load callbacks
- Fix - [#23548](https://geometa.co.uk/support/stormworks/23548) Fix setVehicleKeypad not working if input 1 is unchanged
- Fix - [#23432](https://geometa.co.uk/support/stormworks/23432) Remove cross from none type map label
- Fix - [#23432](https://geometa.co.uk/support/stormworks/23432) Fix handling of tile marker icons for deletion
- Fix - [#23432](https://geometa.co.uk/support/stormworks/23432) Remove all map labels with the target map_id
- Fix - [#23418](https://geometa.co.uk/support/stormworks/23418) Retain capitalization for notification titles
- Rework - [#23416](https://geometa.co.uk/support/stormworks/23416) Prevent notifications of different types stacking
