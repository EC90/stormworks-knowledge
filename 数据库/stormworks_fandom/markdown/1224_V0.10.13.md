# V0.10.13

**V0.10.13** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on April 9th, 2020.

## V0.10.13

- Feature - Emergency Beacon and Emergency Beacon Locator
- Feature - Added a help message for admins when un-authed player joins the game

- Fix - Added missing composite node to Harness
- Fix - Rope audio playing at full extension / retraction
- Fix - Cost of medium winch
- Fix - Time desync for mission and research display timers
- Fix - +connect command line parameter not working
- Fix - Added further protection from chat + mission object crashes
