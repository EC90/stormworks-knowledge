# V1.8.3

**V1.8.3** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on July 7th, 2023.

## V1.8.3

- Feature - Arid Island Predators

- Crocodile
- Mountain Lion
- Coyote

- Arid camp rescue missions can now spawn with a Mountain Lion

- Rework - Stormworks crashes now have a submit crash dialog box
- Rework - [#19184](https://geometa.co.uk/support/stormworks/19184) Always display component costs in editor

- Fix - Random small oil patch rendering artefacts
- Fix - Old save compatibility with new oil spill missions
- Fix - Oil spill message spam on new spill

- Fix - [#17818](https://geometa.co.uk/support/stormworks/17818) Crash when calling setAudioMood with invalid moods
- Fix - [#18936](https://geometa.co.uk/support/stormworks/18936) Bullet casing direction for mirrored guns
- Fix - [#19188](https://geometa.co.uk/support/stormworks/19188) Removed outdated logic popups for power and fluids
- Fix - [#19232](https://geometa.co.uk/support/stormworks/19232) Fix vehicle thumbnails in save/delete confirm view
- Fix - [#19300](https://geometa.co.uk/support/stormworks/19300) Updated pivoting and gimbal part descriptions to use turns
- Fix - [#19393](https://geometa.co.uk/support/stormworks/19393) Removed invisible post physics at rail crossing

We have also added a link to the Geometa merchandise page to the game's main menu
