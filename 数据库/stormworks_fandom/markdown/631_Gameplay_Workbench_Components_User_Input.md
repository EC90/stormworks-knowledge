## User Input

Throttle Lever

[![Throttle Lever](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/3/3e/Throttle_Lever.jpg/revision/latest/scale-to-width-down/100?cb=20190317011401)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/3/3e/Throttle_Lever.jpg/revision/latest?cb=20190317011401)

- Output 1 (Number): the value of the lever
- You can define the maximum and minimum value

Push Button

[![Button Push](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/9/98/Button_Push.jpg/revision/latest/scale-to-width-down/100?cb=20190317011311)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/9/98/Button_Push.jpg/revision/latest?cb=20190317011311)

- Output 1 (On/Off): if pushed

Push Button (2 Sided)

[![Button Push 2 Sided](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/4/4f/Button_Push_2_Sided.jpg/revision/latest?cb=20190317011304)

- Output 1 (On/Off): if pushed
- can be pushed from both sides of the block

Toggle Button

[![Button Toggle](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/1/14/Button_Toggle.jpg/revision/latest?cb=20190317011322)

- Output 1 (On/Off): if activated

Toggle Button (2 Sided)

[![Button Toggle 2 Sided](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/7/70/Button_Toggle_2_Sided.jpg/revision/latest?cb=20190317011316)

- Output 1 (On/Off): if activated
- can be toggled from both sides of the block

Lockable Button

[![Button Lockable](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/c/c7/Button_Lockable.jpg/revision/latest?cb=20190317011258)

- Output 1 (On/Off): if activated
- Input 1 (On/Off): if button is unlocked and the player can interact with it

Key Button

[![Button Key](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/1/19/Button_Key.jpg/revision/latest?cb=20190317011250)

- Output 1 (On/Off): if activated
- Works like a toggle button but you can define a time needed to activate it (e.g. hold 2 seconds to activate)

Keypad Small

[![Keypad Small](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/c/c5/Keypad_Small.jpg/revision/latest?cb=20190317011342)

- Output 1 (Number): the value inserted into the keypad

Keypad Large

[![Keypad Large](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/e/e8/Keypad_Large.jpg/revision/latest?cb=20190317011337)

- Output 1 (Number): the first value inserted into the keypad
- Output 2 (Number): the second value inserted into the keypad

Helm

[![Helm](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/c/c8/Helm.jpg/revision/latest?cb=20190317011331)

- Output 1 (Number): the rotation (from -1=left to +1=right)

Pilot Seat

[![Pilot Seat](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/a/af/Pilot_Seat.jpg/revision/latest?cb=20190317011355)

- Output 1 (Number): a/d
- Output 2 (Number): w/s
- Output 3 (Number): left/right
- Output 4 (Number): up/down
- Output 1 (On/Off): if 1 is pressed
- Output 2 (On/Off): if 2 is pressed
- Output 3 (On/Off): if 3 is pressed
- Output 4 (On/Off): if 4 is pressed
- Output 5 (On/Off): if 5 is pressed
- Output 6 (On/Off): if 6 is pressed
- Output 31 (On/Off): if trigger is pressed
- Output 32 (On/Off): if occupied

- there is also a composite output which sends even more values, but all combined into one composite

Modes:

- Reset: When e.g. w is pressed the value will rise from 0 to 1, once w is released the value will decrease until 0. The opposite with s: it decreases from 0 to -1

Instrument Panel

[![Instrument Panel](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/8/83/Instrument_Panel.jpg/revision/latest?cb=20190317005222)

- Uses composite inputs and outputs with configurable channels from 1-32.
- Composite inputs: A combination of up to four numeric or boolean inputs to dials, gauges, indicators, seven-segment displays, and/or radial/bar segment displays.
- Composite output: A combination of up to four outputs from buttons and switches.
- **Daisy chaining:** Instrument panels can be linked together into a chain so your microcontrollers only need one composite input and output for multiple instrument panels.
  - **Note:** You can't use multiple buttons/switches on the same channels on different panels - if the same channel is used, then only the last panels' button/switch state will control the output.
