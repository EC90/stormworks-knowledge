# V1.7.8

**V1.7.8** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on June 9th, 2023.

## V1.7.8

- Feature - Arid Island Herbivores

- Greater Roadrunner
- Bighorn Sheep
- Buffalo

- Rework - Improved anti-cheat support
- Fix - [#17851](https://geometa.co.uk/support/stormworks/17851) Align medium tank tracks to their wheels
- Fix - [#17938](https://geometa.co.uk/support/stormworks/17938) Slow doors on creative island
- Fix - [#18104](https://geometa.co.uk/support/stormworks/18104) Monitors turning off when not looking directly at them
- Fix - [#18112](https://geometa.co.uk/support/stormworks/18112) Fix controller losing focus in UI after binding ui navigation button to an action
- Fix - [#18345](https://geometa.co.uk/support/stormworks/18345) setVehiclePosSafe now returns result position even on failure (fixed ai aircraft script error)
- Fix - [#18401](https://geometa.co.uk/support/stormworks/18401) Added loot crates for arid and underwater islands
- Fix - [#18567](https://geometa.co.uk/support/stormworks/18567) Mesh issue on the top of the Oil rig pumpjack
- Fix - [#19690](https://geometa.co.uk/support/stormworks/19690) Hose int affecting rope length
- Fix - [#19692](https://geometa.co.uk/support/stormworks/19692) Stopped clearing attach states for characters or creatures attempting to reattach to their current seat
