## Standards

The Standards are finished so far, the first vehicles on the workshop are already being labeled/certified!

### Introduction

Some players came together to define standards for different types of vehicles. The goal is simply to keep workshop items compatible. Some vehicle types do not have any standards or defining standards is just not useful.

### Structure of standards

A Vehicle can meet multiple standards. A standard can be for a generic type (e.g. Air vehicle) or a more specific type (e.g. Helicopter). Each Standard has a version to help keep standards up to date, and to allow for future changes. Each standard can have additional and optional information like *features* and *size*. If you want to add these to your standard badge you must meet the specified rules. Typically the size is combined with one feature. Features vary from type to type but there are [global features](https://stormworks.fandom.com/wiki/Wiki/Standards/Features) that every vehicle can have.

### Labels/Badges

Every Standard has a little badge/label: [![Example Badge](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/4/4e/Standards_Example_Badge.jpeg/revision/latest?cb=20190519171112)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/4/4e/Standards_Example_Badge.jpeg/revision/latest?cb=20190519171112)

This badge is an image that can be added to the steam workshop page of your vehicle. It will link to a webpage showing all the standards/rules that your vehicle fulfills. You can also include the Standard into the creations name. Example:

[LT1 t XL] Huge American Truck

The example badge would link to [https://sws.flaffipony.rocks/check?s=LT1%20t%20XL](https://sws.flaffipony.rocks/check?s=LT1%20t%20XL)
