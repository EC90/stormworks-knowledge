# Gameplay/Workbench/Advanced Mode

## Advanced Mode

The "Advanced Mode" Used to be in the game as an alternative to the "[Normal](https://stormworks.fandom.com/wiki/Wiki/Building/Normal_Mode) Mode", which was a simpler mode to build in, with no pipes and many things removed. (For example: Pipes for Air, Exhaust, Coolant, or connecting electricity, etc.).

Today, the "Advanced Mode" is the Default building mode, and "Normal Mode" is no longer an option.
