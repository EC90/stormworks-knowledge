# V0.6.15

**V0.6.15** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 29th, 2019.

## V0.6.15

- Feature - 8 new wheel components with improved physics (4 with built-in suspension, 4 without)
  - - Suspension versions have tunable stiffness and damping
  - - Tunable grip on all new wheels
  - - 3 different tyre tread options that affect grip in the arctic biome
  - - Tire radius can be customised to match most vehicle sizes

- Fix - Despawned player vehicles remain on the map and can be returned to the workbench
- Fix - Unloaded vehicles are still visible on the map in multiplayer
- Fix - Water particles no longer render in doorways when no water is being transferred between compartments
- Fix - Fixed rotor blade rotation not matching up with how they appear in the vehicle editor when spawned with vehicle damage enabled
- Fix - Other players show on the map for multiplayer host
- Fix - Player map icon uses player location instead of camera location
- Fix - Fixed microcontroller memory gate not respecting reset value after returning to workbench
- Fix - Instrument panel buttons are no longer pushable without electric in advanced mode
- Fix - Fixed graphics settings not saving/loading on MacOS
- Fix - Fixed not being able to drag hotbar items between slots in the microcontroller editor
- Fix - Gyro no longer requires 50% power to work in advanced mode
- Fix - Fixed jet engine turbines not generating electricity
