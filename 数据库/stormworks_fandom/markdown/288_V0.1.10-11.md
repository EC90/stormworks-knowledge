# V0.1.10-11

**V0.1.10-11** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on March 8, 2018.

## v0.1.11

- Fix - multiplayer symbols no longer show up all over map
- Fix - game performance issue resolved
- Fix - wind turbine lift now operates correctly
- Fix - correct keybindings now show on handle interaction labels

## v0.1.10

- Fix - movement issue in singleplayer
- Fix - multiplayer characters now render with correct clothes
- Fix - character look direction works correctly in 3rd person mode
- Fix - multiplayer character animation state improvements
- Fix - multiplayer crash when spawning character
- Fix - resolved character position issue when in seat or on ladder
- Fix - version showing correctly in MacOS
