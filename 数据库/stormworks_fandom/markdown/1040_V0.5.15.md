# V0.5.15

**V0.5.15** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 15th, 2019.

## V0.5.15

- Fix - Disabled spotlight volumes for all AMD graphics as well as Vega
- Fix - Close cmd.exe after cleaning backup files
- Fix - Fixed game not restoring fullscreen state properly when relaunching
- Fix - Fixed sending chat messages in multiplayer causing creative menu to be opened
