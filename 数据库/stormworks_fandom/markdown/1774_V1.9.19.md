# V1.9.19

**V1.9.19** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on December 8th, 2023.

## V1.9.19

- Feature - End effectors now cut ropes ([#19287](https://geometa.co.uk/support/stormworks/19287) [#18207](https://geometa.co.uk/support/stormworks/18207) [#12104](https://geometa.co.uk/support/stormworks/12104))
- Feature - [#6069](https://geometa.co.uk/support/stormworks/6069) Changed grass to snow for Xmas
- Balance - Updated heat rate based on volume for heaters inside compartments
- Rework - Identical notifications now stack
- Fix - Debuff icon rendering stacking
- Fix - Map center revealing on game start
- Fix - [#21808](https://geometa.co.uk/support/stormworks/21808) Fluid cannon pressure issues
- Fix - [#21628](https://geometa.co.uk/support/stormworks/21628) Fluid hoses clogging
- Fix - [#22878](https://geometa.co.uk/support/stormworks/22878) Fixed server side workbench interaction for static vehicles
- Fix - [#22856](https://geometa.co.uk/support/stormworks/22856) [#23334](https://geometa.co.uk/support/stormworks/23334) Fixed static behaviour for addon spawned groups
- Fix - [#21872](https://geometa.co.uk/support/stormworks/21872) Jet engine turbojets applying force in space
- Fix - [#22811](https://geometa.co.uk/support/stormworks/22811) Steam pistons now base their power on steam pressure instead of volume
