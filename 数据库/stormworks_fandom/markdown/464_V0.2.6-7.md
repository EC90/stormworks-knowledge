# V0.2.6-7

**V0.2.6-7** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* were released on May 18, 2018.

## v0.2.7

- Feature - Mission spawn menu is now available in multiplayer
- Feature - Improved stability for large vehicles in multiplayer
- Feature - New component - paintable sign (small 10x10 grid on one face for detailed painting)
- Feature - Added additive paint tool for painting additive layer of paintable sign
- Feature - Mission vehicles can now be set as static from their properties window (static vehicles are fixed in place, such as cranes or buildings)
- Feature - Creator of mission vehicle shows on map when hovering a loaded vehicle
- Feature - Added button in mission editor for parenting selected zone/fire to a vehicle
- Feature - Can now set objective dependencies in mission editor (an objective will be inactive/hidden until its dependencies are complete allowing for multi-part missions and branching missions)
- Feature - Added sliders to mission editor for setting preferred environmental parameters
- Feature - Added difficulty selector to set recommended difficulty level of edited mission
- Feature - Added some validation when uploading missions to the workshop
- Feature - Missions spawn in the world when their environmental parameters are met, allowing the creation of more atmospheric missions
- Feature - Loot boxes found in the world now generate multiple rewards similar to mission rewards
- Feature - Rebalanced fire (fires take less time to extinguish, can reignite if surrounded by other fires, can slowly burn out naturally when small enough)
- Fix - Missions spawn correctly in multiplayer
- Fix - Connectors now work properly in multiplayer
- Fix - Improved handle desync in multiplayer
- Fix - Fixed graphical artifacts in multiplayer when far from spawn
- Fix - Fire missions now show markers on fires
- Fix - Fixed being able to shift-place vehicles in mission editor
- Fix - Missions that require fire equipment only spawn when equipment has been unlocked
- Fix - Mission rewards always generate with at least 1 money rewards
- Fix - Fixed mission editor crash when setting component dependency after deleting component
- Fix - Fixed several small issues with some missions
- Fix - General physics stability improvements
- Fix - Fixed crash when overwriting vehicle file
- Fix - Survivors no longer need to stop following you to complete missions
- Fix - Fixed water components not working correctly when mirrored
- Fix - Fixed linear speed sensor giving incorrect reading when flipped

## v0.2.6

- Feature - added bridge and crane to oil refinery island
- Fix - drag-deleting multibody parts no longer causes crash
- Fix - anti-piracy detection no longer creates false positive detections
- Fix - nuclear waste mission fixes
- Fix - updated truck and container in mud pump mission to work better
