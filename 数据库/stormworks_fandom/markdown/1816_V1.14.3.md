# V1.14.3

**V1.14.3** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on May 7th, 2025.

## V1.14.3

- Feature - Firefighter SCBA Outfit
- Feature - [#19848](https://geometa.co.uk/support/stormworks/19848) [#16936](https://geometa.co.uk/support/stormworks/16936) Train wheels release from track logic node
- Feature - [#25605](https://geometa.co.uk/support/stormworks/25605) The majority of the small/medium non-hostile creatures can now be carried
- Feature - New Trailer preset
- Feature - Added fire missions for new game locations

- Fix - [#26800](https://geometa.co.uk/support/stormworks/26800) Updated naming convention for missile laser logic nodes
- Fix - [#26984](https://geometa.co.uk/support/stormworks/26984) Warning light mesh issues
- Fix - [#26993](https://geometa.co.uk/support/stormworks/26993) Electrical cable anchor missing warning
- Fix - [#27020](https://geometa.co.uk/support/stormworks/27020) Large warhead voxel asymmetry
- Fix - [#27083](https://geometa.co.uk/support/stormworks/27083) Resolve translations not rebuilding on language change
- Fix - [#27083](https://geometa.co.uk/support/stormworks/27083) Resolve item inventory tooltips not localized
- Fix - [#27086](https://geometa.co.uk/support/stormworks/27086) Addon lua docs minor fixes
- Fix - Default fire mission, bollard and signal fixes
