## Dedicated Server

Choose the guide depending on

- your setup (pc with screen / server without screen / command line only)
- your prefered installation method (manual / automatic)

## Pro's and Con's

**Automatic (SteamCMD & condenser)**

+ works with command line access (no screen or Remote Desktop Connection) + Install server in < 5 minutes + 4 scripts included (install, update, start, stop) + uses steamcmd (does not affect the normal steam client, does not need a steam account) - security settings are being changed to allow the powershell scripts to run - fixed installation path ("C:/steacmd" and "C:/condenser")

**Manual (SteamCMD)**

+ works with command line access (no screen or Remote Desktop Connection) + uses steamcmd (does not affect the normal steam client, does not need a steam account) + you have full control over the installation process - you must install SteamCMD manually - you must install/update/start/stop the Stormworks Dedicated Server manually

**Manual (Normal Steam Client)**

+ automatic installation and updates by Steam - you must start/stop the Stormworks Dedicated Server manually - does affect the normal steam client (it shows you playing Stormworks Dedicated Server, ...)

## Manual (Normal Steam Client)

- Install Steam Client and login
- in your bibliothecary search for "Stormworks" and enable the filter "Tools"
- you should see the "Stormworks Dedicated Server" Tool
- install it
- after installation you can go to the installation folder (right click the game -> properties -> location on disk)
- now you can follow Beginner's guide on steam, start at the section "Server Configuration"
- [https://steamcommunity.com/sharedfiles/filedetails/?id=1995371855](https://steamcommunity.com/sharedfiles/filedetails/?id=1995371855)
