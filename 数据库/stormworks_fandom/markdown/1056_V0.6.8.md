# V0.6.8

**V0.6.8** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on March 15th, 2019.

## V0.6.8

- Feature - Added Instrument Panel component (compact set of dials and buttons that can be controlled using microcontroller composite logic). Includes dial, gauge, 6 button types, 2 types of seven segment display.

- Fix - Fixed issue with saving for players using Wine
- Fix - Fixed some rail junction switches not working
- Fix - Jet engine no longer functions when missing air intake
- Fix - Increased force produced by jet engines by 2x
- Fix - Jet engine turbine generates electric
- Fix - Increased electric consumption of starter motors by 2.5x to resolve perpetual energy generation
- Fix - Fixed ocean spray particles rendering inside vehicles
- Fix - Fixed ocean foam being visible inside vehicle at some angles
- Fix - Minor changes to mission text for clarity
- Fix - Fixed crash in mission editor when deleting a location that hasn't been edited
- Fix - Mission component properties panel is now visible by default
- Fix - Fixed invisible physics on straight trainline piece that was causing damage to trains
- Fix - Improved access to rail junction signals on some islands
- Fix - Fixed doubled physics causing wheels to behave strangely on military base
