# V1.6.14

**V1.6.14** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on February 17th, 2023.

## V1.6.14

- Feature - Physics Sensor ([#10065](https://geometa.co.uk/support/stormworks/10065) [#10119](https://geometa.co.uk/support/stormworks/10119) [#3793](https://geometa.co.uk/support/stormworks/3793) [#4465](https://geometa.co.uk/support/stormworks/4465))

The physics sensor component combines functionality of several other sensors into a convenient single block. The sensor outputs position, rotation, linear and angular speeds over 14 composite channels detailed on the component.

- Fix - [#16642](https://geometa.co.uk/support/stormworks/16642) Wheel secondary physics issues for clients
- Fix - [#17831](https://geometa.co.uk/support/stormworks/17831) Seafloor generation issue
- Fix - [#15856](https://geometa.co.uk/support/stormworks/15856) No longer convert rescued survivors to static NPCs, instead update their display name to 'Rescued'
- Fix - [#13931](https://geometa.co.uk/support/stormworks/13931) Ai boats/aircraft now track damage and despawn after 2 mins if above threshold
- Fix - [#13936](https://geometa.co.uk/support/stormworks/13936) Return value of getZones not including Zone parent vehicle data
- Fix - [#14017](https://geometa.co.uk/support/stormworks/14017) Added editor arrows for wings
- Fix - [#14835](https://geometa.co.uk/support/stormworks/14835) Fixed teleporting under the map through very tall terrain
- Fix - [#13078](https://geometa.co.uk/support/stormworks/13078) Rotor physics mirroring issues
- Fix - [#14848](https://geometa.co.uk/support/stormworks/14848) Metal ore foundry mesh issues
- Fix - [#14851](https://geometa.co.uk/support/stormworks/14851) Gold foundry mesh issues

Addon Lua:

- Added setCharacterTooltip and setCreatureTooltip for renaming non-player Characters and Animals
