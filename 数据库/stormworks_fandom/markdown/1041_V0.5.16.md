# V0.5.16

**V0.5.16** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on January 18th, 2019.

## V0.5.16

- Feature - Added Fluid Jet component (water jet that produces thrust and has thrust vectoring)
- Feature - Added Fluid Slot Port component (a larger fluid port that produces a slight downforce on the ocean surface)
- Feature - Improved keybinding support for mice with more than 3 buttons

- Fix - Jet exhaust light fades away as temperature decreases when switched off
- Fix - Ctrl-S hotkey no longer interrupts free mode camera movement in vehicle editor
- Fix - Saving and loading the game whilst grabbed by a shark will no longer cause shark to never let go
- Fix - Fixed painting additive layer on mirrored paintable signs
- Fix - Fixed additive on mirrored throttle levers not rendering properly
- Fix - Updated creative island crane with some minor fixes and improvements, courtesy of XFury and Gardiner
- Fix - Fixed "7" on digital display missing part of additive
