# V1.12.8

**V1.12.8** of *[Stormworks: Build and Rescue](https://stormworks.fandom.com/wiki/Stormworks:_Build_and_Rescue)* was released on November 6th, 2024.

## V1.12.8

- Feature - [#23813](https://geometa.co.uk/support/stormworks/23813) Fluid and Electric Pulley components
- Feature - [#6373](https://geometa.co.uk/support/stormworks/6373) Racing Clothing items
- Fix - [#8341](https://geometa.co.uk/support/stormworks/8341) Host now has authority over mic/speaker is_transmit state
- Fix - [#25117](https://geometa.co.uk/support/stormworks/25117) Fluid jet mirrored animation issues
- Fix - [#25943](https://geometa.co.uk/support/stormworks/25943) Limit maximum fluid cannon force
- Fix - Winches now check rope type is valid for a proposed connection
- Rework - [#25844](https://geometa.co.uk/support/stormworks/25844) Removed rope mass scaling, added rope tension impulses
