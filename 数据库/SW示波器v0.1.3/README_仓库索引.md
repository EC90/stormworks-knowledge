# SW 示波器（外部工具）· 仓库索引

> 本目录只保留**可文本检索的部分**；第三方二进制不入库（2026-09-08 仓库瘦身）。

## 这是什么

社区作者制作的 Stormworks 信号示波器工具（v0.1.3，文件时间 2023-06-30，中文界面），
配合游戏内微控把混合信号以 60 tick/s 记录成 CSV，并可实时渲染近 300 tick 波形。
本工作区用它完成了模块化引擎 18 轮实测（经验已固化为技能 `sw-modular-engine-bench`）。
