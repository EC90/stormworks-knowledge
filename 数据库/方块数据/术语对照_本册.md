## 六、汉化陷阱汇总（引用前必读）

| # | 陷阱 | 正确做法 |
|---|---|---|
| 1 | `Fluid Tank` 被统一译为「油箱」 | 它其实是**通用流体箱**，可装水/柴油/任意流体。气体专用的是 `Gas Tank`=气罐。写文档时按需加注 |
| 2 | `Rotor` 有两种汉化 | 直升机旋翼类 → **螺旋桨**（大/巨型/重型）；共轴旋翼类 → **旋翼**（小/中/大/轻）。`Rotor (Tail)` = **尾桨** |
| 3 | `Fluid Heat Sink` 与 `Fluid Heat Radiator` 都译「流体散热器」 | 引用时**必须带英文名** |
| 4 | `Composite` 译法不统一 | 对照表：`Composite`=混合、`Composite Data`=综合数据；节点描述里多为「复合」。本册统一用**复合** |
| 5 | wiki 名与游戏内名**词序相反** | 例：`Motor Small`（wiki）↔ `Small Electric Motor`（游戏）。**查表一律用游戏内名** |
| 6 | 窗户命名 **wiki 用 W×H，游戏用 H×W** | 例：wiki `Window 2x1` = 游戏 `Window 1x2` = 窗(2x1) |
| 7 | `Harness` 译「安全带」 | wiki 描述为「可固定一个人、可挂绞车」，与座椅安全带同词，需靠上下文区分 |
| 8 | ✅ **已结案** wiki 声纳射程写作 **km**（60/100/200） | 这三个数值出自**游戏内 s_desc 原文**，不是 wiki 笔误。⚠ 但数值远超地图尺度，有效距离仍须实测。注意**旧版声纳只有 3000 m** |
| 9 | wiki 把三种声纳**都写成 `Smal Sonar`** | 按图片文件名应为 Small / Medium / Large |
| 10 | wiki 把 `Pipe Angle Corner` 与 `Pipe T-Piece Corner` **都写成 `Pipe T-Pice Corner`**（且拼错） | 以对照表区分：3向 / 4向 |
| 11 | `Artillery Cannon` 有**两套译名** | 通用词条命中「榴弹炮」，但**部件名**（`def_gun_xl_name`）是「**大型**榴弹炮」，其弹带也全叫「大型榴弹炮…」。本册统一用**部件名** |
| 12 | `Warhead` 与 `Warhead Body` **都译「弹头」** | 引用时**必须带英文名**。据 id 推断 Body 是惰性弹体、Warhead 是可起爆整弹（此推断未见于 wiki，需实测） |
| 13 | `Feeder` 两套译名 | 自动火炮 → **进料器**；三种重炮 → **供弹机**。同一功能不同译名，按炮种取 |
| 14 | `Chest Rig` / `Plate Vest` / `Black Hawk Vest` 两套译名 | 「战术胸挂 / 战术背心 / 黑鹰背心」vs 部件名「胸挂 / 插板胸挂 / 黑鹰防弹背心」。本册用**部件名** |
| 15 | 汉化补丁错字：`火旱枪`、`水下火旱枪` | 应为「焊枪 / 水下焊枪」。照录未改，检索时用错字才能命中 |
| 16 | wiki 写 `Flare Gun`，对照表是连写的 `Flaregun` | 查表用 **`Flaregun`** = 信号弹枪 |
| 17 | **日文 wiki 的中文名 ≠ 游戏内中文名** | 日文 wiki 用日文汉字（物理センサー／液量計／風向風速計…），**不可直接当中文用**。中文一律回查对照表。典型：`Physics Sensor` = **多功能物理传感器**（不是「物理传感器」） |
| 18 | **日文 wiki 的节点名是旧称** | 云台摄像机在日文 wiki 写 `Rotation Pivot`/`Rotation Pitch`，**游戏内实为 `Pivot Rotation`/`Pitch Rotation`** = 航向控制／俯仰控制 |
| 19 | `Wavelength` 译「**激光编码**」 | 不是「波长」。发射端与接收端须设**相同整数编码**才能配对 |
| 20 | **`Radar (Dish)` 新旧同名中文不同** | 旧 = **雷达(盘)**，新 = **雷达(抛物面天线)**。必须带「旧/新」限定词引用 |
| 21 | **`Fluid Capacity` 两个译名** | 液位测量仪上 = **总容量**；气体测量仪上 = **气体容量**。按部件取，不可混用 |
| 22 | 新旧雷达 Radar Data **通道顺序不同** | 旧「雷达(巨)」= 距离·信号强度·仰角·方位角；**新版 = 距离·方位角·仰角·时间**。写解算器前先确认是哪一代 |
| 23 | 同为 `Pivot Rotation`，两种云台译名不同 | 摄像头云台 = **航向控制**；自稳定云台 = **旋转控制**。同为 `Camera Feed`：前者=**摄像头输出**，后者=**视频输出** |
| 24 | `Pressure Sensor` 与 `Contact Sensor` 错位 | 对照表 `def_pressure_sensor_name` 的英文名是 **Contact Sensor**，中文却是「**压力传感器**」。引用时**必须带英文名** |
