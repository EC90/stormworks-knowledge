## 19.3 工作原理

- **推力来源**：喷口后方产生推力，**正比于引擎内部 RPS**（不是直接正比于油门）。
- **点火条件**：燃烧室**内部压力足够高时**才开始燃烧（需压气机先建立压力）。
- **加力（Afterburner）**：开启后追加推力、耗油增加，但**对最高速度几乎无帮助**，主要提升加速前~中段。
- **旋转喷口**：`Rotation Target` 取 **-0.5~0.5（圈/turn）** 设定推力方向——与 `03_机械.md` §3.3 枢轴角度约定一致（**圈非度**）。

## 19.4 与其他册的关联

- 角度单位「圈/turn」：见 `03_机械.md` §3.3（定点朝向型 -0.25~0.25、连续旋转型 0~∞）。
- 模块化引擎进气:进油 = **2:1** 的约定是柴油模块化引擎的；喷气引擎烧**喷气燃料（Jet Fuel）**，走 `Fuel` 连接、由 `Throttle` 控制。
- 推力/动力整合进载具：涡轮可经 `RPS`（扭力）驱动螺旋桨/旋翼，或经 `Electric` 发电。

## 19.5 选型速查

| 需求 | 用哪个 |
|---|---|
| 模块化喷气引擎基础推力 | 进气口 + 压气机 + 燃烧室 + 涡轮 + 喷口(基础型) |
| 额外推力 / 高速机动 | 大进气口（带涡轮风扇） |
| 转向/延展管路 | 气道(直/L/T/十字/斜) |
| 加速前中段增益 | 加力喷口（注意极速增益极小） |
| 矢量推力 | 旋转喷口（Rotation Target -0.5~0.5 圈） |
| 取电 / 驱动其他部件 | 喷气涡轮（Electric 发电 / RPS 扭力输出） |
