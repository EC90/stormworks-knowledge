# 10 无线电

**本节回答**：① 天线有哪几档、射程与功耗；② 频段规则与游戏内置频道；③ 传输距离怎么算；
④ 定向天线怎么用；⑤ 龙门吊控制频道。
源页面：`Gameplay/Workbench/Components/Radio`（修订 4716，标注 **V1.15.2**）。

**总览**：无线电让载具与人员共享**数字、布尔、音频、视频**数据。
信号强度受**距离**和**电量耗尽**影响而变差，用**更大的天线**可以改善（同时提高最大射程）。
信号差时音频会加静电、视频会有颗粒/雪花，**但数字与布尔数据在到达最大射程前都是可靠的**
（最大射程同时受发射端和接收端影响）。

**无线电也是操作火车道岔的必要条件。**

## 10.1 频段规则

可用频段**可以是任意数**，但有边界：

- **只能用整数**；带小数点的会四舍五入到最近整数
  （0.5 及以上进位到 1，0.5 以下舍到 0）。
- 大于 **16,777,216** 的数字可能与邻近数字重叠。
- 游戏内数字精度限制在 **±2²⁴**；超出范围的数字会被转换成邻近值，
  因此**保证频道不重叠的安全区间是 ±16,777,216**。
- **可以用负数**，且负数与正数**互不相同**（-1 不会与 1 通信，反之亦然）。

### 龙门吊频道（Gantry cranes）

龙门吊用于买卖**鱼、石油、燃料**，控制方式相同：
- **布尔通道 1**：发送 On 信号 → 切换泵/真空机开关（买或卖）。
- **数字通道 1**：左右移动吊车，取值 **-1 ~ +1**
  （站在泵后面时 -1 向左，站在水里面向泵时 -1 向右）。
  ⚠ **只有绝对值 > 0.8 才有效果。**
- **数字通道 2**：上下移动（**1 = 上升**）。同样只有 |值| > 0.8 才生效。

## 10.3 逻辑与用法

### Radio RX 天线（收发数字 / 布尔 / 音频）

每根天线**在发射与接收之间二选一**，由发射模式决定。

| 节点 | 方向 | 说明 |
|---|---|---|
| **Transmit mode** | 布尔输入 | **关（或未连接）**= 监听模式，可接收；**开** = 发射模式，可发送但**不能**接收 |
| **Frequency** | 数字输入 | 频率值，见 10.1 的频段规则 |
| **Signal strength** | 数字输出 | **0~1**；无信号时为 0。**小型天线没有这个节点。**<br>可用于**扫描枪自动检测有数据传输的频道**并**三角定位发射源**。通过分析频道内各数据通道可以辨别数据类型；把一个麦克风接到天线上也能判断是否有音频传输 |
| **Data Send** | 复合输入 | 天线在发射模式下会**把发到该节点的所有数据发射出去** |
| **Data Recv** | 复合输出 | 提供在该天线频率上、来自**附近最强信号源**的数据 |
| **Audio Send** | 音频输入 | 发射麦克风音频；也可**转接另一频率天线的音频**，用于跨远距离中继通信 |
| **Audio Recv** | 音频输出 | 提供该频率上来自**附近最强信号源**的音频 |

### 视频天线

**视频传输与无线电通信互不干扰，反之亦然。**
视频用**独立的发射机与接收机**管理——这样可以做「遥控载具上的摄像头 → 控制终端的监视器」这样的链路。

### 手持无线电

- 可以与玩家通信、**与自动驾驶载具交互**。
- **即使只有音频在传输、静电大到听不清，手持电台在特定频率上产生的信号强度仍可被用来检测接收信号。**
- 载具可以通过把音频接到**扬声器**来区分音频与其他数据类型——**扬声器有一个逻辑节点指示它是否正在接收传输**。
- 因此手持电台可用于**选择性远程触发系统**，以及徒步或驾驶轻量载具时用**莫尔斯电码**做远距离通信。
- ⚠ **手持电台无法接收自动驾驶载具发回的数据。**
  理论上可以把蜂鸣器放在麦克风旁边发出莫尔斯码，但**实际上麦克风只传输玩家语音，且只在玩家靠近时传输**。
  当然，接收**玩家驾驶的载具**发出的音频是可以的。

## 10.4 定向天线（Directional antennas）

- 可收发**音频、视频、布尔、数字**数据。
- **必须对准目标设备**才能通信；可与**其他定向天线、视频天线或手持电台**通信。
- 接受 **pitch（俯仰）** 与 **yaw（偏航）** 输入来转动。
  - **pitch**：可让天线相对建造编辑器里的小箭头**最多转 36°**；**输入 1 指向箭头的反方向**。
  - **yaw**：让天线组件绕底座旋转，**任一方向最多整整 360°**（即 **-1 ~ +1 对应 720°** 的转动量）。
- **瞄准不准会导致信号质量下降。**
- **高度会增大传输距离**（原文注明「进一步分析待做」）。

## 10.5 传输距离计算（重点）

在 Stormworks 里传输距离的算法与直觉不同。
从天线 A 发到天线 B 的最大距离取决于：

1. 天线 A 的射程
2. 天线 B 的射程
3. 天线 A 的电量
4. 天线 B 的电量
5. 以及区域内设置的**任何中继器**

### 公式一：作为发送方，算最大距离

```
maximumDistance = ( rangeAntennaA + rangeAntennaB ) × batteryLevelA × batteryLevelB
```

### 公式二：作为接收方，算最大距离（需已知到发送方的距离）

```
maximumDistance = distanceToSender / ( 1 - signalStrength )
```

### 公式三：算到发送方的距离（需已知两端天线射程与两端电量）

```
distanceToSender = ( rangeAntennaSender + rangeAntennaReceiver ) × batteryLevelSender × batteryLevelReceiver × ( 1 - signalStrength )
```

若已知发送方电量恒满（例如柴油发电机供电）且知道其天线型号，则**无需任何复合数据**即可算出距离：

```
distanceToSender = ( rangeAntennaSender + rangeAntennaReceiver ) × 1 × batteryLevelReceiver × ( 1 - signalStrength )
```

### 用 GPS 算两点距离

```
distanceToSender = sqrt( (myGpsX - senderGpsX)² + (myGpsY - senderGpsY)² )
```

> 💡 **提示**：可以通过无线电把 GPS 坐标传出去。
> ⚠ **小型天线没有 signalStrength 输出**，所以公式二、三**对小型天线无效**。

### 示例

发送方：巨型天线（射程 20000 m）；接收方：小型天线（射程 100 m）。

**双方电量 100% 时**

```
maximumDistance = ( 20000 + 100 ) × 1 × 1 = 20100 m
```

**发送方 100%、接收方 50% 时**

```
maximumDistance = ( 20000 + 100 ) × 1 × 0.5 = 10050 m
```

## 10.6 控制火车道岔

**做法**：在 **440 频道**的第 **1 路复合布尔通道**上广播 on/off 信号。

示例：给火车装一根天线（频率 440，发射模式），把一个**按压按钮**接到天线的**复合输入（布尔通道 1）**。
按下按钮，**射程内所有火车道岔都会切换**。
