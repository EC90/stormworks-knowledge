## [Blocks](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Blocks "Wiki/Building/Components/Blocks")

Parts without any logic and moving parts.
For example:

- Cubes
- Windows

## [Vehicle Control](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Vehicle_Control "Wiki/Building/Components/Vehicle Control")

Parts that help you to steer/move/control a vehicle.
For example

- Wheels
- Wings
- Rudders

## [Mechanics](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Mechanics "Wiki/Building/Components/Mechanics")

Parts that can move other things or can be moved itself.
For example:

- Pivots
- Hinges
- Doors
- Tracks
- [Hardpoints](https://stormworks.fandom.com/wiki/Hardpoint "Hardpoint")

## [Propulsion](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Propulsion "Wiki/Building/Components/Propulsion")

Parts that are used to move vehicles.
For example:

- Wheels
- Propellers
- Engines
- Gearbox / Clutch

## Specialist Equipment

Parts that perform special actions.
For example:

- Cameras
- Beds
- Handheld Items
- Pulleys

## [Logic](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Logic "Wiki/Building/Components/Logic")

Parts that interact with the logic network.
For example:

- Add, subtract, multiply, divide
- AND, OR, NOT
- Microcontrollers

## [Displays](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Displays "Wiki/Building/Components/Displays")

Parts that display values from the logic network.
For example:

- Dial
- Digital display
- Artificial Horizon

## [Sensors](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Sensors "Wiki/Building/Components/Sensors")

Parts that read values from the environment and output values for the logic network.
For example:

- GPS
- Speed Sensor
- Torquemeter
- Radar/Sonar

## [Decorative](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Decorative "Wiki/Building/Components/Decorative")

Parts are just here to build nice looking vehicles
For example:

- Rails
- Tire (not a wheel!)

## [Fluids](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Fluids "Wiki/Building/Components/Fluids")

Parts to handle fluids.
For example:

- Pipes
- Pumps
- Valves
- Tanks

## [Electricity](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Electricity "Wiki/Building/Components/Electricity")

Parts that interact with the energy network (only used in [Advanced Mode](https://stormworks.fandom.com/wiki/Wiki/Building/Advanced_Mode "Wiki/Building/Advanced Mode").
For example:

- Relay
- Battery
- Generator

## Jet Engines

Parts that are used to build modular jet engines.
For example:

- Combustion chamber
- Turbines
- Intake, ducting, and exhaust

## Weapons

Parts for use with the [Weapons DLC](https://stormworks.fandom.com/wiki/Weapons_DLC "Weapons DLC").
For example:

- Modular cannons
- Bombs

## Modular Engines

Parts used to build modular engines.
For example:

- Clutches
- Cylinders
- Belt-driven accessories

## Industry

Parts used with the [Industrial Frontier DLC](https://stormworks.fandom.com/wiki/Industrial_Frontier_DLC "Industrial Frontier DLC").
For example:

- Ducts
- Oil rig parts
- Steam engine parts

## [Windows](https://stormworks.fandom.com/wiki/Wiki/Building/Components/Windows "Wiki/Building/Components/Windows")

Various shapes of window blocks.
