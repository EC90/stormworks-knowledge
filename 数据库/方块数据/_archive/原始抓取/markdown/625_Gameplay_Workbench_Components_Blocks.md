# Gameplay/Workbench/Components/Blocks

## Blocks

Block

[![Block](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/3/34/Block.jpg/revision/latest/scale-to-width-down/100?cb=20190317004603)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/3/34/Block.jpg/revision/latest?cb=20190317004603)

The basic block (a cube) you will use to build vehicles, side length 0.25 metres (1 unit). Has a mass of 1.

Wedge

[![Wedge](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/d/d7/Wedge.jpg/revision/latest/scale-to-width-down/100?cb=20190317004805)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/d/d7/Wedge.jpg/revision/latest?cb=20190317004805)

A basic building block for creating faces at a 45 degree angle to the axes. Has a mass of 0.5, takes up 1x1x1 units of space.
