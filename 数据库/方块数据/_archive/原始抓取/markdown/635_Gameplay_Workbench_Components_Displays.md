# Gameplay/Workbench/Components/Displays

## Displays

Artifical Horizon

[![Artifical Horizon](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/7/7f/Artifical_Horizon.jpg/revision/latest/scale-to-width-down/100?cb=20190317005131)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/7/7f/Artifical_Horizon.jpg/revision/latest?cb=20190317005131)

- Used for orientation (azimuth)

Compass Ball

[![Compass Ball](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/6/64/Compass_Ball.jpg/revision/latest/scale-to-width-down/100?cb=20190317005147)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/6/64/Compass_Ball.jpg/revision/latest?cb=20190317005147)

- Used for orientation (north, east, south, west)

Dial

[![Dial](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/e/e7/Dial.jpg/revision/latest?cb=20190317005205)

- Input 1 (Number): the number to display
- You can select minimum and maximum of the display

Digital Display

[![Digital Display](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/a/ab/Digital_Display.jpg/revision/latest?cb=20190317005155)

- Input 1 (Number): the number to display
- You can select minimum and maximum of the display

Gauge Display

[![Gauge Display](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/4/43/Gauge_Display.jpg/revision/latest?cb=20190317005212)

- Input 1 (Number): the number to display as white line
- Input 2 (Number): the number to display as red line
- You can select minimum and maximum of the display

Instrument Panel

[![Instrument Panel](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)](https://static.wikia.nocookie.net/stormworks_gamepedia_en/images/8/83/Instrument_Panel.jpg/revision/latest?cb=20190317005222)

- A combination of 4 other displays or user input
- Input 1 (Composite): used to set values for displays of this panel
- Output (Composite) input signal, overwrittеn by switches and buttons on this panel
- You can connect several panels in series
