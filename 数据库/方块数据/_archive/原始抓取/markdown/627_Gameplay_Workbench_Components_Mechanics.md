### Robotic Pivots

- Input:
- Logic (number): Rotation Target
- Pipes: As specified in their names (Fluid or Rotation (RPS)) NOTE: The Compact pivot does not have a pipe in-, nor output
- Output:
- Pipes: As specified

Robotic pivots can, as their name suggests, pivot to a specified destination. This destination can be -90 to 90 degrees from the starting position (1/4th of a turn in both directions. However, if you input a number, it should be between -1 and 1, since the input isn't understood by the robotic pivot in degrees. This means that if you want to turn the pivot to 45°, then your input has to be 0.5. Due to this, if you want to turn to a very specific, not easily converted angle, (like 38.7°) you have to use a bit of maths. The formula is the following:

#### Compact Robotic Pivot

- The smallest one of the bunch, with no extra features

#### Robotic Pivot Power

- One of the 2 big ones
- Can be used as an RPS Passthrough. For example if you're building a custom rail truck, and you want to power the wheels, you use this pivot for putting the RPS from the engine to the wheels

#### Robotic Pivot Fluid

- The 2nd big guy
- Has a built-in fluid passthrough, meaning you can pass fluids through it. Custom fire extinguisher turrets come to mind as an example, directing the water from the fluid tanks to the adjustable nozzle.

### Velocity Pivots

- Input:
- Logic (number): Rotation Speed
- Output:
- Logic (number): Pivot Angle (ONLY on the big version)

Velocity Pivots are usually used where either a constant motion is required, or a Robotic Pivot's maximum angles are too much of a limitation. The non-compact version is the go-to usually for many builders, because of that extra angle output. That makes a lot more things possible, because without that, you can never be sure if your pivot is actually at the place it is supposed to be.

#### Compact Velocity Pivot

- The small one, you tell it how to spin and it will try its best

#### Velocity Pivot

- Used either the same way as the small one, without using the angle output
- OR by using the angle output, and attaching it to a PID, you can accurately tell it where to go, thereby opening up many possibilities, for example, for turrets that you want to turn all the way around.
