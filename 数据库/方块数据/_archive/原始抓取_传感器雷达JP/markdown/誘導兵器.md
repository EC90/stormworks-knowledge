## 誘導兵器概要

誘導兵器とは発射後に搭載された誘導装置によって目標地点へ自律的に、  
または外部からの指示で誘導され、高い命中精度で目標に到達するミサイル、爆弾、砲弾などの兵器の総称である

#### VLS

垂直発射方式(VLS:Vertical Launch System)とは、艦艇などで使用されるミサイルを垂直に発射する方式である

VLS

ランチャー式と比べ全弾の連続発射が可能で同時に複数の方向に発射できる一方、母機のレーダーによる誘導が必須で低空目標への応答が遅いなどの欠点もある

- 設計  
  GPS誘導方式よりもさらに厄介である。天頂を向いた状態で発射されるため、ミサイルはロール方向とヨー方向の区別ができなくなる(これをジンバルロックという)。そのため、マイクロコントローラーとLua、フィジックスセンサーが必須である。また、指向が不可能であるため、打ち上げた後に母機の誘導に従って目標方向に向かなければならない

  **<GPS誘導>**  
  [![スクリーンショット (63).png](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::ref/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2863%29.png.webp?rev=6edde2d52d752d5feedbc28c185b3ff2&t=20260107055333 "スクリーンショット (63).png")](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::attach/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2863%29.png?rev=6edde2d52d752d5feedbc28c185b3ff2&t=20260107055333 "スクリーンショット (63).png")  
  ハードポイント (以下hdpと略す) から送られてきた座標を保存する回路  
  hdpの複合信号は目標座標 x と y (以下tgtxとtgtyと略す) の情報が入っている  
  hdpの発射信号を反転させて発射された時にメモリーレジスタに値を固定する  
  ラジオ信号を使って　tgtx,y　を取得する場合、この値の固定をしなければ途中で誘導地点を変更できる  
  [![スクリーンショット (64).png](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::ref/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2864%29.png.webp?rev=3196dd7e1b096aabb5f96a754d8aa042&t=20260107062606 "スクリーンショット (64).png")](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::attach/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2864%29.png?rev=3196dd7e1b096aabb5f96a754d8aa042&t=20260107062606 "スクリーンショット (64).png")  
  メモリーレジスタに保存された、もしくはラジオ信号からの tgtx,y　と  
  PHYSICS SENSORから出るミサイルの現在座標(コンポジット緑信号 1(x) と 3(y) )の差(引き算)を求める  
  このとき、tgtx,y から現在座標を引くこと  
  subtract(引き算)はAからBを引くため、tgtx,yはA、現在座標はBにつなぐ  
  [![スクリーンショット (65).png](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::ref/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2865%29.png.webp?rev=21475efd6c55d31c86bb5d7440e755ba&t=20260107064830 "スクリーンショット (65).png")](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::attach/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2865%29.png?rev=21475efd6c55d31c86bb5d7440e755ba&t=20260107064830 "スクリーンショット (65).png")  
  求めた差とPHYSICS SENSORから出るミサイルの現在方位角(コンポジット緑信号17(コンパスセンサー))を  
  魔法の関数

  |  |
  | --- |
  | 2\*(((atan2(x,y)/pi2+z)%1+1.5)%1-0.5) |

  に入れる、 x には差の x 、 y には差の y 、 z には方位角をつなぐ  
  [![スクリーンショット (66).png](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::ref/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2866%29.png.webp?rev=4becebb84ec839ef473b13c005aa2ab1&t=20260107070657 "スクリーンショット (66).png")](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::attach/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2866%29.png?rev=4becebb84ec839ef473b13c005aa2ab1&t=20260107070657 "スクリーンショット (66).png")  
  それらをフィンのコンポジット緑信号　1　に出力する、ミサイルフィンを使用しない場合、ヨー制御に出力する  
  これでまずヨー制御については完了した　続いて高度維持回路を組んでいく  
  **<高度維持>**  
  [![スクリーンショット (67).png](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::ref/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2867%29.png.webp?rev=4830d0b492e983d5db442d8f11d757d9&t=20260107071819 "スクリーンショット (67).png")](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::attach/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2867%29.png?rev=4830d0b492e983d5db442d8f11d757d9&t=20260107071819 "スクリーンショット (67).png")  
  目標高度とPHYSICS SENSORから出るミサイルの現在高度(コンポジット緑信号 2 )の差を求める  
  魔法の関数

  |  |
  | --- |
  | clamp(x-y/4,最小ピッチ角,最大ピッチ角) |

  を使う、　x　には目標高度、 y にはミサイルの現在高度をつなぐ  
  それをPID制御のSETPOINTにつなぐ  
  そしてPHYSICS SENSORから出るミサイルの現在のピッチ角(コンポジット緑信号 15 )を  
  単位変換

  |  |
  | --- |
  | (x\*pi2)\*(180/pi) |

  で回転数から度数へと変換する(ピッチ角を度数で設定するため、わかりやすくなるが必要ではない)  
  そしてそれをPID制御のPROCESS VARIABLEにつなぐ  
  それをフィンのコンポジット緑信号　2　に出力する、ミサイルフィンを使用しない場合、ピッチ制御に出力する  
  これでGPS航法に必要な部分は完了した、続いてミサイルの終末誘導用の回路を組んでいく  
  **<終末誘導>**  
  [![スクリーンショット (68).png](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::ref/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2868%29.png.webp?rev=3e3e6cb88f09e9c8f2ac71d6a3da72af&t=20260107074007 "スクリーンショット (68).png")](https://cdn.wikiwiki.jp/to/w/sbarjp/%E8%AA%98%E5%B0%8E%E5%85%B5%E5%99%A8/::attach/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%20%2868%29.png?rev=3e3e6cb88f09e9c8f2ac71d6a3da72af&t=20260107074007 "スクリーンショット (68).png")  
  ミサイル用レーダーのコンポジット信号のうち、Radar Data(検出した物体の情報)のものから、コンポジット赤信号　1　を入力、キャパシター>コンポジットスイッチボックスの順でつなぎ、  
  キャパシターはchageを0sec、dischageを0.5secほどにする、これにより「終末誘導を開始した直後にレーダーが目標を失探してGPS航法に即座に切り替わり完全に外れる」  
  ということを阻止できる  
  コンポジットスイッチボックスはオフにGPS誘導の信号を、オンにミサイル用レーダーのMissile Output(ミサイル出力)をつなぐ  
  これでMICROCONTROLLERは完成した

### 誘導爆弾

ロケットエンジンやジェットエンジン等の推進装置を持たないかわりに、航空機から投下することでその慣性と位置エネルギーで目標まで飛行し弾頭を命中させて破壊する誘導兵器

- StormWorksでの扱い  
  StormWorksでの飛翔体は推力のない状態ではほとんど舵が効かない。さらに投下時の慣性も小さく、空気抵抗ですぐに減速してしまう。そのため1%ロケットやインテークとRCSスラスターによるラム圧推進などのわずかな推力で滑空誘導する事例がほとんどである。  
  誘導方法はミサイルとほぼ同じだが、射程延長のためにより高度な高度維持、滑空のロジックが必要である。

### 誘導魚雷

ロケットやスクリューなどの推進装置を持ち、誘導装置によって目標まで水中を航行し弾頭を命中させて破壊する誘導兵器

#### ソナー式

水中であるため、電波の反射を利用したレーダーは使用できない。かわりに音波の反響を用いたソナーを使用する。

#### GPS式

ミサイルと同様である。しかし、ミサイル頬ほど速度が速くないので動目標に当てるのは至難だろう。

#### 有線式

ウインチを伸ばすことで誘導する方式である。しかし、ウインチの長さがかなり短い(最大で500m)ためあまり実用的ではない。

### ドローン

小型の無人機に弾頭を乗せて攻撃する方式である。  
モーターは電力バカ食いなのでお勧めはしない。  
エンジンもラジエーターがでかいのでお勧めはしない。
