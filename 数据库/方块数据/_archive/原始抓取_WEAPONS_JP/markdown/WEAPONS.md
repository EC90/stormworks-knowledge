# WEAPONS

ビークルへ搭載できる砲や弾薬およびその輸送用ベルト、爆薬。Search and Destroy DLCを購入しワールド作成時に有効にすることで発砲できるようになるが、未購入やDLC無効ワールドでも設置ができる。

## 武器弾薬のデータ集

- 砲・銃各種で選択可能な弾薬

  | 武器種 | High Explosive | Fragmentation | Kinetic | Armor Piercing | Incendiary |

  | Machine gun | × | × | 〇 | 〇 | 〇 |
- 弾種別解説

  | 弾種 | 解説 |
  | --- | --- |
  | kinetic | 日本語名は運動エネルギー弾。命中したマージの周囲一定距離にダメージを与える。マージが違うとダメージが伝わらない。 |
  | Armor Piercing | 日本語名は徹甲弾。命中したマージの周囲一定距離にダメージを与えつつ、一定フィジックス分貫通する。 |
  | Fragmentation | 日本語名は榴散弾。命中したマージ周囲一定距離にダメージを与えつつ、単一マージにダメージを与える初速を持った子弾を複数周囲にスポーンさせる。 |
  | High Explosive | 日本語名は榴弾。命中した地点から一定範囲に無差別にダメージを与えるこのゲーム最強の砲弾。Rocket Launcherの弾頭もコレ。 |
  | Incendiary | 日本語名は焼夷弾。命中したマージの周囲一定距離にダメージを与えつつ。一定確率で弾着点を出火させる。 |

## MACHINE GUN AMMO BOX

マシンガンの弾薬。設置時にマシンガン本体に溝を合わせることで弾の供給が行われる。撃ち切ると台座のみの表示となり、他に設置したこのパーツから弾薬を手で移してくることで再装填できる。
