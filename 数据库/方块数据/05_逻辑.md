# 05 逻辑

**本节回答**：逻辑部件分哪几类、每一类的输入输出接口是什么。
源页面：`Gameplay/Workbench/Components/Logic`（修订 4163）。

**两类基础 + 一个补充**（原文）：
- **数值（Numeric）**：操作数字，例如两数相加。
- **布尔（Boolean）**：真假逻辑，例如开关门、开关灯。
- 另有 **Composite（复合）**、**Functions（函数）**、**Other（其他）** 三组，以及 **Microcontroller（微控制器）** 组。

**两种实现方式**：直接摆在创建物上，或放进微控制器里。

## 5.8 信号类型与复合信号处理（教程向，补自 biligame「微控入门」）

> 来源：`https://wiki.biligame.com/stormworks/微控入门`（BKN-46 原创，中文社区教程）。
> 此节是**概念性补充**——`5.1~5.7` 只列了部件清单，`5.3 Composite` 也只写了「微控制器是唯一能读写复合数据的部件」，
> 但**没讲信号到底有几种、复合怎么读写**。本页补全这部分。⚠ 教程内容可能随版本变化，接口名以游戏内为准。

### 5.8.1 六种接口（信号）类型

| 类型 | 英文 | 内容 | 默认值 |
|---|---|---|---|
| 数字 | number | IEEE754 标准 **32 位浮点数** | 0 |
| 开关 | on/off | 开/关两态，对应布尔值 | off |
| 混合 | composite | **32 个数字通道 + 32 个开关通道**的混合信号，用于压缩数据传输 | 64 个信道全为 0 / off |
| 视频 | video | 视频信号；**只有 Lua 组件和视频信号切换盒能处理**，无法获取长宽，每个像素 RGB(0,0,0) | — |
| 线缆 | rope | 提供物理连接，一般同时含混合信号、视频信号与电力传输 | — |
| 音频 | audio | 音频信号，用于游戏内无线电语音 | — |

> **接口形状约定**：所有信号都从**出口（实心圆）**流向**入口（空心圆）**；**若入口没有输入，则取其默认值**（上表）。

### 5.8.2 混合信号（Composite）的读写

复合信号除 Lua 外**无法直接处理**，必须借助微控制器内的 `Composite Read` / `Composite Write` 模块（模块名即游戏内英文，汉化补丁未收录，勿自译）。

**读取（Read）** — 取复合信号中某通道的数据：

```
Composite Read(number)
port: 1          ← 读取 1 号数字通道；也可接变量实现动态通道读取（port: variable）
```

**写入（Write）** — 把普通数字/开关信号写进复合信号：

```
Composite Write(number)
start / num: 1 / 3   ← 把连接的数字信号分别写入 1、2、3 号数字通道
```

改起始节点和写入数量即可换通道；开关信号同理。入口的混合信号是「想要覆盖的内容」，不填则以全 0/off 为基础覆盖。

⚠ **数字通道与开关通道互相独立**：对同一序号信道分别写 `Composite Write(number)` 和 `Composite Write(on/off)`，**互不干扰**。

### 5.8.3 颜色数据与 RGB 灯

RGB 灯（`灯(RGB)` / `指示灯(RGB)`）吃**复合信号 `颜色数据（Color Data）`** 输入，支持 **RGB 与 HSV 两种色彩空间**。
最简单的混合信号处理就是把 R/G/B 三个数字信号写入 Color Data 通道来控制灯色。

### 5.8.4 视频信号的限制

视频信号**只有 Lua 组件和视频信号切换盒能处理**（见 `11_显示器与视频.md`）；普通逻辑部件读不到、也改不了视频。

> 实战参考：Lua 微控制器内的脚本写法是 Stormworks 特有的（与常规 Lua 差异大），详见 `..\stormworks基本设定\` 与 `..\BKN46-bknsw-6300d21\`（已在 5.6 / 顶部规则引用）。
