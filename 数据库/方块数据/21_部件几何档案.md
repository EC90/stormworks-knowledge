## 1. 本册的定位：实测几何 vs 占位格数

现有 01–20 册与 `00_速查_部件总表.md` 的尺寸，来自定义 XML 的 `<surface>` / `vox` 推算的**占位格数**（如「占 1x1x1」）；本册提供**从二进制实测的真实渲染几何**。

两者是不同维度，交叉比对可发现单看一边看不到的信息：

| 现象 | 含义 | 实例 |
| --- | --- | --- |
| 实测 < 占位 | 部件实体不满格，存在留空 | Push Button：占位 1x2x1，实测仅 **1×0.08×1** 格（按钮几乎贴面板） |
| 实测 ≈ 占位 | 标准方块类，尺寸可信 | 气压计 1×0.32×1 格 |
| 实测 > 占位 | **可动部件烘焙了极限姿态** | 气动活塞 占位 1x2x1，实测 1×**5.10**×1（活塞杆伸出态） |
| 占位 >> 视觉体积 | **占位即效果范围**（雷达扫描区） | 雷达(巨) 占位与实测**均为 37×5×37 格**，但视觉上只是个小雷达 |

**全量比对结论（558 条可比对部件）**：吻合 515 条（92.3%）、超出 21 条（3.8%）、偏小 22 条（3.9%）。92.3% 的吻合率是对解析正确性的强验证——占位格数是完全独立的数据源，解析若出错不可能与它在九成样本上吻合。

## 2. 单位、坐标系与字段释义

- **1 格 = 0.25 m**，**Y 轴向上**，顶点坐标单位为米。
- 本册「实测格」= 顶点实测 AABB 尺寸 ÷ 0.25。

| 字段 | 含义 |
| --- | --- |
| 顶点 / 三角 | 渲染网格规模（三角 = 索引数 ÷ 3） |
| 实测格 | **顶点真实 AABB**，亚格精度 |
| 占位 vox | 定义 XML 声明的占位格数（`vox`），仅部分定义有值 |
| 着色器 | submesh 的 shaderId：0 Opaque / 1 Transparent / 2 Emissive / 3 Lava |
| 涂装 | 顶点中命中可涂色基色 RGB(255,125,0) 的数量。**固定色**=不可涂装；**整件涂装**=全部顶点随涂装变色 |
| bounds | `exact`=声明与实测一致可直接用；`tile_declared`=瓦片声明框，不可当尺寸 |

> ⚠ **`.mesh` 顶点不含 UV 坐标**（设计如此，非解析遗漏）。Stormworks 靠顶点色 + shaderId + 程序化材质渲染。

### 7.1 占位远大于视觉体积的部件（雷达类）

**雷达(巨) 案例**：`component_radar_huge.mesh` 实测 37×5×37 格（9.25×1.25×9.25 m），看似离谱，但定义 XML `radar_huge.xml` 明确声明 `<voxel_min x="-18" y="0" z="-18"/>` / `<voxel_max x="18" y="4" z="18"/>`，算得占位正是 **37×5×37 格** —— 与 mesh 实测**完全一致**。

因此这不是解析异常，而是**游戏设计：雷达的占位即其扫描范围**。顶点到中轴距离分布在 1.507~4.625 m（中心 1.5 m 半径内无顶点），是一个大圆环。

> 💡 **可玩性提示**：雷达类部件会**占掉大片空间**（雷达(巨) 占 37×5×37 格），在紧凑载具内布雷达时要预留空间；反过来说，雷达的扫描范围与占位等价，可用占位格数直接推算覆盖范围。

> ⚠ **方法论说明**：曾尝试用「顶点全为基色」「归一化填充度」等启发式自动识别「辅助几何」，均**产生大量误报**（机翼、龙骨、气罐等真实大尺寸/薄壳部件被误判）。原因在于薄壳结构（气罐是空心圆柱）与范围指示环的几何特征高度重叠，无法用简单统计量区分。**本册因此不做自动判定**，改以 §6 的 vox 比对为判读依据。

### 7.2 地形件不可用 bounds

地形件（`moon_surface_*`、`arid_island_*`、`mainland_*` 等）的 `bounds` 是**瓦片声明框**而非真实几何。例：`arid_island_10_10.mesh` 声明 ±500/±1000，实测 y∈[-354.63, 183.12]。全量 1596 个 mesh 属 `tile_declared`，本册档案表已用 ⚠ 标记。

## 10. 复现与查询

```bash
PY="C:/Users/EC90/.workbuddy/binaries/python/versions/3.13.12/python.exe"
K="D:/STORMWORKS/技能库/sw-mesh-tools/scripts"

# ① 全量校验格式（3653 个文件，约 11 秒；失败返回退出码 2）
"$PY" "$K/sw_mesh.py" verify

# ② 单文件详情
"$PY" "$K/sw_mesh.py" info "E:/SteamLibrary/steamapps/common/Stormworks/rom/meshes/component_barometer.mesh"

# ③ 导出 OBJ（须落在 D:\\STORMWORKS 下）
"$PY" "$K/sw_mesh.py" obj "<mesh路径>" -o "D:/STORMWORKS/_work/mesh_preview/x.obj"

# ④ 重建索引（游戏更新后）
"$PY" "$K/build_mesh_index.py" --incremental

# ⑤ 查询部件几何
"$PY" "$K/sw_geom.py" get 气压计
"$PY" "$K/sw_geom.py" mesh component_barometer
"$PY" "$K/sw_geom.py" top --by verts --limit 20
```
