## 1.3 窗户的通用性质（源页面 `Windows`）

- 与现实一样**半透明**，玻璃四周有边框。
- **气密且水密**，即使极端压力下也阻止水或其他流体通过。
- **不会因压力损坏**，行为等同普通基础构件。**除非被 XML 修改**。
- 尺寸矩阵：平面 **1x1 / 1x2 / 1x3 / 2x2 / 2x3 … 3x3**（X=宽，Y=高，最大 3x3）。
- 斜窗族多一个维度**深度（Z）**：`1x1x1`、`2x1x1`、`3x1x1` 等（X=宽，Y=高，Z=深）。
- **两个上色区**：内侧一个、外侧一个。
