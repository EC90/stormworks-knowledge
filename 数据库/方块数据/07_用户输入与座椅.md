### 7.2.1 驾驶座椅的通道表（重点）

**独立输出节点**（驾驶座椅 / 紧凑型 / 轮舵 / 宇航 / 控制器手柄通用）：

| 类型 | 通道/节点 | 含义与按键 |
|---|---|---|
| 数字 | 1 | Axis 1：`[a]/[d]` 轴，a 降 d 升 |
| 数字 | 2 | Axis 2：`[w]/[s]` 轴，s 降 w 升 |
| 数字 | 3 | Axis 3：`[←]/[→]` 轴，← 降 → 升 |
| 数字 | 4 | Axis 4：`[↑]/[↓]` 轴，↓ 降 ↑ 升 |
| 数字 | Look X | 水平视线方向 **-0.35(左) ~ 0.35(右)**（约 -126° ~ 126°） |
| 数字 | Look Y | 垂直视线方向 **-0.2(下) ~ 0.2(上)**（约 -72° ~ 72°） |
| 开关 | Trigger | **空格键**按下时输出开 |
| 开关 | 1–6 | 数字键 1–6 是否被按下 |
| 开关 | Occupied | 是否有人坐着（开=占用） |

⚠ **轴默认值方向**：`a/s/←/↓` = -1，`w/d/→/↑` = +1（与其它来源描述一致）。
**Reset 模式**：按下 W 时数值从 0 升到 1，松开 W 后降回 0；按 S 则相反，从 0 降到 -1。

**复合输出 `Seat data`（座席信息）通道映射**（所有驾驶座椅通用）：

| 类型 | 通道 | 内容 |
|---|---|---|
| 数字 | 1–4 | Axis 1~4 数值 |
| 数字 | 9 | Look X 数值 |
| 数字 | 10 | Look Y 数值 |
| 开关 | 1–6 | Hotkey 1~6 开关 |
| 开关 | 31 | Trigger 开关 |
| 开关 | 32 | Occupied 开关 |

> **SELECT 可配置项**（座席选择工具）：每个 Axis 可设 `Label`（着席帮助显示名）、`Mode`（**Reset**=松手回 0 / **Sticky**=保持数值）、`Sensitivity`（1~100%，数值变化速度）；
> 每个 Hotkey 可设 `Label`、`Mode`（**Toggle**=每次按切换 / **Push**=按住才开）；另可设 `Trim Axis 1~4`（轴输出修正值，等同场内 Alt+轴 trim 操作，出厂即带该 trim）。

### 7.2.2 驾驶座椅(HOTAS) 的特殊处

- 提供 **8 个数值轴 + 48 个开关热键**（标准驾驶座椅是 4 轴 + 6 热键）。
- Axis 5~8、Hotkey 7~48 **需在 OPTION 里额外配置**才会启用。
- ⚠ **复合通道溢出限制**：标准复合输出最多 32 个开关通道。HOTAS 的 On/Off 通道 33~48 **微控制器侧通道不够、无法直接识别**，要用这些通道须改接普通逻辑输出（非 Seat data 复合）再进微控制器。
- 其余 Look X/Y、Occupied、Trigger、Seat data 数字通道 1~8/9/10 映射与标准座椅相同。

### 7.2.3 驾驶座椅(宇航) 的氧气功能

- 造型为 MMU（载人机动单元），**无碰撞判定**（本身不挡其它方块）。
- 背面有进气口（`Fluid In` 流体入口）：着席且**身着宇航服**时，向进气口供 **氧气 / Air**，会**代为消耗宇航服的氧气**（延长舱外活动时间）。
- 其余输出通道与标准驾驶座椅一致。

## 7.3 仪表板（Instrument Panel）

| 中文 | 游戏内英文名 | 说明 |
|---|---|---|
| 仪表板 | Instrument Panel | 4 合 1 显示/输入面板 |

**关键规则**（原文要点）：
- 使用**复合输入与复合输出**，**通道可在 1–32 之间配置**。
- **复合输入**：最多 4 路数字或布尔，接到表盘、仪表、指示灯、七段数码管、环形/条形段显示器。
- **复合输出**：最多 4 路，来自面板上的按钮与开关。
- **菊花链（Daisy chaining）**：多个仪表板可**串联成链**，这样微控制器**只需一路复合输入和一路复合输出**就能驱动多块面板。
- ⚠ **通道冲突**：**不能**在不同面板的**同一通道**上放多个按钮/开关——
  若通道重复，**只有最后一块面板上的按钮/开关状态会生效**。

> `Displays` 页对仪表板的描述略有不同：「4 个其他显示器或用户输入的组合；
> 输入1（复合）设置面板上各显示器的值；输出（复合）为输入信号，被面板上的开关与按钮覆盖。」
> 两页互补，不矛盾。
