## 1. 核心定量规律（Lua 里最常引用的数值）

### 1.1 稳态转速：与排量、缸数基本无关 🎮

| 配置 | 真空载稳态 RPS | 备注 |
| --- | --- | --- |
| 1x1 单缸 | 60.66 | 06/09/12/13 轮一致 |
| 1x1 双缸 | 59.95 | 11 轮 |
| 1x1 四缸 | 59.98 | 14 轮 |
| 3x3 单缸 | 60.06–60.26 | 15/16 轮 |
| 5x5 单缸 | 60.93–61.11 | 17 轮 |
| 5x5 双缸 | 60.93 | 18 轮 |

**Lua 启示**：
- `气1/油0.5` 下，任何模块化引擎单缸配置的**空载转速上限都在 ~60 RPS**（实测 60.0–61.2，脉动后最高约 62.2）。
- 写转速控制器时，`目标转速 ≈ 55–60` 是合理范围；**不要写超过 62 的目标**（到不了）。
- 带载会掉转速：1x1 带一个自由轮就掉 22%（60.7→47.2），3x3/5x5 几乎不掉。**小排量对负载敏感得多**。

### 1.2 扭矩：三排量序列（飞轮加速法，同 1x1 飞轮）🎮

| 排量 | 排量比 | 自行加速 3→60 RPS | 平均加速度 | 相对 1x1 |
| --- | --- | --- | --- | --- |
| 1x1 单缸 | 1× | 81.1 s | 0.70 RPS/s | 1× |
| 3x3 单缸 | 27× | 3.27 s | 17.45 RPS/s | **24.8×** |
| 5x5 单缸 | 125× | 0.75 s | 76.00 RPS/s | **108×**（上限） |

**结构性结论**：
- **小排量段（1x1→3x3）**：扭矩 ×25 < 排量 ×27（有损耗，疑似基础摩擦/泵气损失占比大）；
- **大排量段（3x3→5x5）**：扭矩 ×4.4 ≈ 排量 ×4.63（近线性）；
- 负载法（熄火负载）整体偏低：3x3/1x1=11.9×、5x5/3x3≥4.3×——因为负载法受**离合器打滑**限制。

**Lua 启示**：估算“这台引擎能不能带动某负载”，优先按“**扭矩 ≈ 单缸扭矩 × 缸数**”粗算（见下），别按排量线性外推小排量段。

### 1.3 缸数乘法：总扭矩 ≈ 单缸扭矩 × 缸数 × 0.85–1.0 🎮

- 1x1：1 缸 0.70 → 2 缸 ~1.4 → 4 缸 ~2.8 RPS/s（达速时间 85.5/41.0/22.1 s 反比，时间×缸数 ≈ 85 常数）；
- 5x5：单缸 76.0 → 双缸 131.5 RPS/s（系数 **1.73×**，略低于 2，双缸本体质量翻倍 + 共用歧管充气略降）。

**Lua 启示 / 实车选型**：
- **要扭矩优先加大单缸排量**（1x1→3x3 = ×25）；
- 缸数翻倍只有 ×1.7–2 且**油耗同步翻倍**；
- 歧管多缸共用时，高转速充气效率会轻微下降。

### 1.4 每缸每冲程油量（供油特性，跨加载方式复现）🎮

四冲程每缸每 2 转进气 1 次：

```
每缸每冲程油量(L/行程) = 柴油流量(L/s) ÷ ( RPS × 缸数 / 2 )
```

| 排量 | 每缸每冲程油量 | 相对 1x1 |
| --- | --- | --- |
| 1x1 | 0.00144–0.00145 | 1× |
| 3x3 | 0.0369–0.0378 | ~26× |
| 5x5 | 0.22 | ~153× |

- 同一台引擎用**两种完全不同的加载方式**（自由轮制动 / 锁死轮+离合器）测得值相差仅 0–2.4%——**它是引擎自身的供油特性**，可作 Lua 油耗估算的基准。
- 1x1→3x3 严格按排量缩放（比值 0.96）；3x3→5x5 单位排量偏高 22%。

### 1.5 空载油耗与峰值油耗 🎮

| 配置 | 空载油耗 L/s | 峰值（加载时） |
| --- | --- | --- |
| 1x1 单缸 | 0.023–0.025 | 0.042 |
| 1x1 双缸 | 0.028–0.034 | 0.086 |
| 1x1 四缸 | 0.046–0.056 | 0.157 |
| 3x3 单缸 | 0.23–0.26 | ~1.1 |
| 5x5 单缸 | 0.34–0.48 | ~6.6–7.8 |
| 5x5 双缸 | 0.75 | — |

**Lua 启示**：油箱大小/续航估算用“空载油耗 × 负载系数”；**油耗峰值出现在“引擎被负载逼到极限”的拐点处**，而非空载。

### 1.6 进气压力：轻载时与负载无关，重载才升 🎮

- 真空载：1x1 ≈ **0.519 atm**、3x3 ≈ **0.520 atm**、5x5 ≈ **0.678 atm**；
- 带轮（轻负载）时 1x1 会升到 0.678（因掉速→每循环充气多）；3x3/5x5 带轮几乎不掉速、看不出变化。
- **Lua 启示**：进气压力**不能当负载或转速的信号**（轻载时基本不变），只能做一致性/故障检查。大排量（5x5）读数天然更高。

## 2. 传感器通道与 Lua 读取写法 🎮

| 信号 | 部件 → 节点 | 单位 | Lua 注意事项 |
| --- | --- | --- | --- |
| 曲轴转速 | 模块化发动机曲轴 → RPS | 转/秒 | 主转速源；单缸有冲程脉动（见 §3.2） |
| 飞轮转速 | 飞轮 → RPS | 转/秒 | **与曲轴逐点相同（零滑差）**，可互备 |
| 进气压力 | 流体压力传感器 → Pressure | atm | 见 §1.6 |
| 柴油流量 | 液体泄压阀 → Flow Rate | L/s | **前 ~60 tick 有假读数 281.97 L/s，必须丢弃**（见 §3.1） |
| 扭矩 | 扭矩计 → Torque | 游戏单位（非 N·m） | **所接网络决定测到什么**（见 §2.1） |
| 网络转速 | 扭矩计 → RPS | 转/秒 | 与曲轴 RPS 的差 = 传动链滑差（见 §2.2） |
| 起动机状态 | 起动机 → Starter | 0/1 | 可直接当输入/记录 |

### 2.1 ⚠ 扭矩计测的是"整个所连动力网络"，不是单点

`🎮 日文 wiki + 实测双重确认`：
- 扭矩计读数 = **所连网络上所有连接件的动力需求之总和**，与安装位置无关（管路不衰减）。
- **要测"引擎输出扭矩"，扭矩计必须装在发动机侧网络**（曲轴/传动带 ↔ 离合器之间）；
  装在离合器**负载侧**测到的是**负载需求**——07 轮实测差值 17+ 个单位。
- 单位**不要当 N·m 用**（日文 wiki 注明"推测为惯性矩、要検証"，Fandom 称 "force"），只作相对比较。
- 锁死负载会给读数加**与接合压无关的常数项**（1x1 + 锁死 5x5轮 ≈ 20.0）。

### 2.2 离合器打滑（重要非线性）

- 模块化引擎离合器在**接合压 1 时仍会打滑**：滑差（曲轴 RPS − 扭矩计 RPS）随负载单调增大——
  轻载 1.4% → 0.45 接合压 3.6% → 熄火 16.5% → 满接合 **82%**（10 轮实测）。
- **负载瓶颈常是离合器打滑而非引擎扭矩**（10 轮：双缸扭矩 +33%，熄火接合压只 +2.9%）。
- **Lua 启示**：用离合器做动力控制时，**它的传递能力是有上限且会打滑的**；
  想提高"能扛的负载"，换更大/更强的离合器可能比加缸更有效（待验证）。
- 对比：**飞轮与转换曲轴是刚性的、不打滑**（RPS 逐点相同）。

## 3. Lua 信号处理要点

### 3.1 泄压阀流量读数的启动假读数（必过滤）🎮

- 每轮 tick 4 附近都会出现 **281.9718 L/s** 的柴油流量假读数（18 轮全部复现，数值一字不差）。
- **Lua 写法**：记录/使用流量前，**丢弃引擎起动后的前 ~1 秒（60 tick）**，或限制流量上限 `min(flow, 合理上限)`。

### 3.2 单缸冲程振荡（转速/油耗的脉动）🎮

| 排量 | 稳态 RPS 脉动 |
| --- | --- |
| 1x1 | ±0.1% |
| 3x3 | ±2.5% |
| 5x5 | **±8%**（60.03–70.37 之间来回） |

- **Lua 写法**：对 5x5 单缸的 RPS / 油耗做**移动平均（窗口 ≥ 1 秒 / 60 tick）**再用，否则控制会跟着冲程抖。
- 压力读数天然带冲程振荡（0.29–0.73 之间跳），分析时也用窗口均值。

### 3.3 起动机控制（实测验证的写法）🎮

```lua
-- 曲轴 RPS ≥ 3 自动关断起动机（13 轮台架同款逻辑，已验证）
local STARTER_OFF_RPS = 3
if crankshaftRps >= STARTER_OFF_RPS then
    starterOn = false
end
```

- **起动机只在 <3 RPS 的起步阶段真正出力**（13 轮对照：常开 86.0 s vs 关断 85.5 s，差 0.6%）；
- 单缸引擎被拖到 3 RPS 后**能自持并自行加速到 60 RPS 全程不熄火**；
- **重引擎（3x3/5x5）配双起动机**可把起动段砍一半以上（17/18 轮：5x5 达 3 RPS 9.8 s → 3.9 s）。

### 3.4 熄火判据（给 Lua 的判定常量）🎮

| 场景 | 判据 |
| --- | --- |
| 起动机常开 | **RPS < 3 = 熄火**（低于 3 由起动机维持、不自持） |
| 起动机已关断 | RPS < 3 = 熄火（3 RPS 是能自持的门槛，见 §3.3） |

## 4. 引擎动力学特征（PID 调试相关）

### 4.1 时间常数：飞轮决定快慢 🎮

| 配置 | 从 0 到稳态 | 系统特性 |
| --- | --- | --- |
| 无飞轮（任意单缸） | ~1.9–4.6 s | 快，可激进调参 |
| + 1x1 飞轮（mass 100） | 8.2–86 s（随扭矩） | **慢**，时间常数秒级~十秒级 |
| + 3x3 飞轮（mass 200） | 25.4 s（3x3 单缸） | 更慢 |

- **PID 启示**：带飞轮的引擎是**大惯性慢系统**——
  `Kp 要小`、`Ki 要慢`、积分时间常数参考"达速时间"量级；
  无飞轮时才可激进。
- **飞轮只改动态、不改稳态**（11 轮：达速 1.9→41 s，但稳态 RPS/压力不变）——
  所以稳态目标值不因飞轮改变，只影响调节过程。

### 4.2 扭矩-转速特性（影响控制增益）🎮

- **工作区扭矩近乎恒定**（与转速弱相关）：1x1 空载自耗 3.90、工作区 3.94–4.47；
  因此**功率 ∝ 转速**，峰值功率在高转速端。
- **熄火是"被拖垮"的过程**，不是瞬时事件（满接合后要再拖 2.5–2.9 s 才跌破 3 RPS）。
- 加载后**每冲程油量跳升**（空载 → 加载的数倍），这是引擎应对负载的方式，Lua 做负载前馈可参考油耗跳变。

### 4.3 非线性来源清单（PID 需补偿/绕开）

1. **离合器打滑**（§2.2）：饱和非线性，随负载增大；
2. **起动器**：起步阶段的执行器饱和/干扰源（用 §3.3 自动关断剥离）；
3. **单缸冲程振荡**（§3.2）：周期性扰动，需滤波；
4. **进气压力不随负载线性变化**（§1.6）：别拿它当反馈主信号；
5. **油耗的启动假读数**（§3.1）：阶跃扰动，需丢弃。

## 6. 测试方法学（后续 AI 追加轮次时遵循）

1. **台架标准接法**（"扭矩计前置"版，测引擎输出扭矩）：
   `曲轴 → 模块化引擎离合器(同尺寸，恒定1取力) → 扭矩计 → 通用离合器(变量) → 锁死 5x5轮`。
   模块化引擎必须经**同尺寸离合器**才能取力（用户已确认）。
2. **跨排量比扭矩的标准方法（飞轮加速法，已验证干净）**：
   用**转换曲轴**把引擎接到**同一个 1x1 飞轮（mass 100）**，起动机 RPS≥3 自动关断，
   记录"自行加速 3→60 RPS 的平均加速度"作扭矩指标。**起动机不影响（13 轮已证）**。
3. **数据留档**：`SW示波器v0.1.3\` 的旧 CSV 会被清理，**归档文档 §6 附录是唯一副本**；
   `eng_test.xml` 也只有一份，换台架前另存副本。
4. **生成文档**：`<WS>/技能库/sw-modular-engine-bench/scripts/make_record.py`，
   通道顺序已变时用 `--cols + --roles` 映射（`scan/rps/press/flow/torque/aux`）。
5. **术语/规格**：先跑 `汉化相关\脚本\sw_check.py --auto` 再用 `sw_batch.py` 核对译名；
   规格用 `方块数据\脚本\sw_defs.py get "<英文名>"`，**不抄 wiki**。
