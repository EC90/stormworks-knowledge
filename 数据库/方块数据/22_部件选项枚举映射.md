# 22_部件选项枚举映射（载具 XML 属性代号 ↔ 游戏内下拉文本）

> **用途**：AI 读取载具 XML（`<SW_SAVE>\data\vehicles\*.xml`）时，据此把 `<o>` 上的
> 整数代号还原为玩家在游戏内看到的选项文本。
> **数据来源**：`stormworks64.exe` 静态提取（`.text` 代码引用顺序 = 下拉枚举顺序，
> golden 双重验证），见 `技能库/sw-property-options/SKILL.md`。
> **查询**：`python "<PY>" "<WS>/数据库/方块数据/脚本/sw_defs.py" options <属性名>`
> **可信度**：`auto`=golden/强锚定；`partial`=需游戏内复核；`curated`=人工策展；`todo`=未解析。

## 1. 已确认枚举文本表（可直接用于解读 XML）

### 1.1 雷达/LSS 扫描模式 `m_sweep_mode`（auto）
雷达（`radar_advanced_dish`/`radar_advanced_missile`）与 LSS 共用，详见 `17_传感器与雷达.md` §2.2.1。
`0=Static 1=Clockwise 2=Anticlockwise 3=Sweep 4=Manual`

### 1.2 炮塔座圈/枢轴传动比 `gear_ratio`（auto，用户确认）
仅座圈/枢轴族：`multibody_turret_*`、`multibody_pivot_*`、`multibody_compact_pivot_*`、
`multibody_velocity_pivot_*`、`linear_compact_head`。
`0=1:1 1=1:2 2=1:4 3=1:8 4=1:16 5=1:32`

### 1.3 模块化引擎变速箱传动比 `gear_ratio_1` / `gear_ratio_2`（partial，强结构证据）
适用于 `modular_engine_gearbox_1x1/3x3/5x5`；`torque_clutch` 也写 `gear_ratio_2`。两组选项相同：
`0=1:-1 1=1:1 2=6:5 3=3:2 4=9:5 5=2:1 6=5:2 7=3:1`
（等值：1:-1 反转 / 1:1 / 1.20 / 1.50 / 1.80 / 2.00 / 2.50 / 3.00；存档实测取值上限 7，吻合）

### 1.4 干扰弹类型 `flare_type`（partial）
`flare_launcher`。`0=Illumination 1=Smoke 2=Illumination Parachute 3=Smoke Parachute 4=Chaff`
（照明 / 烟雾 / 照明伞降 / 烟雾伞降 / 箔条）

### 1.5 硬点挂载类型 `ordinance_type`（partial）
`connector_hardpoint_a/b`、`connector_slider_track` 等。
`0=Ordinance 1=Utility 2=Fuel 3=Unguided bomb 4=Laser Guided Bomb 5=GPS Guided Bomb
6=Rocket 7=Rocket Pod 8=Laser Guided Missile 9=GPS Guided Missile
10=Radar Guided Missile 11=Torpedo 12=Cannon`

### 1.6 弹药类型 `property_ammo_type`（partial，人工策展）
`gun_drum_xsmall` 等武器。exe 弹药簇 6 项连续注册：
`0=Unloaded 1=Kinetic 2=High Explosive 3=Fragmentation 4=Armor Piercing 5=Incendiary`
⚠ 存档实测 `property_ammo_type=6` → **至少 7 项，本表可能缺尾项**（疑 Squash Head/EMP），需游戏内下拉复核。

### 1.7 弹药伤害类型 `property_ammo_damage`（partial，人工策展）
武器（`gun_belt_*`/`gun_drum_*`）。候选同弹药簇：`Kinetic / High Explosive / Fragmentation / Armor Piercing / Incendiary`。
⚠ 存档实测取值 {1,3,4,5} 未含 0 与 6，与 ammo_type 表位未必完全一致，需游戏内复核。

## 3. 关键陷阱（解读 XML 前必读）

1. **座圈 ≠ 变速箱**：`gear_ratio`（座圈 6 档 1:1→1:32）与 `gear_ratio_1/2`
   （模块化变速箱 8 档 1:-1→3:1）是不同属性、不同变比集，禁止混用。
2. **`input_velocity` 是浮点标量不是枚举**（实测取值 1 与 5）。
3. `t="N"`（`<c>` 上）语义未定，不是选项代号（见 `数据/xml_id_map.json` `_notes`）。
4. 字符串池**物理顺序 ≠ 枚举顺序**；跨属性共享串（两个变速箱共用 `'1:1'`）——
   顺序只信**代码引用顺序**。
5. 枚举顺序以游戏内 UI 下拉为准；游戏更新后重跑
   `python "<PY>" "<WS>/技能库/sw-property-options/scripts/extract_property_options.py" --selftest`。

## 4. 未解析属性补全途径

`数据/property_options.json` 中 `verified=="todo"` 的枚举键，候选序列在 `candidates` /
`alt_candidates` 字段（来自 exe 字符串池邻域，顺序未定，不可直接采信）。
补全方法：① 游戏内逐个切换下拉→保存载具→比对 XML 值；② 或继续逆向属性描述符表
（`.rdata` 中 slot[0]=面板函数、slot[9]=同部件键清单）。

## 5. 方法论一页版

```

  ├─ .rdata 字符串池 24201 条（部件区：选项串与标签/图标交错共存）

```
