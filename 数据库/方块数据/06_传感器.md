### 多功能物理传感器：17 路复合输出（重点）

> 坐标约定：**红箭头 = X 轴，绿箭头 = Y 轴，蓝箭头 = Z 轴**。

| 通道 | 内容 |
|---|---|
| 数 1–3 | 方块的 **X / Y / Z 位置** |
| 数 4–6 | 方块的**欧拉旋转 X / Y / Z** |
| 数 7–9 | 方块的**线速度 X / Y / Z** |
| 数 10–12 | 方块的**角速度 X / Y / Z** |
| 数 13 | **绝对线速度** |
| 数 14 | **绝对角速度** |
| 数 15 | **局部 Z 倾斜（俯仰 pitch）** |
| 数 16 | **局部 X 倾斜（滚转 roll）** |
| 数 17 | **罗盘航向（-0.5 ~ 0.5）** |

⚠ **注意**：在 XML 里把物理传感器改成不可见，**会同时破坏第 17 路输出**。

### 线性速度传感器的 4 种模式

| 模式 | 含义 |
|---|---|
| Absolute | 不关心方向的速率 |
| Horizontal | 水平速度 |
| Vertical | 垂直速度 |
| Directional | 传感器轴向的速度 —— **唯一需要关心传感器朝向的模式** |

## 6.5 Sonar（声纳）

**机制**（原文）：声纳返回探测范围内物体的信息，输出**相对水下声波的角度**。
可以**被动**探测螺旋桨、引擎等噪声部件，也可以**主动发出一声响亮 ping** 来探测安静的水下物体。
**按住 ping 输入期间，被动信号会被抑制**；激活后**新的 ping 会覆盖旧的**，旧信号不再返回数据。
