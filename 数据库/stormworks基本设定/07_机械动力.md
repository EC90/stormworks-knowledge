# 07 机械动力

> 来源：`Gameplay/Mechanics/Mechanical Power`（修订 4713）
> 原文链接：https://stormworks.fandom.com/wiki/Gameplay/Mechanics/Mechanical_Power

机械动力用来驱动载具移动。

- **产生**：由各类引擎产生，例如预制引擎或模块化引擎。
- **消耗**：由车轮、螺旋桨或旋翼消耗。
- **转换**：也可以被发电机消耗，用来产生 [电力](06_电力.md)。

## 相关链条

```
燃料（柴油 / 航空燃油 / 煤炭） → 引擎 → 机械动力
                                    ├→ 车轮、螺旋桨 / 旋翼（推进）
                                    └→ 发电机 → 电力 → 电池储存
```

对照表把 `mechanical power` 译作「机械动力」
（见 `def_torque_crank_s_desc`：产生机械动力的摇把），本册沿用。
