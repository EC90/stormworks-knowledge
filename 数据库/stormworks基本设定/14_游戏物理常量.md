# 14 游戏物理常量

> 来源：游戏定义文件 `sdk/data/game_constants.xml`（🎮 权威，游戏根目录只读解析）
> 数据权威性：🎮 级真值，**优先级高于 wiki** 中任何同名字段的数值。

本册把 `game_constants.xml` 中全部 **38 个物理常量**按三个域整理成中文表，
供精确计算（弹道、浮力、阻力、升力、阻尼等）时直接查用。

> ⚠️ 常量名是开发者在 XML 里的**原始命名**（蛇形命名），保留原文不意译，便于对照 XML 检索；
> 中文释义写在「含义」列。数值为当前游戏版本默认值，若后续游戏更新改动，以 XML 为准。

## 一、世界（World）

车辆整体的重力、阻尼、摩擦，以及雷达/声纳的测量噪声。

| 常量名 | 默认值 | 含义 |
| --- | --- | --- |
| `gravity` | 10.0 | 世界重力加速度（m/s²，现实约 9.81，游戏取整） |
| `vehicle_linear_damping` | 0.1 | 载具基础线性阻尼（随高度升高趋近于 0） |
| `vehicle_angular_damping` | 0.1 | 载具基础角阻尼 |
| `vehicle_friction` | 0.8 | 载具基础物理表面摩擦系数 |
| `sonar_noise` | 0.001 | 声纳报告位置的微小偏差正负范围 |
| `radar_noise` | 0.001 | 雷达报告位置的微小偏差正负范围 |
| `radar_distance_noise` | 0.01 | 雷达报告距离的最大百分比偏差 |

## 二、空气动力学（Aerodynamics）

飞行体在空气中受到的阻力、升力与高速缩放。

| 常量名 | 默认值 | 含义 |
| --- | --- | --- |
| `air_drag_factor_linear_pressure` | 0.05 | 速度对压力阻力的线性系数 |
| `air_drag_factor_quadratic_pressure` | 0.1 | 速度对压力阻力的二次系数 |
| `air_falloff_power_pressure` | 0.6 | 压力阻力相对运动方向表面的衰减缩放 |
| `air_drag_factor_linear_suction` | 0.025 | 速度对吸力阻力的线性系数 |
| `air_drag_factor_quadratic_suction` | 0.05 | 速度对吸力阻力的二次系数 |
| `air_falloff_power_suction` | 0.4 | 吸力阻力相对运动方向表面的衰减缩放 |
| `air_drag_factor` | 0.2 | 载具车身空气阻力的基础系数 |
| `air_speed_threshold` | 15.0 | 表面开始施加空气动力的速度阈值（m/s） |
| `air_high_speed_threshold` | 50.0 | 表面开始施加高速缩放的空气动力速度阈值（m/s） |
| `air_high_speed_factor_scale` | 8.0 | 高速下对载具施加的叠加缩放（0.1 相当于 1.1 倍） |
| `air_density` | 1.225 | 空气密度（kg/m³） |
| `viscous_air_resistance` | 0.25 | 粘性空气阻力系数 |
| `lift_force` | 0.25 | 施加于表面的升力缩放系数 |

## 三、水动力学（Hydrodynamics）

水体中的阻力、浮力、波浪作用与撞击力。

| 常量名 | 默认值 | 含义 |
| --- | --- | --- |
| `drag_factor_linear_pressure` | 15.0 | 速度对压力阻力的线性系数 |
| `drag_factor_quadratic_pressure` | 17.0 | 速度对压力阻力的二次系数 |
| `falloff_power_pressure` | 2.5 | 压力阻力相对运动方向表面的衰减缩放 |
| `drag_factor_linear_suction` | 12.0 | 速度对吸力阻力的线性系数 |
| `drag_factor_quadratic_suction` | 5.0 | 速度对吸力阻力的二次系数 |
| `falloff_power_suction` | 0.3 | 吸力阻力相对运动方向表面的衰减缩放 |
| `water_drag_factor` | 1.0 | 载具车身水阻力的基础系数 |
| `water_drag_weight_factor_multiplier` | 4.0 | 载具车身附加质量水阻力系数乘数 |
| `water_density` | 1000.0 | 水的密度（kg/m³） |
| `wave_velocity_factor` | 0.5 | 上升波浪对浮体的作用效果 |
| `wave_velocity_factor_reverse` | 0.3 | 下降波浪对浮体的作用效果 |
| `viscous_resistance_factor` | 0.5 | 粘性阻力系数 |
| `slamming_force_multiplier` | 100.0 | 波浪撞击表面的力缩放 |
| `buoyancy_damping` | 0.05 | 基于浸没程度的载具基础角阻尼 |
| `buoyancy_damping_submerged` | 0.92 | 基于浸没程度叠加的角阻尼 |
| `buoyancy_mass_multiplier` | 10.0 | 载具基础质量乘数 |
| `buoyancy_mass_modifier` | 10.0 | 附加质量乘数（由 lower/upper 界定的系数推导） |
| `buoyancy_mass_modifier_lower` | 2000.0 | 质量修正缩放的下界 |
| `buoyancy_mass_modifier_upper` | 23000.0 | 质量修正缩放的上界 |
| `buoyancy_mass_modifier_pow` | 1.0 | 质量系数乘以修正值前所乘的幂 |
