# 11 逻辑与信号

> 来源：`Gameplay/Mechanics/Logic`（修订 4243）
> 原文链接：https://stormworks.fandom.com/wiki/Gameplay/Mechanics/Logic

Stormworks 的逻辑系统建立在**两个逻辑节点之间的连接**之上。
逻辑连接共有 **6 类**：**电力、数据、复合、视频、音频、绳索**。

## 各类节点

| 类型 | 颜色 | 说明 |
| --- | --- | --- |
| **电力** | 标准黄色 | 关闭「无限电力」时，所有部件都必须接上电力，最方便的形式是电池。电力节点的优点是**没有固定的输入/输出之分**，节点之间直接互连即可 |
| **数据（开/关）** | 红色 | 用于开关量连接。开/关节点必须接到另一个开/关节点 |
| **数据（数值）** | 绿色 | 用于数值连接。数值节点必须接到另一个数值节点 |
| **复合** | 紫色 | 复合数据要被使用，必须用**微控制器**把信号转换成其他逻辑节点。很多部件都有复合输出，但这个输出并非一定需要用到 |
| **视频** | 浅蓝色 | 视频可以从摄像头取出送到显示器，也可以用 Lua 向视频信号上绘制内容 |
| **音频** | 黄褐色 | 音频可在麦克风与扬声器之间连接 |
| **绳索** | 黑色 | 绳索的连接方式与电力节点类似。节点之间的绳索只有在**载具生成后**才会显示出来 |

> 顺带一提：红色和绿色正是色盲最难分辨的两种颜色。

## 连接规则

除**电力**和**绳索**外，所有逻辑节点都必须在**输入与输出之间**连接：

- 部件的**逻辑输出节点**是那个**较小的实心圆点**（中间没有孔）；
- 部件的**逻辑输入节点**是那个**较大的圆圈**（中间有孔）；
- 只有在**输出接输入、且颜色相同**时连接才有效
  （例如视频就是：蓝色小实心点 → 蓝色大圆圈）。
