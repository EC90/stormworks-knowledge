### 1. 直升机三轴姿态 PID 自动驾驶仪（含航路点归航与攻击模式）

- 来源：steam id 3242277101 · <https://steamcommunity.com/sharedfiles/filedetails/?id=3242277101> · **载具**（PYOs Tactical data link 3.6）
- 更新时间：**2025-04-11**
- 用到：物理传感器（欧拉角/角速度）、GPS 传感器、陀螺仪、旋翼、属性滑块（PitP/PitI/PitD…）
- 亮点：**把「世界坐标差」直接解成罗盘方位与仰角**（`atan` 两参 + `/2π` 得圈），配合**圈单位最短角差**消除跨 0 跳变；PID 用**表 + id** 实现多实例且带抗积分饱和；`rps` 软启动握手防止落地时积分爆掉。

```lua
-- aliases: 8192-char budget, see 00_cheatsheet 14
GN=input.getNumber GB=input.getBool SN=output.setNumber SB=output.setBool
PN=property.getNumber
M=math Ma=M.atan Mb=M.abs Mc=M.cos Mf=M.floor Ms=M.sin Mr=M.sqrt
pi2=M.pi*2

function Mp(v,a,b) return M.max(M.min(b,v),a) end          -- clamp

-- world delta -> (compass [turns], pitch [turns])
-- SW: math.atan takes (x, y) -- TWO args, x first; divide by 2pi -> turns
function G2CpsPit(g)
  return -Ma(g[1],g[2])/pi2, Ma(g[3],Mr(g[1]^2+g[2]^2))/pi2
end

-- shortest signed difference between two angles in TURNS (no 0/1 jump)
function CD(c,t)
  c,t=c%1,t%1
  if (c-t)>0.5 then t=t+1 elseif (c-t)<-0.5 then t=t-1 end
  return (c-t)
end

-- generic PID, one instance per id; I-term clamped = anti-windup
Is={} Ds={}
function pid(id,v,s,p,i,d,plmt,ilmt,dlmt)
  if not Is[id] then Is[id]=0 Ds[id]=0 end
  Is[id]=Mp(Is[id]+i*(s-v),-ilmt,ilmt)
  local rst=Mp(p*(s-v),-plmt,plmt)+Is[id]+Mp(d*(s-v-Ds[id]),-dlmt,dlmt)
  Ds[id]=s-v
  return rst
end

inatialized=false
function onTick()
  rps=GN(24)
  dalt=(GN(2)-alt)*60                    -- vertical speed, m/s (60 ticks/s)
  alt=GN(2)
  mapx,mapy=GN(1),GN(3)
  p,r,c=GN(15),GN(16),GN(17)             -- pitch / roll / compass, TURNS
  APtgtx,APtgty,APtgtalt=GN(30),GN(31),GN(32)   -- 0 = no waypoint

  if APtgtx~=0 then                      -- mode: fly to waypoint
    APx,APy,APalt=APtgtx,APtgty,APtgtalt
  end

  if APx~=0 then
    aptgtcps,_ = G2CpsPit({APx-mapx,APy-mapy,0})
    aptgtdst   = Mr((APx-mapx)^2+(APy-mapy)^2)     -- m
    if aptgtdst>25 then APdir=aptgtcps end         -- 近处冻结航向，防打转
    dirdlt = CD(c,aptgtcps)                        -- heading error [turns]
    distx  = Ms(dirdlt*pi2)*aptgtdst               -- lateral offset, m
    distz  = Mc(dirdlt*pi2)*aptgtdst               -- along-track offset, m
    -- 远/中/近三段增益叠加，再按距离衰减
    APspdx = Mp(Mp(distx/200,-1,1)*12+Mp(distx/10,-1,1)*1+Mp(distx/50,-1,1)*2,-20,20)
    APspdz = Mp(Mp(distz/300,-1,1)*25+Mp(distz/10,-1,1)*1+Mp(distz/50,-1,1)*4,-30,30)
  end

  if rps>8 then                                    -- soft-start handshake
    if not inatialized then
      APdir=c APx=mapx APy=mapy APalt=alt inatialized=true
    end
    Pit=-pid(1, p, pitT, PN('PitP'),PN('PitI'),PN('PitD'),PN('PitPM'),PN('PitIM'),0.4)
    Rol=-pid(3, r, rolT, PN('RolP'),PN('RolI'),PN('RolD'),PN('RolPM'),PN('RolIM'),0.4)
    Yaw=-pid(2, CD(c,APdir), 0, PN('YawP'),PN('YawI'),PN('YawD'),PN('YawPM'),PN('YawIM'),0.4)
    cO = Mp(APalt-alt,-10,10)                      -- alt error, clamped
    Col=0.2+Mp(pid(4,dalt,cO,PN('ColP'),PN('ColI'),PN('ColD'),PN('ColPM'),PN('ColIM'),0.5),-0.7,0.7)
  else
    Pit,Rol,Yaw,Col=0,0,0,0
  end
  if rps<5 then inatialized=false end              -- 停车即复位，下次重新握手

  krps=Mp((rps-5)/5,0,1)                           -- 0@5rps -> 1@10rps
  SN(1,Pit*krps) SN(2,Rol*krps)
  SN(4,(Col+Yaw)*krps) SN(5,(Col-Yaw)*krps)        -- 差动输出 = 共轴/双旋翼偏航
end
```

**要点（代码外说明）**
- `math.atan(x, y)` 是 SW 的**两参**形式（x 在前），返回**弧度**；除以 `2π` 转成圈，才能和罗盘/俯仰输入量纲一致。
- `CD()` 是圈单位角度差的**标准写法**：先 `%1` 归一，再用 ±0.5 判定绕行方向。缺了它，航向在 0/1 交界处会突然反向。
- PID 的积分项单独 `Mp(...,-ilmt,ilmt)` 限幅即「抗积分饱和」；`Ds[id]=s-v` 存在表里即微分项的历史值。
- `inatialized` + `rps` 阈值是**防地面误动作**的关键：引擎没起来时清零输出并复位状态。
- 攻击/巡航/返航多模式用 `mode` 整数做状态机，切换时 `cntwy=0` 重置等待计时（完整逻辑见暂存文件）。

> ⚠ **该脚本中的 `E2R / tM / Mv / G2L`（欧拉角→旋转矩阵系列）在本文件里定义后并未被调用**，属残留辅助函数；且其 `E2R` 内 `cos/sin` 直接使用 `input.getNumber(4/6/5)`，而物理传感器欧拉角单位是**圈**，直接入三角函数需先 ×2π（见 `17_传感器与雷达.md` §1.3）。
> **要写矩阵变换请用 `02_雷达与传感器数据处理.md` 例 4，或知识册 `17` 的 Z-Y-X 标准写法。**

### 2. 汽车自适应巡航 ACC（多雷达目标选择 + 时距控制 + 走停状态机）

- 来源：steam id 3687286349 · <https://steamcommunity.com/sharedfiles/filedetails/?id=3687286349> · **微控制器**（Elias Adaptive Cruise Control）
- 更新时间：**2026-06-13**（本批采集中最新）
- 用到：7 路雷达（每路 4 通道：距离/方位/仰角/接近速度）、属性滑块（Time Gap / Lane Width / Speed Limiter）
- 亮点：**用车道宽度构造「接受锥」**过滤旁车道目标；目标切换带**滞后 + 锁定计时**防抖动；**时距（time-gap）分段增益**；`ap()` 缓动函数做无过冲逼近。原脚本为 **Minify 压缩态**，本例为反压缩并按语义重命名后的可读版。

```lua
igN=input.getNumber igB=input.getBool osN=output.setNumber osB=output.setBool
pgN=property.getNumber ab=math.abs mx=math.max mn=math.min
ra=0.22 hz=60 tgp=2.0 lw=3.0 buf=1.2            -- ra: EMA alpha; hz: ticks/s
pdistT={0,0,0,0,0,0,0} relT={0,0,0,0,0,0,0}      -- per-channel history
sw=14 swn=10 slt=22 mst=6                        -- switch margins / lock ticks

function cl(x,a,b) return mn(mx(x,a),b) end
-- approach: move c toward f by step g, never overshoot
function ap(c,f,g)
  if c<f then c=c+g if c>f then c=f end
  else       c=c-g if c<f then c=f end end
  return c
end
-- acceptance cone half-angle [turns] from lane width: atan((lw/2)/d)
function gct(d)
  if d<=0 then return 0.01 end
  return cl(math.atan(lw*0.5/d)/(2*math.pi),0.001,0.01)
end
-- radar ch h -> (dist, azimuth, elevation, closing speed); ch8 has no elev/rv
function rt(h)
  b=(h-1)*4+1
  d=igN(b) a=igN(b+1) e=0 rv=0
  if h~=8 then e=igN(b+2) rv=igN(b+3) end
  return d,a,e,rv
end
-- per-channel closing speed from distance history, smoothed by EMA
function gcl(h,d)
  p=pdistT[h] c=0
  if p>0 and d>0 then c=(p-d)*hz end
  r=relT[h]+(c-relT[h])*ra
  relT[h]=r pdistT[h]=d
  return r
end
-- is target in cone AND ahead of us?
function ok(d,a,e,ch,v,cg)
  if d<=0 or d>=800 then return false,false end
  if ab(a)>ch or ab(e)>ch then return false,false end
  if cg<=v+5.0 then return true,false end          -- not overtaking
  q=gct(d)
  if ab(a)<=q and ab(e)<=q then return true,true end
  return false,false
end
```

目标选择核心（滞后 + 锁定）：

```lua
-- bi = best index, bs = best score; lower = more urgent
score = sc(d,a,e,cg)                 -- d + |a|*aW + |e|*eW + |cg|*tW
if t then score = score+200 end      -- oncoming: hard priority
if tlk<=0 or not curOk then
  if curOk then
    if g<bs-sw-swn then bs=g bi=h curOnc=t end     -- need bigger margin to steal the LOCKED one
  else
    if g<bs-sw      then bs=g bi=h curOnc=t end
  end
end
-- 目标稳定 mst tick 后才认定
if ti==tls then tsn=tsn+1 else tsn=0 tls=ti end
tsb = tsn>=mst
```

**要点**
- **接受锥 `gct()`**：`atan(车道半宽 / 距离)`，远目标锥角小、近目标锥角大，天然过滤邻车道与护栏。这是比「固定方位阈值」稳得多的做法。
- **滞后切换**：已锁定目标要被抢走需超出 `sw+swn`，未锁定时只需 `sw`；再加 `tlk` 锁定计时（tick），彻底杜绝两目标来回跳。
- **走停状态机** `sl`：`rd<=ssi` 且目标速度低于 `stm` 进入停车，`rd>=so` 释放；`bm` 缓升控制刹车力度。
- 所有阈值集中在文件顶部常量区 + 属性滑块，便于调参；这也是压缩后仍能维护的关键。
- 该脚本**完整演示了 Minify 后的代码长什么样**：`igN=input.getNumber` 这类别名、`;` 分隔、单字母变量。反压缩与改名流程见 `07_字数压缩与工程手法.md`。

### 3. HSI 水平状态指示器（旋转罗盘玫瑰 + 航路点指针 + 地速矢量）

- 来源：steam id 2836937357 · <https://steamcommunity.com/sharedfiles/filedetails/?id=2836937357> · **载具**（ENDAIR A321-200）
- 更新时间：**2022-07-19**
- 用到：指南针、GPS 传感器、键盘/航路点输入、显示器 1x1
- 亮点：用 **`%1` 把圈归一** 后 ×360 得角度；罗盘玫瑰与航路点指针**共用一套极坐标画法**；量程随距离**自动分档**。

```lua
range = 5
function onTick()
  mx,my = 64,64                                  -- 1x1 monitor: 32x32 scaled x2
  Compass = input.getNumber(10)                  -- compass sensor, TURNS
  HDG  = (((360 + Compass) % 1)*360)             -- turns -> degrees
  HDG2 = (((360 - Compass) % 1)*360)             -- mirrored, for top readout
  gpsx,gpsy = input.getNumber(11),input.getNumber(12)
  navx,navy = input.getNumber(13),input.getNumber(14)
  speedF,speedR = input.getNumber(15),input.getNumber(16)
  speedT = math.sqrt(speedF^2 + speedR^2)
  speedA = ((math.atan(speedF,speedR)*180/math.pi-180)+360)%360

  dX,dY = gpsx-navx, gpsy-navy
  dtt = math.sqrt(dX^2 + dY^2)/1850              -- m -> NM (1852, author uses 1850)
  htt = ((math.atan(dX,dY)*180/math.pi-180)+360)%360
  speedScale = (speedT/100)*45

  navLine = not (navx == 0 or navy == 0)         -- 0,0 = no waypoint set
  if dtt > 9 then range = 1.5
  elseif dtt < 3 then range = 15
  else range = 5 end                             -- auto range switching
  output.setNumber(1,htt) output.setNumber(2,dtt)
end
```

罗盘玫瑰与航路点指针（同一套极坐标）：

```lua
  -- compass rose: N/NE/E/... rotated by HDG; -90 deg offset puts N at top
  screen.drawText((mx/2-2+(39)*math.cos(math.rad(HDG-90))),
                  (my +(39)*math.sin(math.rad(HDG-90))), "N")
  -- ... NE/E/SE/S/SW/W/NW 同法，角度 -90/-45/0/+45/+90/+135/-180/-135
  if navLine then
    -- waypoint bearing: HDG (own heading) + htt (bearing to wp)
    wx = mx/2-2+(dtt*range)*math.cos(math.rad(HDG+htt-90))
    wy = my   +(dtt*range)*math.sin(math.rad(HDG+htt-90))
    screen.drawLine(mx/2,my,wx,wy)
    screen.drawCircle(wx,wy,5)
  end
  -- ground-speed vector
  screen.drawLine(mx/2,my, mx/2-2+speedScale*math.cos(math.rad(speedA)),
                            my   +speedScale*math.sin(math.rad(speedA)))
```

**要点**
- `((360 + Compass) % 1)*360`：加 360（整数）不影响取余结果，等价于 `Compass % 1`，但**对负输入更稳**；`%1` 是把圈归到 0–1 的惯用写法。
- 屏幕坐标 **Y 向下**，`-90°` 偏移让 0°（北）落在正上方；`math.cos/sin` 用**角度**须先 `math.rad()`。
- 量程自动分档（1.5 / 5 / 15）对应刻度标注 10-20-30 / 3-6-9 / 1-2-3 NM，是小型 HSI 的通用做法。
- 注意作者用 `1850` 而非 `1852` 做米→海里换算，量级正确、精度略差。
