### 1. 瞄准门控与开火时序（双轴对准阈值 + 计数确认 + 余弹记账）

- 来源：steam id 3242277101 · <https://steamcommunity.com/sharedfiles/filedetails/?id=3242277101> · **载具**（PYOs Tactical data link 3.6 / 直升机陀螺 AP）
- 更新时间：**2025-04-11**
- 用到：物理传感器、GPS 传感器、陀螺仪、武器挂点、属性滑块（`atk range` / `aim ready threshold` / `aim offset vertical`）、属性开关（`aim pit`）
- 亮点：**「对准」不是瞬时判定而是连续计数确认**（稳住 60 tick 才开火），彻底杜绝抖动误射；瞄准与飞行共用同一套 `G2CpsPit`，攻击时**直接覆盖姿态目标**而非另起一套控制回路。

```lua
ammo=PN('ammo') atk=false cntatk=0

function onTick()
  trigger = GN(25)>0.5                             -- 手动扳机（优先）
  -- 收到攻击指令 + 有目标坐标 + 有余弹 => 进入攻击模式
  if GN(14)>0.5 and atkx~=0 and ammo>0 then atk=true end
  if GN(18)~=0 then atkx,atky,atkz=GN(18),GN(19),GN(20) end   -- 目标世界坐标

  -- 先按航路点/巡航算一遍姿态目标（略，见 01 例 1）
  ...

  SB(1, false or trigger)                          -- 默认：手动扳机直通
  if atk then
    SN(27,atkx) SN(28,atky) SN(29,atkz)            -- 把目标坐标透传给后续方块

    if aptgtdst < PN('atk range')*0.9 then         -- 进入 90% 射程才瞄准
      APdir,pitT = G2CpsPit({atkx-mapx, atky-mapy, atkz-alt})
      if property.getBool('aim pit') then
        pitT = pitT + PN('aim offset vertical')    -- 弹道下坠补偿 / 抬高瞄准点
      else
        pitT = 0
      end
      rolT = 0                                     -- 瞄准时锁平滚转

      -- 对准判定：航向误差 与 俯仰误差 同时小于阈值
      if Mb(CD(c,APdir)) < PN('aim ready threshold')
     and Mb(p-pitT)      < PN('aim ready threshold') then
        cntatk = cntatk + 1
      end
      if cntatk > 60 then                          -- 连续 60 tick（约 1 秒）才算稳
        SB(1,true)
        cntatk = 0
        atk    = false
        ammo   = ammo - 1                          -- 本地记账，不依赖游戏反馈
      end
    end
  end

  if rps < 5 then ammo = PN('ammo') end            -- 引擎停车 => 重新装填计数
end
```

**要点**
- **连续计数确认**（`cntatk > 60`）是火控可靠性的核心：单帧阈值判定会在机体微抖时反复触发/中断。60 tick ≈ 1 秒，是手感与安全的折中。
- `Mb(CD(c,APdir))` 与 `Mb(p-pitT)` **双轴同时判定**：航向对准用圈单位角差 `CD()`（`01 例 1`），俯仰直接比角度。
- 攻击时 `rolT=0` **锁平滚转**——避免机体带坡度射击导致横向偏差。
- `ammo` 在**脚本内记账**并在 `rps<5`（停车）时从属性重载：不依赖游戏的弹药反馈，逻辑自洽且可调。
- `SB(1, false or trigger)` 让**手动扳机始终优先**，自动开火只是叠加一路；这种「手动直通 + 自动并联」的写法值得照抄。
- `PN('atk range')*0.9` 留 10% 射程余量，防止在极限距离反复进出判定。
- **余弹与射程全部走属性**，同一个脚本换载具只需调属性，不改代码。
