## 1. clamp（限幅）

```lua
function cl(x,a,b) return x<a and a or (x>b and b or x) end
-- 或更直白：
function Mp(v,a,b) return math.max(math.min(b,v),a) end
```

> 出现于 `3687286349`、`3242277101`、`2774712393`。**几乎每个工坊脚本都有**。

## 2. 圈单位最短角差（跨 0 不跳变）

```lua
-- c, t 均为「圈」(0..1)，返回带符号最短差，范围 -0.5..0.5
function CD(c,t)
  c,t = c%1, t%1
  if (c-t)> 0.5 then t=t+1
  elseif (c-t)<-0.5 then t=t-1 end
  return (c-t)
end
```

> 来源 `3242277101`（更新 2025-04-11）。航向 / 罗盘 / 雷达方位**必用**。
> 变体（度）：`d = ((a-b+180)%360)-180`。

## 3. 转向 / 限速跟随（无过冲逼近）

```lua
-- 把 c 朝目标 f 移动，步长 g，绝不过冲
function ap(c,f,g)
  if c<f then c=c+g if c>f then c=f end
  else       c=c-g if c<f then c=f end end
  return c
end

-- 限速跟随（用于镜头/缩放平滑）
mz = mz - clamp(mz-z, -0.5, 0.5)      -- 每 tick 最多变 0.5
mx = mx - clamp(mx-mcx, -100, 100)
```

> 来源 `3687286349`（ap）、`2774712393`（限速跟随）。比线性插值更可控，**不会在目标突变时抖**。

## 4. 指数平滑（EMA）与滑动平均

```lua
-- EMA：ra 越小越平滑（0.1 很稳但迟钝，0.5 灵敏但抖）
r = r + (new - r)*ra

-- 滑动平均：保留最近 t 个采样（Av 版会自动建表）
function Av(n,v,t)
  if n==nil then n={0} end
  t = math.max(math.floor(t),1)
  table.insert(n,v)
  local s=0
  if #n>t then for i=1,#n-t do table.remove(n,1) end end
  for i=1,#n do s=s+n[i] end
  return s/#n
end
```

> 来源 `3687286349`（EMA）、`3242277101`（滑动平均 `Av`）。
> ⚠ 滑动平均每 tick 都 `table.remove(t,1)` 是 O(n) 操作，`t` 很大时改环形缓冲。

## 5. 通用 PID（多实例 + 抗积分饱和）

```lua
Is={} Ds={}
function pid(id,v,s,p,i,d,plmt,ilmt,dlmt)
  if not Is[id] then Is[id]=0 Ds[id]=0 end
  Is[id] = Mp(Is[id] + i*(s-v), -ilmt, ilmt)                  -- 积分单独限幅 = 抗饱和
  local rst = Mp(p*(s-v), -plmt, plmt) + Is[id]
            + Mp(d*(s-v-Ds[id]), -dlmt, dlmt)
  Ds[id] = s-v
  return rst
end
```

> 来源 `3242277101`（更新 2025-04-11）。用法：`pid(1, 当前值, 目标值, P, I, D, ...)`，`id` 区分不同回路。
> **积分项必须限幅**，否则长时间偏差会让 I 项爆掉，撤掉偏差后系统持续过冲。

## 6. 两圆 / 三圆求交（三角定位）

```lua
-- 两圆交点（返回两点，需另择一半）
function solve_2_circles(A,B)
  d = math.sqrt((A.x-B.x)^2+(A.y-B.y)^2)
  if d>A.r+B.r or d<math.abs(A.r-B.r) or d==0 then return nil,nil end
  a = (A.r^2-B.r^2+d^2)/(2*d)
  h = math.sqrt(math.max(0, A.r^2-a^2))
  x2,y2 = B.x-A.x, B.y-A.y
  x0,y0 = A.x+a*x2/d, A.y+a*y2/d
  rx,ry = -y2*h/d, x2*h/d
  return {x=x0+rx,y=y0+ry}, {x=x0-rx,y=y0-ry}
end

-- 三圆：用第 3 圆 C 的半径误差消歧，直接给唯一解
function solve_3_circles(A,B,C)
  local p1,p2 = solve_2_circles(A,B)
  if not p1 then return nil end
  local e1 = math.abs(math.sqrt((p1.x-C.x)^2+(p1.y-C.y)^2)-C.r)
  local e2 = math.abs(math.sqrt((p2.x-C.x)^2+(p2.y-C.y)^2)-C.r)
  return (e1<e2) and p1 or p2
end
```

> 来源 `3664940456`（更新 2026-02-13）。详见 `02_雷达与传感器数据处理.md` 例 1。

## 7. hex 字符串 → RGB（属性文本配色的标配）

```lua
function hex2rgb(hex)
  hex = hex:gsub("#","")
  return {r=tonumber("0x"..hex:sub(1,2)),
          g=tonumber("0x"..hex:sub(3,4)),
          b=tonumber("0x"..hex:sub(5,6))}
end
```

> 来源 `1815902922`、`2623064051`。让用户直接在属性里填 `#FF8800`，**不用改代码换配色**。

## 8. 用数字索引动态选择属性文本

```lua
-- 数字属性给出索引 -> 按标签名读取对应的文本属性
local idx = property.getNumber("MapColor1")   -- 例如返回 2
local txt = property.getText(idx)             -- 读取标签为 "2" 的文本属性
```

> 来源 `2774712393`。配合**把多个预设（配色方案、航点表、字模分片）存成 N 个文本属性**，即可用一个数字滑块切换全部预设。
> ⚠ `getText` 的标签参数**区分大小写**，且与微控里属性方块的标签完全一致才读得到。
