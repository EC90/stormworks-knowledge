# Workshop Lua 示例集 · 目录

> **这是什么**：从本机 Steam 创意工坊订阅的载具 / 微控制器中，提取并整理出的**游戏内 Lua（脚本 Lua）范例**。
> 面向「要写 SW 游戏内 Lua 时，先来这里找手法」的场景。
>
> **怎么用**：先按功能在下表找范例 → 打开对应分类文件 → 复制核心片段改造。
> 全部为**脚本 Lua**（`onTick` / `onDraw` + `input` / `output` / `screen` / `property` / `map`），**不涉及附加 Lua**，代码中不应出现 `server.*`。
>
> **阅读约定**
> - 代码块内保持 **ASCII**（游戏内 Lua 源码仅允许英文字符，见 `00_速查 §13`）；中文说明一律放在代码块**外**。
> - 只标注 **Stormworks 独有**的点（双端随机、圈 vs 弧度、Y 垂直轴、`atan` 两参、8192 上限等），通用 Lua 语法不注。
> - 中文专有名词取自 `D:\STORMWORKS\汉化相关\` 术语对照表；表中未收、按同族习惯自译的标 `※`。

- 速查差异：`数据库/Lua/lua总体设定/00_速查_SW_Lua与常规Lua差异.md`
- 传感器坐标与解算：`数据库/方块数据/17_传感器与雷达.md`
- 术语对照：`汉化相关/README_中英对照表.md`

## 四、采信优先级提醒

多个物品实现同一功能时，本集**优先采用更新时间更晚者**（更新时间取自 Steam Web API 的 `time_updated`，见 `_meta/items.json`）。
仅当「旧作有而新作没有的独特手法」时保留旧作，并在示例中标注。
