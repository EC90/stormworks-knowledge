### 1. Lua 键盘协议位解析（单个数字拆出坐标与字符）

- 来源：steam id 2659444728 · <https://steamcommunity.com/sharedfiles/filedetails/?id=2659444728> · **载具**（Lua Keyboard）
- 更新时间：**2022-04-29**
- 用到：键盘（Lua Keyboard 微控）、显示器、复合通道 31/32
- 亮点：**键盘把「点击事件」和「字符」打包进同一个数字**，用位运算解出；作者给出了**完整位布局注释**，是唯一可靠的协议文档级示例。

```lua
-- bit 1      = type (1 = touch/click, 0 = character)
-- bit 2      = keyboard is shown
-- if type == true (click):
--   bits 3-13  = x  (11 bits, 0..2047)
--   bits 14-24 = y  (11 bits, 0..2047)
-- if type == false (character):
--   bits 2-8   = charcode (7 bits ASCII)
function parseKeyboard(numb)
  local fl = math.floor(numb)
  local type          = (numb & 1) == 1           -- SW Lua 5.3: 原生位运算符 & >> <<
  local keyboardShown = (numb & 2) == 2

  local ret = {type=type, keyboardShown=keyboardShown,
               click=false, x=0, y=0, key=0, char=""}
  if type then
    ret.click = true
    ret.x = (fl >> 2)  & 2047                     -- >>2 跳过 type+shown，掩码 11 bit
    ret.y = (fl >> 13) & 2047
  else
    local charc = (fl >> 2) & 127                 -- 7 bit ASCII
    ret.key = charc
    if charc > 31 and charc < 127 then
      ret.char = string.char(ret.key)             -- 可打印字符
    else
      if charc == 4   then ret.CONFIRM = true     -- Ctrl-D / 确认
      elseif charc == 127 then ret.DEL = true end -- 退格
    end
  end
  return ret
end

message = "abcdes"
function onTick()
  keyboard = parseKeyboard(input.getNumber(31))
  output.setBool(31,false) output.setBool(32,false)   -- 默认不请求

  if keyboard.click and not keyboard.keyboardShown then
    if inRect(keyboard, buttonOpen)  then output.setBool(31,true) end  -- 请求打开键盘
    if inRect(keyboard, buttonClose) then output.setBool(32,true) end  -- 请求关闭
  end
  if keyboard.DEL then
    message = string.sub(message, 1, string.len(message)-1)
  elseif keyboard.char then
    message = message .. keyboard.char
  end
end
```

**要点**
- SW 的 Lua 是 **5.3+**，原生支持 `& | ~ << >>`，**不需要 bit32 库**。这是做位打包的前提。
- `math.floor(numb)` 必须先做：`>>` 对浮点数行为不可靠，转成整数再位移。
- 同一通道既传坐标又传字符，靠 **bit 1 区分**——避免多占一路复合通道，这是 SW 里非常珍贵的做法（复合通道数量有限）。
- 「打开/关闭键盘」是**请求式**的：`output.setBool(31,true)` 拉高后由键盘微控响应，脚本每 tick 默认拉低，形成脉冲。
- 该作品自带一个可直接复用的键盘微控，**把 `parseKeyboard` 抄进自己的脚本就能获得全 ASCII 输入**。

- 完整脚本：`AI相关/_提取暂存/2659444728_vehicle_1.lua`
- 关联：`00_速查 §16`（input/output）、`§11`（多返回值括号）

### 2. TCAS 空中防撞（无线电多目标跟踪 + 前向轨迹预测）

- 来源：steam id 2046605849 · <https://steamcommunity.com/sharedfiles/filedetails/?id=2046605849> · **载具**（SR-71 Blackbird）
- 更新时间：**2021-03-12**
- 用到：无线电接收机、GPS 传感器、显示器
- 亮点：**8 张平行表同步维护多机档案**；用 `for i=0,MAXD,RATE` **时间步进预测未来位置**做冲突检测；给出 CLIMB/DESCEND 解脱建议；告警文字**滚动闪烁**。

```lua
RATE=15 MAXD=600 Expiry=1500 SENSE=350 MINALT=300
DC={} DX={} DY={} DA={} DD={} DS={} DV={} DE={}    -- 代号/X/Y/高度/航向/地速/升降率/存活tick

function onTick()
  -- 本机状态：由「回波自身数据」通道周期性刷新
  if input.getNumber(11) > 0 and input.getBool(30) then
    MY_DIR = math.atan(input.getNumber(13)-MY_Y, input.getNumber(12)-MY_X)   -- rad
    MY_GS  = math.sqrt((input.getNumber(13)-MY_Y)^2 + (input.getNumber(12)-MY_X)^2)*60/MY_AGE
    MY_VS  = (input.getNumber(14)-MY_ALT)*60/MY_AGE
    MY_X,MY_Y,MY_ALT = input.getNumber(12),input.getNumber(13),input.getNumber(14)
    MY_AGE = 0
    MY_CODE= input.getNumber(11)
  end
  MY_AGE = MY_AGE + 1

  -- 他机档案：过期剔除 + 命中更新
  isEXIST=false
  for k,v in pairs(DC) do
    DE[k] = DE[k] + 1
    if DE[k] > Expiry then
      -- ⚠ 风险点：见下方「要点」
      table.remove(DC,k) table.remove(DX,k) table.remove(DY,k) table.remove(DA,k)
      table.remove(DD,k) table.remove(DS,k) table.remove(DV,k) table.remove(DE,k)
    end
    if DC[k] == input.getNumber(26) then           -- 同一代号 => 更新
      isEXIST=true
      DD[k] = math.atan(input.getNumber(23)-DY[k], input.getNumber(22)-DX[k])
      DS[k] = math.sqrt((input.getNumber(23)-DY[k])^2+(input.getNumber(22)-DX[k])^2)*60/DE[k]
      DV[k] = (input.getNumber(24)-DA[k])*60/DE[k]
      DX[k],DY[k],DA[k] = input.getNumber(22),input.getNumber(23),input.getNumber(24)
      DE[k] = 0
    end
  end
  if not isEXIST and input.getNumber(26)>0
     and input.getNumber(24) > MINALT
     and input.getNumber(26) ~= MY_CODE then       -- 过滤地面目标与自己
    table.insert(DC, input.getNumber(26))
    table.insert(DX, input.getNumber(22))
    table.insert(DY, input.getNumber(23))
    table.insert(DA, input.getNumber(24))
    table.insert(DD,0) table.insert(DS,0) table.insert(DV,0) table.insert(DE,0)
  end
end
```

前向轨迹预测（冲突检测核心）：

```lua
  NEAREST = SENSE
  for i = 0, MAXD, RATE do                        -- 未来 0..600 秒，步长 15 秒
    X_CHK = MY_X + (MY_GS * i * math.cos(MY_DIR))
    Y_CHK = MY_Y + (MY_GS * i * math.sin(MY_DIR))
    A_CHK = MY_ALT + (MY_VS * i)
    for k,v in pairs(DC) do
      TX = DX[k] + (DS[k]*i*math.cos(DD[k]))
      TY = DY[k] + (DS[k]*i*math.sin(DD[k]))
      TA = DA[k] + (DV[k]*i)
      TEST = math.sqrt((X_CHK-TX)^2 + (Y_CHK-TY)^2 + (A_CHK-TA)^2)
      if TEST < NEAREST then
        NEAREST = TEST ALARM = true
        -- 解脱建议：对方更高就下降，否则爬升
        if MY_ALT >= DA[k] or A_CHK <= MINALT then ADVICE="CLIMB"
        else ADVICE="DESCEND" end
      end
    end
    if ALARM then break end                       -- 首个命中即停，省算力
  end
```

告警显示（滚动 + 方向三角）：

```lua
  elseif ENABLE and ALARM then
    DRAWT = DRAWT + 0.5
    if DRAWT > w/2 then DRAWT = -w/2 end          -- 循环滚动
    screen.setColor(255,0,0,255)
    screen.drawText(-DRAWT, 12, ADVICE)           -- 负 x = 从左侧滚入
    if ADVICE == "CLIMB" then screen.drawTriangleF(2,10, w/2,2, w-2,10)
    else                     screen.drawTriangleF(2,18, w/2,26, w-2,18) end
    screen.drawRectF(0,h-7,w,7)
  end
```

**要点**
- **平行表（parallel arrays）** 是 SW 里存多目标最常见的形态：8 张表下标对齐，插入/删除必须**八表同步**。更稳的写法是**单表存 record**（`{code=,x=,y=,...}`），但平行表在字符数紧张时更省。
- ⚠ **`table.remove` 写在 `pairs` 循环里是风险做法**：删除会使后续 key 前移，导致跳过元素或越界。安全写法是**倒序 `for k=#DC,1,-1 do ... end`**，或先收集待删下标再重建表。
- 冲突检测用**时间步进 + 三维欧氏距离**，是 TCAS 的简化实现；`RATE=15`（秒）是精度与算力的折中——600 秒内 40 步 × 目标数，仍在 tick 预算内。
- `MY_AGE` 记录距上次自身数据刷新经过的 tick，`*60/MY_AGE` 把「这段时间的位移」换算成 m/s（**60 tick = 1 秒**是 SW 的固定逻辑频率）。
- 过滤条件 `input.getNumber(24) > MINALT` 排除地面载具，`~= MY_CODE` 排除自己的回波——**做无线电共享时这两条缺一不可**。
- `screen.drawText(-DRAWT, ...)` 用**负坐标**让文字从屏幕左侧滚入，是零成本的跑马灯。
