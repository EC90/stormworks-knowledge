### 1. 旋翼 RPS 与升降率双柱告警（1×1 显示器）

- 来源：steam id 2213181424 · <https://steamcommunity.com/sharedfiles/filedetails/?id=2213181424> · **载具**（AW101-SW Merlin SICG SAR）
- 更新时间：**2021-12-14**
- 用到：显示器 1x1、速度传感器、高度传感器、属性滑块（各档阈值）
- 亮点：**负高度 `drawRectF` 画双向柱条**（左柱旋翼 RPS，右柱升降率，升降率柱可正可负）；**多阈值顺序覆盖配色**，一行 `if` 一个档位，极省字符。

```lua
function onTick()
  RRPS = input.getNumber(4)                  -- 旋翼 RPS
  SPD  = input.getNumber(6)*1.94384          -- m/s -> kt (x1.94384)
  ALT  = input.getNumber(7)-4                -- 减机体安装高度偏移
  dALT = input.getNumber(8)                  -- 升降率 m/s
  DRPS = property.getNumber("Rotor Danger RPS")
  WRPS = property.getNumber("Rotor Warn RPS")
  MRPS = property.getNumber("Rotor Mean RPS")
  DD   = property.getNumber("Descent Danger")
  DW   = property.getNumber("Descent Warn")
end

function onDraw()
  -- 左侧：旋翼 RPS 柱（0 在 y=24，向上生长，满量程 = 2*MRPS 对应 23px）
  screen.setColor(100,0,0)
  if RRPS > DRPS then screen.setColor(150,112) end                       -- 注意：缺省蓝=0
  if RRPS > WRPS then screen.setColor(25,50,100) end
  if RRPS > ((MRPS*2)-WRPS) then screen.setColor(150,112,0) end          -- 超速警告（对称档）
  if RRPS > ((MRPS*2)-DRPS) then screen.setColor(100,0,0) end            -- 超速危险
  screen.drawRectF(0, 24, 2, -(RRPS/(MRPS*2))*23)                        -- 负高度 => 向上

  -- 右侧：升降率柱（以 y=13 为中点，正=上升向上，负=下降向下）
  screen.setColor(25,50,100)
  if -0.5 < dALT and dALT < 0 and ALT < 25 then screen.setColor(0,50,0) end   -- 低空小下降率 = 安全
  if -DW > dALT then screen.setColor(150,112) end
  if -DD > dALT then screen.setColor(100,0,0) end
  screen.drawRectF(30, 13, 2, -(dALT/10)*11)                             -- 符号决定方向

  -- 数字读出
  screen.setColor(25,50,100)
  screen.drawTextBox(1,23,16,9, string.format("%.0f",SPD), -1, 0)
  if ALT < 0 then
    screen.setColor(100,0,0)
    screen.drawTextBox(16,23,16,9, "SUB", 1, 0)                          -- 水下
  else
    if ALT < 25   then screen.setColor(150,100,0) end
    if ALT < 999  then screen.drawTextBox(16,23,16,9, string.format("%.0f",ALT),       1, 0)
    else               screen.drawTextBox(16,23,16,9, string.format("%.0f",ALT/1000),  1, 0) end
  end
end
```

**要点**
- 🔑 **双向柱条的画法**：`drawRectF(x, 中点y, w, -值*比例)`。值为正 → 负高度 → 向上；值为负 → 正高度 → 向下。**一个表达式同时表达方向与长度**，这是 SW 屏幕（Y 向下）的通用技巧。
- **顺序覆盖配色**：先设最宽松的颜色，再用逐级 `if` 覆盖。省去 `elseif` 链，且档位增删极方便——但**顺序不能反**，必须从严到宽倒着写（这里是从宽到严正着覆盖）。
- `(MRPS*2 - WRPS)` 是**对称超速阈值**：以 2×MRPS 为满量程，超速档与低速档镜像，读数条两端都告警。
- `ALT = input.getNumber(7)-4` 减去**传感器相对机体/水面的安装高度偏移**，这类硬编码偏移在实际载具里很常见，改机体时记得同步。
- `SPD*1.94384` 是 m/s→节（kt）换算；若用 km/h 则是 `*3.6`。
- 1×1 显示器只有 **32×32 像素**，`drawTextBox` 的对齐参数（`-1` 左 / `0` 中 / `1` 右）是唯一可用的排版手段。
