### 1. 应答器三角定位（双圆/三圆交点 + 基线切换 + 离群剔除）

- 来源：steam id 3664940456 · <https://steamcommunity.com/sharedfiles/filedetails/?id=3664940456> · **载具**（PYO's Transponder Locator）
- 更新时间：**2026-02-13**（同功能的 Zizo 版为 2023-11-26，按「同功能取新」以本作为主范例）
- 用到：应急信标接收机、GPS 传感器、显示器
- 亮点：**不靠雷达转台**，仅用「本机动起来 + 多次测距」做三角定位；`solve_3_circles` 直接给唯一解，`solve_2_circles` + 历史均值选半平面；**基线自动切换**与**三级离群剔除**保证收敛。

```lua
M=math abs=M.abs sqrt=M.sqrt atan=M.atan floor=M.floor
BUF_SIZE=20 MIN_DIST=50 MAX_TICKS=900
BASELINE_STORE=0.33 BASELINE_SWITCH=0.50      -- 基线长度的 33% / 50% 阈值
OUTLIER_DIST=350 RES_BUF_MAX=6
buffer={} res_buffer={} base_point=nil candidate_point=nil

function onTick()
  ticks=ticks+1
  mx=input.getNumber(1) my=input.getNumber(3) my_alt=input.getNumber(2)
  sig=input.getBool(1)
  vx=(mx-lx)*60 vy=(my-ly)*60 lx=mx ly=my       -- 60 ticks/s -> m/s

  if sig and not last_sig then                   -- rising edge = one reply pulse
    delta=ticks-last_pulse_tick
    if delta>10 and delta<MAX_TICKS then
      cur_delta=delta
      dist_slant=250+(delta-10)*50               -- 应急信标：脉冲间隔 -> 斜距
      r_horiz = dist_slant>abs(my_alt) and sqrt(dist_slant^2-my_alt^2) or 0
      -- 移动不足 MIN_DIST 的采样点丢弃（基线太短解不出）
      store=true
      if #buffer>0 then
        last=buffer[#buffer]
        if sqrt((mx-last.x)^2+(my-last.y)^2)<MIN_DIST then store=false end
      end
      if store and r_horiz>0 then
        table.insert(buffer,{x=mx,y=my,r=r_horiz})
        if #buffer>BUF_SIZE then table.remove(buffer,1) end
      end
    end
    last_pulse_tick=ticks
  end
  last_sig=sig
end
```

三个圆求交点（唯一解）——**三角定位的数学核心**：

```lua
-- A,B 定基线，用第 3 点 C 消歧；返回交点
function solve_3_circles(A,B,C)
  d=sqrt((A.x-B.x)^2+(A.y-B.y)^2)
  if d>A.r+B.r or d<abs(A.r-B.r) or d==0 then return nil end   -- 无交点/内含
  a=(A.r^2-B.r^2+d^2)/(2*d)
  h=sqrt(M.max(0,A.r^2-a^2))
  x2,y2=B.x-A.x,B.y-A.y
  x0,y0=A.x+a*x2/d, A.y+a*y2/d
  rx,ry=-y2*h/d, x2*h/d
  p1={x=x0+rx,y=y0+ry} p2={x=x0-rx,y=y0-ry}
  -- 用第 3 个圆的半径误差选解
  e1=abs(sqrt((p1.x-C.x)^2+(p1.y-C.y)^2)-C.r)
  e2=abs(sqrt((p2.x-C.x)^2+(p2.y-C.y)^2)-C.r)
  return (e1<e2) and p1 or p2
end
```

基线选择与离群剔除：

```lua
-- 选「离基线最远」的第 3 点，几何精度最高
A,B = buffer[#buffer], buffer[1]
L_A,L_B = B.y-A.y, A.x-B.x
L_C = B.x*A.y - B.y*A.x
L_denom = sqrt(L_A^2+L_B^2)
for b=2,#buffer-1 do
  P=buffer[b]
  d_line=abs(L_A*P.x+L_B*P.y+L_C)/L_denom       -- 点到直线距离
  if d_line>max_dist_line then max_dist_line=d_line idx_c=b end
end

-- 结果离群 3 次 -> 整体复位重来
if #res_buffer>=3 then
  ax,ay = mean(res_buffer)
  if sqrt((result.x-ax)^2+(result.y-ay)^2)>OUTLIER_DIST then is_outlier=true out_cnt=out_cnt+1 end
end
if out_cnt>=3 then res_buffer={} buffer={} base_point=nil out_cnt=0 result=nil end
-- 精度 = 结果集合内的最大散布半径
for b=1,#res_buffer do
  d=sqrt((res_buffer[b].x-target.x)^2+(res_buffer[b].y-target.y)^2)
  if d>max_d then max_d=d end
end
precision=max_d
```

**要点**
- 应急信标只给**距离**不给方位，所以必须**本机移动**积累多个圆；这就是 `MIN_DIST=50` 的意义。
- 两圆交于两点 → 用**第三圆**消歧；只有两个圆时用**历史结果均值**选离均值近的那一半。
- 第 3 点取「**离基线最远**」的采样，交点最不敏感于测距误差（几何精度）。
- **基线切换**：本机动出基线半径 33% 时记录候选点，50% 时正式换基线——避免基线随移动缓慢漂移导致解抖。
- `precision`（结果散布半径）直接当**定位精度**输出到屏幕画圆，是可复用的人机交互设计。

- 关联：`00_速查 §4`、`§16`（map/screen）、`17_传感器与雷达.md`

### 2. 雷达 PPI 扫描显示 + 目标余晖衰减

- 来源：steam id 1899288562 · <https://steamcommunity.com/sharedfiles/filedetails/?id=1899288562> · **载具**（NJ EXAMPLE LUA RADAR）
- 更新时间：**2021-10-13**
- 用到：雷达、显示器、属性滑块（背景/文字/目标 RGB）
- 亮点：**把雷达方位（圈）转成扫描线角度**；用 **`targets[x]=y` 以像素 X 为键**存目标，随时间老化删除，实现**无缓冲的余晖拖尾**；`drawTriangleF` + alpha 做扫描扇形残影。

```lua
targets = {} targetstime = {}                    -- [pixel x] = pixel y / age
pi = math.pi
function onTick()
  w = input.getNumber(2) h = input.getNumber(3)  -- 屏幕尺寸由复合输入给定，非 screen.getWidth
  r = h/2
  t  = input.getBool(11)                          -- 有目标
  d  = input.getNumber(6)                         -- 目标距离 m
  rg = input.getNumber(7)                         -- 期望量程 m
  dad = (d/rg)*r                                  -- 距离 -> 像素半径
  on  = input.getBool(1)
  rdrspd = (100 - input.getNumber(10)) * 6        -- 转速 -> 余晖时长(tick)
  radarrot = input.getNumber(8)                   -- 雷达偏航，TURNS

  if on then
    angrdr = radarrot*6.2832                      -- 圈 -> 弧度
    x1 = w/2 + r   * math.cos(angrdr-1.5708)      -- 扫描线端点(-90deg 使 0 在正上)
    y1 = h/2 + r   * math.sin(angrdr-1.5708)
    x3 = w/2 + dad * math.cos(angrdr-1.5708)      -- 目标点
    y3 = h/2 + dad * math.sin(angrdr-1.5708)
    if t and d <= rg then
      targets[x3] = y3                            -- 以像素 x 为键写入
      targetstime[x3] = 0
    end
    for x3,time in pairs(targetstime) do
      targetstime[x3] = time + 1
      if time >= rdrspd then
        targets[x3] = nil targetstime[x3] = nil   -- 老化消失 = 余晖
      end
    end
  end
end
```

扫描扇形残影（`drawTriangleF` + 第 4 参数 alpha）：

```lua
  screen.setColor(TR,TG,TB,150)
  screen.drawTriangleF(w/2,h/2, x10,y10, x1,y1)   -- 残影 1（滞后 0.1 rad）
  screen.setColor(TR,TG,TB,100)
  screen.drawTriangleF(w/2,h/2, x10,y10, x11,y11) -- 残影 2（滞后 0.25 rad）
  for x4,y4 in pairs(targets) do
    screen.setColor(TGTR,TGTG,TGTB)
    screen.drawCircleF(x4,y4,1)
  end
```

**要点**
- `screen.setColor(r,g,b,a)` 的**第 4 个参数是 alpha**（0–255），这是做残影/半透明的唯一手段。
- 用 **`targets[x]=y`**（以像素 X 为键）能天然去重同列目标，代价是**同一列只保留一个**目标——作者接受了这个取舍，换来了极简的余晖实现。
- 屏幕尺寸走**复合输入**而非 `screen.getWidth()`，因为 onTick 中不可调 screen API（见 `00_速查 §9`）。
- 余晖时长由雷达转速反推 `rdrspd=(100-speed)*6`，转速越快余晖越短，视觉上正好匹配真实雷达。

- 完整脚本：`AI相关/_提取暂存/1899288562_vehicle_0.lua`
- 关联：`00_速查 §9`（onTick/onDraw 分离）、`§16`（screen 绘图 API）

### 3. 3D 激光扫描成像（96×96 距离网格 + 分象限精扫）

- 来源：steam id 3001288106 · <https://steamcommunity.com/sharedfiles/filedetails/?id=3001288106> · **载具**（3D scanner - ocean surface scanner/lidar camera）
- 更新时间：**2023-07-09**
- 用到：激光测距仪（枢轴云台）、显示器、触控屏
- 亮点：**把云台扫过的距离填进 96×96 数组**，归一化后**逐像素 `drawRectF(x,y,1,1)`** 渲染成深度图；支持**低分辨率全扫 + 选中象限高分辨率重扫**；触控按钮用 `lp` 闩锁**消抖**。

```lua
w,h = 96,96
data={}
for i=1,96 do data[i]={} for j=1,96 do data[i][j]=0 end end   -- 固定尺寸数组

function onTick()
  isP = input.getBool(1)                          -- 触控按下
  inX,inY = input.getNumber(3),input.getNumber(4)
  lx,ly = input.getNumber(12),input.getNumber(13) -- 云台当前角度
  dst = input.getNumber(5)                        -- 激光测距 m
  -- 测距仪装在倾斜云台上，需按偏角做余弦修正得到水平距离
  agl = math.atan(math.sqrt(lxo^2+lyo^2),1)       -- atan(x,y) 两参
  dst = dst*math.cos(agl)

  if ti then                                      -- ti = 已稳定，可以采样
    if rng then
      mav = fmax(data) miv = fmin(data)           -- 归一化用极值
      lxo = lxo + xs*1.9*istep                    -- 步进到下一列
      ...
      data[m][n] = dst
      n = n + istep
    end
  else
    s = s+1 if s>=3 then ti=true s=0 end           -- 跳过 3 tick 让云台到位
  end

  -- 触控按钮：isP and not lp => 只在按下瞬间触发一次
  if btp(w*0.9,h*0.2,6,6) and rng==false then xm=xm*0.5 ym=ym*0.5 g=g+1 xr,yr=xr/2,yr/2 end  -- 放大
  if btp(w*0.9,h*0.5,6,6) and rng==false then xm=xm/0.5 ym=ym/0.5 g=g-1 xr,yr=xr*2,yr*2 end  -- 缩小
  -- 3x3 象限选择：命中即设定扫描范围 Xqm/Yqm
  if btp(j,k,w/3,h/3) and rng==false then
    qdr=j m,n=k,j-1 curr_q=q
    lxo,lyo = getq(curr_q) Xqm=j+w/3 Yqm=k+h/3
    xr,yr=w2,h2 rng=true res="L" istep=1
  end
end

function btp(x,y,w,h)                              -- button touched (latched)
  if isP and not lp and inX>=x and inX<=x+w and inY>=y and inY<=y+h then
    lp=true return true
  end
  return false
end
```

渲染（归一化 + 逐像素）：

```lua
function sk(u,v,l) return (u-v)/(l-v) end          -- 归一化到 0..1
function onDraw()
  w,h = screen.getWidth(), screen.getHeight()
  for m,e in ipairs(data) do
    for n,f in ipairs(data[m]) do
      scaled = sk(f,miv,mav)
      screen.setColor(c_s[1]*255*scaled, c_s[2]*255*scaled, c_s[3]*255*scaled)
      screen.drawRectF(n-1,m-1,1,1)                -- 1px 一个采样点
    end
  end
end
```

**要点**
- **⚠ 性能红线**：96×96 = 9216 次 `setColor` + `drawRectF`，是 onDraw 里极其昂贵的操作。小尺寸显示器可接受，**大屏或高刷新场景必须降分辨率**（这正是作者做「低分辨率全扫 + 象限精扫」的原因）。
- 激光测距仪装在枢轴上，返回值是**斜距**，必须按云台偏角做 `cos` 修正才能得到水平距离。
- 触控消抖用 `lp` 闩锁 + `isP and not lp`，配合 `if not isP then lp=false end` 复位——**这是 SW 触控唯一可靠的「按下沿」写法**（`00_速查 §16` 触控约定）。
- 云台移动后要**空转若干 tick 再采样**（`s>=3`），否则读到的是上一个位置的测距值。
- 数组用**固定尺寸预填充**（`for i=1,96 do data[i]={} ...`），避免 `nil` 稀疏表带来的 `#`/`ipairs` 坑（`00_速查 §6`）。

### 4. 由倾斜传感器解出三轴倾角与罗盘（3×3 姿态矩阵，实际调用版）

- 来源：steam id 3119724150 · <https://steamcommunity.com/sharedfiles/filedetails/?id=3119724150> · **载具**（All in one radar）
- 更新时间：**2023-12-27**
- 用到：物理传感器（欧拉角 + 角速度）、显示器
- 亮点：**手工构造 3×3 姿态矩阵**，从中同时解出三轴**倾角**与三轴**罗盘方位**，并用**转置（即逆）矩阵把全局角速度变换到机体系**——一步到位，无需四元数。

```lua
-- This uses the game's basis:
--     vehicle   world   color
-- x   right     east    red
-- y   up        up      green
-- z   forward   north   blue
IN=input.getNumber OB=output.setNumber
M=math Mc=M.cos Ms=M.sin Ma=M.atan MS=M.sqrt
function onTick()
  tau=2*math.pi
  -- ⚠ 物理传感器欧拉角单位是「圈」，直接进 sin/cos 前须先 *tau
  x=IN(4)*tau y=IN(5)*tau z=IN(6)*tau
  cx,sx=Mc(x),Ms(x) cy,sy=Mc(y),Ms(y) cz,sz=Mc(z),Ms(z)

  -- 姿态矩阵（Z-Y-X 欧拉序展开）
  m00=cy*cz            m01=-cx*sz+sx*sy*cz   m02=sx*sz+cx*sy*cz
  m10=cy*sz            m11=cx*cz+sx*sy*sz    m12=-sx*cz+cx*sy*sz
  m20=-sy              m21=sx*cy             m22=cx*cy

  -- 倾角：用 atan(分量, 水平投影) 求，比 asin 稳定（不会在 ±90° 失效）
  tilt_x=Ma(m10,MS(m00*m00+m20*m20))/tau
  tilt_y=Ma(m11,MS(m01*m01+m21*m21))/tau
  tilt_z=Ma(m12,MS(m02*m02+m22*m22))/tau

  -- 罗盘：矩阵列向量的水平方位角；负号 + /tau 归一到圈
  compass_x=Ma(m00,m20)/-tau
  compass_y=Ma(m01,m21)/-tau
  compass_z=Ma(m02,m22)/-tau

  -- 全局角速度 -> 机体系：乘转置矩阵（正交矩阵的转置即逆）
  ax,ay,az=IN(10),IN(11),IN(12)
  angular_x=m00*ax+m10*ay+m20*az
  angular_y=m01*ax+m11*ay+m21*az
  angular_z=m02*ax+m12*ay+m22*az
end
```

**要点**
- 倾角用 `atan(垂直分量, 水平投影长度)` 而非 `asin(垂直分量)`：后者在接近 ±90° 时数值不稳定，前者全程平滑。这是本例最值得抄的一手。
- **全局→机体**用转置矩阵即可（旋转矩阵正交，`Mᵀ = M⁻¹`），省掉一次求逆。
- 三轴罗盘不是「一个航向角」，而是**每条机体轴在水平面投影的方位角**——用于多方向安装的传感器/天线时很有用。

> ⚠ **原脚本的坑（已在本例中修正）**：原文 `cx,sx=Mc(x),Ms(x)` 中的 `x=IN(4)` **没有 ×2π**。物理传感器欧拉角单位是**圈**（见 `17_传感器与雷达.md`），直接入三角函数会得到错误矩阵。
> 若你的上游脚本已把欧拉角转成弧度再传入，则不需要乘；**直连传感器时必须乘**。
