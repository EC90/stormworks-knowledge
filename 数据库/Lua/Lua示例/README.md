# 游戏内 Lua 指导书与例题集

> **AI 阅读规则（先读这段，先于一切）**
> 📌 路径占位符 `<WS>`/`<HOME>`/`<PY>`/`<PYX>`/`<SW_GAME>`/`<SW_WORKSHOP>` 均**因机器而异**，
> 用 `python "<WS>\工作区导航\脚本\sw_paths.py"` 解析，见 `<WS>\工作区导航\07_路径占位符约定.md`。
>
> 本目录是「**辅助用户编写 / 修改 Stormworks 游戏内 Lua（脚本 Lua）**」时的**唯一入口**。
> 使用顺序固定为三步：**`00_AI写作指导.md` → 本文件的索引表 → 对应分类文件**。
>
> **先确认你写的是哪一种 Lua**（写错对象必然返工）：
>
> | | **脚本 Lua**（本目录全部内容） | 附加 Lua（**不在本目录**） |
> | --- | --- | --- |
> | 载体 | 载具/微控里的 **Lua 脚本方块** | 附加（Addon）里的 `script.lua` |
> | 回调 | `onTick` / `onDraw`（+ `httpReply`） | `onCreate` / `onTick` / `onCustomCommand` … |
> | 全局对象 | `input` `output` `screen` `property` `map` `async` | `server.*` |
> | 持久化 | 无（状态走复合信号 / Memory 方块） | `g_savedata` |
> | 查哪本 | **本目录** | `../lua总体设定/01_addon_Lua_API速查.md` |
>
> **三条铁律（违反必出隐蔽 bug，每次动手前默念）**
> ① 源码**仅 ASCII**（中文只能放进 `property.getText`，或走本机后端渲染）；
> ② 单脚本方块**上限 8192 字符**；
> ③ **多人下脚本级变量不同步**，状态记忆必须走复合信号 / Memory 方块。
> 详见 `../lua总体设定/00_速查_SW_Lua与常规Lua差异.md` §13 / §14 / §15。

## 三、按「坑」反查（出错时先查这里）
| 外部给的索引把表取成 nil，画面直接少一块 | 索引型输入没钳位，`st[0][1]` 取到 `nil` 后 `drawTextBox` 静默不画、不报错 | `09` §27 至少 `max(1, …)`，两侧都钳 |
| 改一个属性，好几处尺寸同时跟着变 | 由属性派生的魔数（系数互不相干）散落在顶点计算里 | `05` §53 派生量集中在一小段算完，别和顶点混写 |
| 半透明叠了很多层却一点没变深 | 屏幕每帧清空，alpha 不会跨帧累积 | `05` §53 要余晖须自己维护历史表（见 `03` §22） |
| 倒计时过了 0 之后屏幕全空 | `N = 10 - floor(Ten)` 会变负数，所有 `if N == …` 都不命中 | `05` §51 给 `N` 加下界 `max(0, …)` |
| 数值转布尔偶发判成 false | 写的是 `x == 1`，上游一点噪声（0.98）就失配 | `08` §18 改成 `x > 0.5` |
| 最后几发弹的弹链状态不更新 | 弹鼓见底后计数不再变化，下降沿永远不来 | `08` §18 补一条「击发沿 + 计数为 0」分支 |
| 写了 `clamp(...)` 却完全没生效 | `clamp` 是纯函数，不赋回等于没写 | `09` §27 必须写成 `v = clamp(v, 0, 100)` |

| 删掉清单条目后分页错位 | `table.remove` 后没重算页码上限 | `07` §11 `nra = ceil(#ds/5)` 自动跳到最后一页 |
| 清空固定结构的表之后，改一行却动了所有行 | 同一个 `def` 表被赋给多行，20 行共享同一张表 | `07` §12 逐行 `{...}` 新建，或写个 `clone()` |

| **`sgn(x)` 偶发 nan**|`x/math.abs(x)` 在 `x == 0` 时是 0/0|`03` §27 写成 `x < 0 and -1 or 1` |
| **目标转到身后时准星突然跳到屏幕另一侧**|透视除法在 z 过零时坐标整体翻号|`08` §20 先判 `p_cam.z <= 0` 返回 nil 不画 |
| **宽屏上准星被横向拉伸**|水平 FOV 与垂直 FOV 共用一个焦距|`08` §20 由宽高比反算水平 FOV，f_x / f_y 分开求 |
| **引信在远离目标时也起爆**|剩余 tick 外推没做符号门控，负距离除以负速度反而得正数|`08` §21 加 `Distance * Velocity > 0` 判据 |
| **刚发射就炸**|没有保险延时，且测距缓冲还没填满|`08` §21 `Arm_Delay` tick 计数解锁 + 缓冲未满输出 −1 |
| **改了属性滑块脚本却不跟着变**|属性在脚本顶层读一次就固定了|`08` §21 要运行时生效就把 `property.getNumber` 挪进 `onTick` |
| **姿态回中在大角度时明显偏软**|用三阶泰勒 `u - u^3/6` 近似 `sin`，abs(u) 超过约 0.8 rad 误差剧增|`06` §23 大姿态直接调 `math.sin` |
| **算出来的倾角在俯仰接近 90 度时符号乱跳**|`asin` 值域只有 ±π/2，且常伴随 `cos(pitch)` 趋零被除|`06` §23 用 `atan(分量, sqrt(另两分量平方和))` 替代 |
| **升降通道死活没输出**|通道号变量只声明未赋值，传了 nil 给 `setNumber`|`06` §23 声明 `rch,pch,ych` 时把 `udch` 一起写上 |
| **曲线首帧报错 / 画不出来**|`drawLine` 需要两点，缓冲区只有 1 个样本时取到 nil|`05` §55 `if size < 2 then return end` |
| **读数超出量程后曲线贴顶贴底**|`minVal / maxVal` 硬编码，超范围读数被 clamp 削平|`05` §55 量程变了要同步改这两个常数，或做滑动极值 |
| **等级/难度调高后速度没变**|把等级当成相位偏移写进 `time % 60 - lvl*2`，模数没变|`05` §56 要改模数：`time % max(6, 60 - lvl*4) == 0` |
| **蛇/轨迹长度莫名其妙多一节或少一节**|两张并行表的 insert 与 remove 没成对|`05` §56 变长靠「只头插不尾删」，成对时长度才不变 |
| **四个函数一模一样只差一个角度常数**|作者复制粘贴改常数，没有参数化|`05` §56 把起始角当参数传；`05` §5.7 的 `drawArc` 就是这么做的 |

| 缩放/微调到上下限后档位开始"漂" | 上下限不是步长的整数倍，`v = v + step` 跳出网格后回不去 | `05` §57 端点先 `floor(端点/步长)*步长` 对齐 |
| 分段画出来的圆弧是一圈虚线 | 段数少于弧长的像素数，每段 1 px 之间留缝 | `09` §29 段数取到弧长像素数附近，或每段加宽到 2 px |
| 按住了按钮却只跳一档 | 只判「按下」没做连发计时 | `05` §57 松开或 `T >= 0.15` 才把 `step` 置回 true |
| 绕点盘旋方向反了 / 半径不对 | 航向用 `atan(dx,dy)`（方向向量 `(sin,cos)`）而偏移点用 `(cos,sin)`，两套约定混用 | `06` §24 实机标定方向；改半径优先改距离属性而不是角度 |

| 刻度画了一大堆却只看见几根 | 循环上限写死成常量（100），超出屏高的全画到屏外 | `08` §22 上限按 `h` 现算 |
| `for i=a,b,step` 直接把游戏卡死 | 步长来自外部输入，传了 0 就是死循环（Lua 不报错） | `08` §22 上游钳 `max(1, step)` |
| 分段坐标映射在边界处跳一下 | 相邻两段的端点值没对上 | `04` §15 先验 θ=0 与 θ=π 两端是否与邻段连续 |
| 传过去的"段数"点亮顺序反了 | `2^k-1` 是"最低位为第一段"，下游取位方向相反 | `01` §14 约定方向，或发 `mask ~ (2^N-1)` 取反 |

| 画了 HUD 却被摄像头画面整个盖掉 | `drawCamera` 写在了 `onDraw` 末尾，绘制顺序是后画盖先画 | `05` §58 放在第一行 |
| `string.format` 里写 `%` 就报错 | `%` 是格式符，字面百分号要转义成 `%%` | `05` §58 `string.format("BAT:%d%%", n)` |
| 状态灯换了屏尺寸就全乱 | 每个格子的坐标硬编码，改一处漏一处 | `05` §59 两层 `for` + 一个格距常量 |
| `setColor` 报参数错误 | 上游通道断线，读进来是 `nil` | `05` §59 写 `setColor(255, v or 0, 0)` 兜底 |
| 横滚接近 90 度时俯仰解算突然发散 | 用了 `asin(sin(p)/cos(r))`，`cos(r)` 趋零被除 | `09` §30 标为反面教材；改用 `06` §23 的 `atan(分量, sqrt(另两分量平方和))` |
| 多目标去重那段一改就报 compare nil with number | `and` 的短路顺带挡下了 `i == j` 时的 `nil` 比较，重排条件即崩 | `03` §30 保持 `(cmp[i][j] or 16) < 15` 在前 |
| 变焦 / 缩放后目标框被拉扁 | 横竖用了同一个比例系数，没按屏幕宽高比修正 | `03` §30 `zx` 多一项 `0.15*(w/h-1)`，与 `zy` 分开算 |
| 目标远离后目标框永远停住不动 | EMA 系数没有上限，逼近 1 之后完全冻结 | `03` §30 `math.min(距离/1000, 0.8)` |
| 悬停 / 低速时速度矢量符号飞出屏幕 | 前向速度当分母，趋零时结果爆炸 | `09` §30 低速分支换成实心圆 + 漂移指针 |
| 按了按钮屏幕没反应（或没点却亮） | 按下态高亮矩形与命中区不是同一个矩形，改一处漏一处 | `05` §60 命中区与 `DRF` 坐标同步维护 |
| 目标框 HUD 目标一多就掉帧 | 两两点距去重的 O(N²) 比较写在 `onDraw` 里 | `03` §30 去重移到 `onTick`，`onDraw` 只负责画 |
| 触屏按钮最边上一格点不中 | 命中判定用了严格不等号 `>` / `<` | `06` §25 改闭区间 `>=` / `<=`（1×1 小屏尤其明显） |
| 折线图刻度线数值很难看 | 直接拿 `最大值/分段数` 当步长 | `05` §61 用 1/2/5×10^k 规范化步长 |
| 曲线少画了几段 / 长度忽长忽短 | 用 `#t` 量稀疏表，Lua 对带空洞的表 `#` 是未定义行为 | `05` §61 逐段判空，或自己维护显式计数 |
| 屏幕没接上时 onDraw 报错 | 判空写成 `if not w and w>0`（恒假，且 nil 时 `w>0` 先报错） | `05` §62 改 `if not w or w<=0 then return end` |
| 倒飞时姿态仪天地是反的 | 滚转角直接用，没做倒飞补偿 | `09` §31 用倒飞判据 `inv<0` 时滚转补 180 度 |
| 闪烁占空比不是 50% | 用区间比较 `x>0 and x<40`，把归零帧排除了 | `09` §32 改用取模 `x%40<20` |
| 不增压时喷油量算成 0 或 nan | 压力通道没接，直接当 0 参与运算 | `09` §32 未增压时压力兜底为 1（大气压） |
| A* 在大地图上规划一次卡好几秒 | open 表用数组线性找最小，是 O(n²) | `06` §26 改二叉堆，或按 x 分桶只搜起终点之间的桶 |
| 最短路搜出一条穿墙的直线 | 邻接表只连了「同一条路上的前后节点」，别把全表两两相连 | `06` §26 建图时按 way 顺序取 `h[i-1]` / `h[i+1]` |
| 解出来的坐标全是正的 / 量级离谱 | 紧凑编码里 ZigZag 没还原符号，或漏了差分累加 | `06` §26 `acc%2` 判符号、`nx=nx+dx` 累加 |
