# 游戏内 Lua 指导书与例题集

> **AI 阅读规则（先读这段，先于一切）**
> 📌 路径占位符 `<WS>`/`<HOME>`/`<PY>`/`<PYX>`/`<SW_GAME>`/`<SW_WORKSHOP>` 均**因机器而异**，
> 用 `python "<WS>\工作区导航\脚本\sw_paths.py"` 解析，见 `<WS>\工作区导航\07_路径占位符约定.md`。
>
> 本目录是「**辅助用户编写 / 修改 Stormworks 游戏内 Lua（脚本 Lua）**」时的**唯一入口**。
> 使用顺序固定为三步：**`00_AI写作指导.md` → 本文件的索引表 → 对应分类文件**。
>
> **先确认你写的是哪一种 Lua**（写错对象必然返工）：
>
> | | **脚本 Lua**（本目录全部内容） | 附加 Lua（**不在本目录**） |
> | --- | --- | --- |
> | 载体 | 载具/微控里的 **Lua 脚本方块** | 附加（Addon）里的 `script.lua` |
> | 回调 | `onTick` / `onDraw`（+ `httpReply`） | `onCreate` / `onTick` / `onCustomCommand` … |
> | 全局对象 | `input` `output` `screen` `property` `map` `async` | `server.*` |
> | 持久化 | 无（状态走复合信号 / Memory 方块） | `g_savedata` |
> | 查哪本 | **本目录** | `../lua总体设定/01_addon_Lua_API速查.md` |
>
> **三条铁律（违反必出隐蔽 bug，每次动手前默念）**
> ① 源码**仅 ASCII**（中文只能放进 `property.getText`，或走本机后端渲染）；
> ② 单脚本方块**上限 8192 字符**；
> ③ **多人下脚本级变量不同步**，状态记忆必须走复合信号 / Memory 方块。
> 详见 `../lua总体设定/00_速查_SW_Lua与常规Lua差异.md` §13 / §14 / §15。
