## 0. 通道约定（读/写信号速查）

引擎 Lua 常用 `input.getNumber(n)` / `input.getBool(n)` 通道：

| 方向 | 信号 | 部件→节点 | 单位 | 备注 |
| --- | --- | --- | --- | --- |
| 读 | 曲轴 RPS | 曲轴 → RPS | 转/秒 | 主转速源；单缸有脉动（§4.1） |
| 读 | 飞轮 RPS | 飞轮 → RPS | 转/秒 | 与曲轴**零滑差**，可互备 |
| 读 | 进气压力 | 流体压力传感器 → Pressure | atm | 轻载时与负载无关（§4.3） |
| 读 | 柴油流量 | 液体泄压阀 → Flow Rate | L/s | **前 60 tick 假读数必过滤**（§4.1） |
| 读 | 扭矩 | 扭矩计 → Torque | 游戏单位 | 必须放**引擎侧**（§6）；非 N·m |
| 读 | 网络转速 | 扭矩计 → RPS | 转/秒 | 与曲轴 RPS 差 = 滑差（§6.2） |
| 读/写 | 起动机 | 起动机 → Starter | 0/1 | §1 |
| 写 | 离合器接合压 | 离合器 → Clutch Pressure | 0–1 | **会打滑**（§6.2） |
| 写 | 歧管节气门 | 气体/燃油歧管 → Throttle | 0–1 | 基准 1 / 0.5 |
| 写 | 轮制动 | 轮 → Variable Brake | 0–1 | 可做测功负载 |

## §1 起动机控制（最常用，实测验证）

**起动机只在 <3 RPS 有效**；3 RPS 后引擎自持，继续开着纯属浪费（13 轮对照：常开 86.0 s vs 自动关 85.5 s，差 0.6%）。

```lua
local STARTER_OFF_RPS = 3   -- 实测：单缸引擎 3 RPS 起自持
function onTick()
  local rps = input.getNumber(1)          -- 曲轴 RPS 通道
  local ignition = input.getBool(1)       -- 点火/起动请求
  if not ignition then
    starterOn = false
  elseif rps >= STARTER_OFF_RPS then
    starterOn = false                     -- 到 3 RPS 自动关断
  elseif not started then
    starterOn = true                      -- 熄火中保持开
  end
  output.setBool(1, starterOn)
end
```

**实测建议**：
- 重引擎（3x3 / 5x5，尤其带飞轮）用**双起动机**：5x5 达 3 RPS 从 9.8 s → 3.9 s（2 台）；
- 起动机拖不动的表现：RPS 长时间卡在 <3（起动段），此时**别把"未达 3 RPS"误判为熄火故障**——只是惯量大。
- 熄火后**自动重启**：判出 `rps < 3` 且持续数秒 → 重新给起动机上电。

## §2 引擎恒转速闭环 PID（恒速控制器）

引擎侧负载变化时，用 PID 调节**气体歧管节气门**（或燃油歧管）把转速锁在目标值。

### 2.1 实测动力学（决定增益量级）

| 配置 | 系统快慢 | 实测达稳态 | 调参方向 |
| --- | --- | --- | --- |
| 无飞轮 | 快 | 1.9–4.6 s | 可激进（较大 Kp） |
| + 飞轮（mass 100–300） | **慢** | 8–86 s | **Kp 小、Ki 慢**，时间常数参考达速时间 |

- 引擎**工作区扭矩近乎恒定**（与转速弱相关）→ 近似线性系统，PID 适用；
- **非线性源**要绕开/补偿：离合器打滑（§6.2）、起动机（§1）、单缸冲程振荡（§4.1）。

### 2.2 推荐写法（条件积分 PID，抗 windup，源自 09 §9）

```lua
function pid(p, i, d)
  return {p=p, i=i, d=d, error=0, integral=0,
    run = function(s, sp, pv, min, max, maxI)
      local error = sp - pv
      local diff = error - s.error
      s.error = error
      local out = error*s.p + s.integral + diff*s.d
      if out > min and out < max then              -- 未饱和才累积积分
        s.integral = math.min(math.max(s.integral + error*s.i, min), maxI or max)
      end
      return math.min(math.max(error*s.p + s.integral + diff*s.d, min), max)
    end}
end

-- 🔧 增益起点（按实测动力学给，供初值，车上再微调）
-- 无飞轮快系统：pid(0.1, 0.004, 0)
-- 带飞轮慢系统：pid(0.02, 0.0005, 0)   ← Kp/Ki 明显更小
pidEngine = pid(0.1, 0.004, 0)
function onTick()
  local rps = input.getNumber(1)
  local target = property.getNumber("Target RPS")  -- 见 §3 给目标范围
  local throttle = pidEngine:run(target, rps, 0, 1)
  output.setNumber(1, throttle)                    -- → 气体歧管 Throttle
end
```

**注意事项**：
- 目标转速务必 **< 60 RPS**（§3）；否则会顶到饱和（Kp 再大也到不了），配合条件积分防 windup。
- 若输出给到**离合器**而非节气门，要注意离合器**打滑上限**（§6.2）——PID 拉高接合压到打滑区也传不过去。
- 09 §9 还有**空燃比闭环**（喷油量随进气走，`pid(0.01, 0.002, 0)`），与转速闭环可并存（一个管气一个管油）。

## §3 转速上限与超速保护

**`气1/油0.5` 下任何单缸配置的空载转速上限都在 ~60 RPS**（实测 60.0–61.2，峰值脉动约 62.2）。

- 目标转速建议 **55–60**；**别写 > 62**（到不了，会饱和）。
- 带载会掉转速：1x1 带一个自由轮掉 22%（60.7→47.2），3x3/5x5 几乎不掉——**小排量对负载敏感**，限速点要按"负载工况"留余量。

```lua
local RPS_LIMIT = 58        -- 实测上限 60，留 2 余量
local RPS_RESUME = 50       -- 迟滞恢复点（防在限值附近抖动）
local limited = false
function onTick()
  local rps = input.getNumber(1)
  if rps > RPS_LIMIT then limited = true
  elseif rps < RPS_RESUME then limited = false end
  if limited then throttle = math.min(throttle, 0.3) end   -- 降油门限速
end
```

## §4 信号处理（实测确认的坑）

### 4.1 单缸冲程振荡 → 移动平均

| 排量 | 稳态 RPS 脉动 | 建议平均窗口 |
| --- | --- | --- |
| 1x1 | ±0.1% | 可不用（或 0.5 s） |
| 3x3 | ±2.5% | 0.5–1 s |
| 5x5 | **±8%**（60–70 来回） | **≥1 s（60 tick）** |

```lua
local buf, N = {}, 60            -- 5x5 单缸：60 tick 移动平均
function sma(x)
  buf[#buf+1] = x; if #buf > N then table.remove(buf, 1) end
  local s = 0; for _, v in ipairs(buf) do s = s + v end
  return s / #buf
end
local rpsSmooth = sma(input.getNumber(1))
```

### 4.2 泄压阀流量的启动假读数 → 必过滤

每轮 tick 4 附近都有 **281.9718 L/s** 假读数（18 轮全部复现，一字不差）。

```lua
local t = 0
function onTick()
  t = t + 1
  local flow = input.getNumber(2)
  if t < 60 then flow = 0 end          -- 起动后 1 秒内的流量读数不可信
  -- 或：flow = math.min(flow, 合理上限)  -- 硬上限兜底
end
```

### 4.3 进气压力不能当负载信号

轻载时进气压力与负载基本无关（1x1/3x3 都 ~0.52，5x5 ~0.678）。**别拿它做负载前馈**；重载（掉速明显）时才会升高。

## §5 熄火检测与自动重启

- 判据：**RPS < 3 = 熄火**（起动机开时，低于 3 由起动机维持、不自持）。
- **熄火是"被拖垮"的过程**：满接合后要再拖 2.5–2.9 s 才跌破 3 RPS——**别在瞬时掉转速时误报熄火**，加个持续时间确认。

```lua
local STALL_RPS, STALL_CONFIRM = 3, 120   -- 3 RPS 且持续 2 秒才判熄火
function onTick()
  local rps = input.getNumber(1)
  if rps < STALL_RPS then stallTicks = stallTicks + 1 else stallTicks = 0 end
  local stalled = stallTicks >= STALL_CONFIRM
  if stalled then
    -- 自动重启：先断负载（离合归零），再给起动机上电
    output.setNumber(2, 0)      -- 离合器接合压归零（脱开负载）
    starterOn = true
  end
end
```

## §6 扭矩测量与传动链诊断（进阶）

### 6.1 扭矩计必须放引擎侧

扭矩计测的是**整个所连动力网络的需求之和**（与位置无关，网络不衰减）。
**测"引擎输出扭矩"→ 放曲轴/传动带 ↔ 离合器之间**；放离合器负载侧测到的是负载需求（实测差 17+ 单位）。
单位**别当 N·m**（官方/社区标注"推测为惯性矩、要検証"），只作相对比较。

### 6.2 滑差 = 离合器在打滑（负载瓶颈）

模块化引擎离合器**接合压 1 也会打滑**，滑差随负载增大（轻载 1.4% → 熄火 82%）：

```lua
local slip = (crankRps - meterRps) / math.max(crankRps, 0.001)   -- 传动链滑差
-- slip 大 → 离合器打滑 → 负载瓶颈在离合器，不在引擎
-- 想提高带载能力：换更大/更强离合器（可能比加缸更有效，待验证）
```

对比：**飞轮与转换曲轴是刚性的、零滑差**（RPS 逐点相同）——打滑只发生在离合器。

## §7 油耗与续航估算

### 7.1 空载 / 峰值油耗（`气1/油0.5` 实测）

| 配置 | 空载 L/s | 峰值（加载）L/s |
| --- | --- | --- |
| 1x1 单缸 | 0.023–0.025 | 0.042 |
| 1x1 双缸 | 0.028–0.034 | 0.086 |
| 1x1 四缸 | 0.046–0.056 | 0.157 |
| 3x3 单缸 | 0.23–0.26 | ~1.1 |
| 5x5 单缸 | 0.34–0.48 | ~6.6–7.8 |
| 5x5 双缸 | 0.75 | — |

**油耗峰值出现在"引擎被负载逼到极限的拐点处"**，不是空载；估算续航用"空载油耗 × 平均负载系数"。

### 7.2 每缸每冲程油量（供油特性，跨加载方式复现）

```lua
-- 四冲程每缸每 2 转进气 1 次
local perStrokePerCyl = flow / (rps * CYLINDERS / 2)   -- CYLINDERS = 缸数
-- 实测基准值（L/行程）：1x1 ≈ 0.00144、3x3 ≈ 0.037、5x5 ≈ 0.22
-- 可用作"这台引擎供油是否正常"的自检基准；1x1→3x3 严格按排量缩放
```

## §9 变速箱与传动（09 §3 + 打滑实测补充）

09 §3 的变速箱挡位（多离合器二进制组合）与差速转向模式可直接用。本系列实测补充两点：

1. **离合器打滑是挡比选择的一部分**：大扭矩下离合会滑（§6.2），
   高档低转速时传动比放大引擎扭矩 → 更易打滑——**打滑时降挡比硬顶接合压有效**。
2. **归一化负载**：可变制动是**每个轮子**的输入值，N 轮由同一信号驱动时总制动 ≈ N 倍——
   换挡逻辑若用"制动需求"做参考，要按轮数归一化（`负载 = 制动输入 × 轮数`）。

## §10 引擎参数速查表（`气1/油0.5`，飞轮加速法标定）

| 排量×缸数 | 单缸扭矩(相对) | 空载 RPS | 空载油耗 L/s | 每缸每冲程 | 起动建议 |
| --- | --- | --- | --- | --- | --- |
| 1x1×1 | 1× | 60.7 | 0.024 | 0.00144 | 单起动机 |
| 1x1×2 | ~2× | 60.0 | 0.031 | — | 单起动机 |
| 1x1×4 | ~4× | 60.0 | 0.051 | — | 单起动机 |
| 3x3×1 | ~25× | 60.1 | 0.245 | 0.037 | **双起动机** |
| 5x5×1 | ~108×(上限) | 61.0 | 0.41 | 0.22 | **双起动机** |
| 5x5×2 | ~188×(上限) | 60.9 | 0.75 | — | **双起动机** |

- 排量选型规律：**小排量段（1x1→3x3）扭矩增长慢于排量（×25 < ×27）；大排量段（3x3→5x5）近线性（×4.4 ≈ ×4.63）**。
- **实车选型：要扭矩优先加大单缸排量（1x1→3x3 一口气 ×25）；缸数翻倍只有 ×1.7–2 且油耗翻倍。**
