# 07 · 路径占位符约定

> **本工作区的所有指导文档都用占位符写路径**，因为**用户名**（`EC90` 只是当前机器的值）与
> **Steam 库盘符**（`E:` 只是当前机器的值）在换机器后必然不同。
> 写真路径的文档在别人机器上是错的，写占位符的文档到哪儿都能用。

## 1. 一句话规则

**文档里写 `<占位符>`，运行前用 `sw_paths.py` 换成真实路径；只有「本机实测值」小节允许写真路径。**

## 2. 占位符总表

| 占位符 | 含义 | 是否关键 | 典型值（仅示意，**不是定值**） |
| --- | --- | --- | --- |
| `<WS>` | 工作区根目录（本文件所在目录的上级） | ✅ | `D:\STORMWORKS` |
| `<HOME>` | 用户主目录，**含用户名，因机器而异** | ✅ | `C:\Users\<用户名>` |
| `<STEAM_LIB>` | Steam 库根目录（Stormworks 所在那一个），**盘符不固定** | ✅ | `X:\SteamLibrary` |
| `<SW_GAME>` | 游戏根目录 = `<STEAM_LIB>\steamapps\common\Stormworks` | ✅ | 🚫 只读 |
| `<SW_DEFS>` | 部件定义目录 = `<SW_GAME>\rom\data\definitions`（🎮 权威源） | ✅ | 🚫 只读 |
| `<SW_WORKSHOP>` | 创意工坊订阅目录 = `<STEAM_LIB>\steamapps\workshop\content\573090` | ✅ | 🚫 只读，无订阅时不存在 |
| `<SW_LANG_TSV>` | 简中汉化补丁 = `<SW_WORKSHOP>\<工坊物品ID>\language.tsv` | ⭕ 非关键 | 物品 ID 会变，**按文件名搜** |
| `<SW_SAVE>` | Stormworks 用户数据 = `<HOME>\AppData\Roaming\Stormworks`（Win） | ⭕ 非关键 | ⚠ 改前备份 |
| `<PY>` | Python 基础解释器（纯标准库，默认用它） | ✅ | `<HOME>\.workbuddy\binaries\python\versions\...\python.exe` |
| `<PYX>` | 带 requests/bs4/lxml 的 venv 解释器 | ⭕ 非关键 | `<HOME>\.workbuddy-ai\binaries\python\envs\default\Scripts\python.exe` |

派生关系（改任一项，派生项随之变）：

```
<STEAM_LIB> ─┬─ steamapps\common\Stormworks          → <SW_GAME>
             │                    └─ rom\data\definitions → <SW_DEFS>
             └─ steamapps\workshop\content\573090    → <SW_WORKSHOP>
                                      └─ *\language.tsv  → <SW_LANG_TSV>
<HOME> ─┬─ AppData\Roaming\Stormworks                → <SW_SAVE>（Windows）
        └─ .workbuddy*\binaries\python\…             → <PY> / <PYX>
```

## 3. 解析方式

```bash
# 人类可读：列出所有占位符的当前真实值 + 状态（OK / MISS）
"<PY>" "<WS>\工作区导航\脚本\sw_paths.py"

# 机器可读：AI 直接消费
"<PY>" "<WS>\工作区导航\脚本\sw_paths.py" --json

# 刷新配置文件 <WS>\工作区导航\路径配置.json
"<PY>" "<WS>\工作区导航\脚本\sw_paths.py" --write
```

- **退出码**：`0` = 关键路径全部找到；`1` = 有关键路径缺失（此时会打印排查建议）。
- **零第三方依赖**：只用标准库，任意 Python 3.8+ 都能跑。没装 WorkBuddy 也照样工作。
- 探测顺序：Steam 本体 → Windows 注册表 `HKCU\Software\Valve\Steam`（macOS/Linux 走默认路径与环境变量）
  → `steamapps\libraryfolders.vdf`（自写极简 VDF 解析）→ 在**所有**库里找 `common\Stormworks`
  与 `workshop\content\573090`（取条目最多的那个库）→ 在工坊目录下**按文件名**搜 `language.tsv`（取最大的）。
- **不硬编码工坊物品 ID**：汉化补丁的 ID（`2019972792` 只是当前值）可能随补丁更新变化，所以按文件名找。

### 已接入占位符解析的工具（换机器不用改代码）

| 工具 | 依赖什么 |
| --- | --- |
| `数据库\方块数据\脚本\sw_defs.py` | `<SW_DEFS>`（只读源）、`<PYX>`（`refresh` 用），见上四级解析 |
| `汉化相关\脚本\sw_locate.py`（新增） | `<SW_LANG_TSV>`，被 `sw_state.py` / `build_glossary.py` 调用，`sw_check.py --auto` 全程自动 |
| `技能库\stormworks-fandom-kb\scripts\wiki_query.py` | 知识库目录：环境变量 `SW_KB` → 技能自带 `kb\` → 由脚本位置反推 `<WS>\数据库\stormworks_fandom` |
| `技能库\stormworks-update-check\scripts\sw_update_check.py` | 状态文件用相对路径，无机器相关路径 |

### 手动覆盖（自动探测失败时的兜底）

```bash
# 方式一：环境变量（占位符去掉尖括号）
export SW_GAME="/path/to/steamapps/common/Stormworks"      # Linux/macOS
set SW_GAME=X:\Games\steamapps\common\Stormworks            # Windows cmd

# 方式二：--set，可重复
"<PY>" "<WS>\工作区导航\脚本\sw_paths.py" --set SW_GAME=X:\Games\steamapps\common\Stormworks --write
```

覆盖后**派生项会自动重算**（改 `<SW_GAME>` 会连带更新 `<SW_DEFS>`、`<STEAM_LIB>`、`<SW_WORKSHOP>`、`<SW_LANG_TSV>`）。

## 4. 找不到时，AI 该怎么做（硬性流程）

`sw_paths.py` 报 `MISS` 时，**不要**猜路径、**不要**直接改文档里的占位符，按以下顺序处理：

1. **读排查建议**：脚本 `⚠ 排查建议` 段已按缺失类型给出步骤（Steam 属性 → 本地文件 → 浏览；
   全盘搜 `Stormworks.exe`；`<SW_SAVE>` 需先启动一次游戏等）。
2. **人工定位**：按建议找到真实路径。
3. **回写配置**：`sw_paths.py --set <KEY>=<真实路径> --write`（或设置环境变量后 `--write`），
   刷新 `<WS>\工作区导航\路径配置.json`。
4. **回写文档**：更新 [`04_环境与外部依赖.md`](04_环境与外部依赖.md) 的「本机实测值」小节，
   把这台机器的真实路径记进去，并注明它对应哪个占位符。**只改这一小节，其他小节一律保持占位符。**
5. **补探测逻辑**：如果是现有逻辑覆盖不到的环境形态（Steam 在 macOS/Linux、
   游戏装在非 Steam 库、Flatpak / Proton 等），**改 `sw_paths.py` 的探测链**，而不是只在文档里打补丁。

> 第 3、4 步是硬性要求：只找到不回写，下一个会话/另一台机器还得重找一遍。

### 关键路径缺失时能否继续工作

| 缺失 | 影响 | 退化方案 |
| --- | --- | --- |
| `<SW_LANG_TSV>` | 术语表无法刷新 | 直接读 `汉化相关\常用术语速查.md` 与 `汉化相关\词典\`，**不影响其他工作** |
| `<SW_WORKSHOP>` | 读不到订阅载具 | 只影响载具 XML 解读类任务 |
| `<PYX>` | 网络爬虫类脚本跑不了 | 用 `<PY>` 跑纯标准库脚本；或自建 venv |
| `<SW_GAME>` / `<SW_DEFS>` | 🎮 权威数值查不到 | 只能退回 wiki 与实测，数值可信度下降，**须在结论里标注** |

## 5. 书写规则（写给 AI 与未来的自己）

1. **新增/修改指导文档一律用占位符**，不要写 `C:\Users\EC90\...` 或 `E:\SteamLibrary\...`。
2. 唯一允许写真路径的地方：`04_环境与外部依赖.md` 的「本机实测值」小节，以及
   `工作区导航\路径配置.json`（自动生成，记录了生成时间与平台）。
3. **历史记录只换路径、不改结论**：`数据库\方块数据\原始抓取_游戏定义\模块化引擎实测_*.md`、
   `.workbuddy\memory\*.md`（含归档）等是**当时机器上的实测存档**。
   **路径**已统一换成占位符（路径本来就该跟着环境走），但**实测数值、测试条件、结论一律不动**——
   改了就等于伪造记录。
4. 代码示例里如果必须用真实值，写成 `"<PY>" "<WS>\汉化相关\脚本\sw_check.py" --auto` 这种形式，
   读者自行替换；不要为了「能直接复制」而写死某台机器的路径。
