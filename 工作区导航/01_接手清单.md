> 目标：**不靠任何平台专属能力**也能接手。下面所有操作都是标准命令行 + 标准库 Python。

## 1. 解析路径占位符 + 跑术语表新鲜度检查（毫秒级，每次都跑）

**工作区文档里所有路径都是占位符**（`<WS>` / `<HOME>` / `<PY>` / `<SW_GAME>` …），
用户名与盘符因机器而异。新环境第一步先把它们换成真实值：

```bash
# 用任意能跑的 python（3.8+，纯标准库）
python "<WS>/工作区导航/脚本/sw_paths.py"           # 打印占位符真实值 + OK/MISS 状态
python "<WS>/工作区导航/脚本/sw_paths.py" --write   # 刷新 工作区导航/路径配置.json
```

**有 `MISS` 就先按脚本给出的排查建议找，找到后回写**（`--set KEY=VALUE --write` + 更新
`04_环境与外部依赖.md` 的「本机实测值」），详见 [`07_路径占位符约定.md`](07_路径占位符约定.md)。

然后跑术语表检查：

```bash
PY="<PY>"      # 由 sw_paths.py 给出；没有托管 Python 时用系统 python 也行

"$PY" "<WS>/汉化相关/脚本/sw_check.py" --auto     # 过期自动重建；退出码 0=最新 2=待更新 3=失败
"$PY" "<WS>/汉化相关/脚本/sw_lookup.py" "modular engine cylinder"   # 单条查询
```

Python 路径若不可用：直接读 `汉化相关\常用术语速查.md`（精简版）或 `汉化相关\词典\部件_*.md`。

## 3. 动手前的红线自检

- [ ] 会不会写 `<SW_GAME>`（= `<STEAM_LIB>\steamapps\common\Stormworks`）或 `<SW_WORKSHOP>`
      下任何文件？→ **禁止**，产出只写 `<WS>`（`D:\STORMWORKS`）。
      （本机 `<STEAM_LIB>` 是 `E:\SteamLibrary`，**换机器会变**，见 `路径配置.json`）
- [ ] 改 `<SW_SAVE>\data\vehicles\*.xml` 前是否已备份到 `<WS>\_work\`？
- [ ] 输出的中文术语是否都查过对照表（而非自译）？
- [ ] 微控制器 Lua 里有没有半角 `<` 或双引号？（会直接破坏 XML，必须规避）
- [ ] 用 `async.httpGet` 批量上传数据时，URL 长度是否 < ~4000 字符？（超了游戏崩溃）
