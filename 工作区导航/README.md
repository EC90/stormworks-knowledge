## 三条不可违反的约束

1. **Steam 目录只读** —— `<SW_GAME>`（= `<STEAM_LIB>\steamapps\common\Stormworks\`，游戏根目录）与
   `<SW_WORKSHOP>`（= `<STEAM_LIB>\steamapps\workshop\content\573090\`，创意工坊订阅物）
   严禁写入/修改/删除/移动，也禁止在其下建临时文件。一切产出只写进 `<WS>`（`D:\STORMWORKS`）。
   > 盘符与用户名**因机器而异**，真实值见 `07` 与 `路径配置.json`。
2. **术语必须查表** —— 涉及 Stormworks 游戏内容的中英互译，先查 `汉化相关\` 对照表，禁止凭语感意译。
3. **数据权威性排序** —— 游戏定义文件 🎮 > 游戏内文本 > 日文 wikiwiki.jp > Fandom/社区 wiki ⚠。
   要精确数值先查 `数据库\方块数据\脚本\sw_defs.py`，查不到才考虑实测。
