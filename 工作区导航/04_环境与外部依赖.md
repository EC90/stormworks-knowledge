# 04 · 环境与外部依赖

> 📌 本文（以及工作区所有指导文档）里的 `C:\...`、`E:\...` 一律写成**占位符**。
> 占位符含义、解析方法与「找不到时怎么办」见 [`07_路径占位符约定.md`](07_路径占位符约定.md)。
> 本机真实值只在本文 §7「本机实测值」给出，换机器后**只改那一节**。

## 1. 运行时

| 用途 | 路径（占位符） | 已装第三方包 |
| --- | --- | --- |
| **基础解释器**（默认用它） | `<PY>` = `<HOME>\.workbuddy\binaries\python\versions\<版本>\python.exe` | **无**（纯标准库） |
| 需要 requests / bs4 / lxml / PIL | `<PYX>` = `<HOME>\.workbuddy-ai\binaries\python\envs\default\Scripts\python.exe` | requests ✅ bs4 ✅ lxml ✅ PIL ✅（无 numpy） |
| 需要 numpy / PIL | `<HOME>\.workbuddy\binaries\python\envs\ocr-light\Scripts\python.exe` | PIL ✅ numpy ✅（无 requests/bs4/lxml） |
| Node.js（管理版） | `<HOME>\.workbuddy\binaries\node\versions\<版本>\node.exe` | — |
| Node.js（系统） | `C:\Program Files\nodejs\node.exe`（Windows 默认安装位置，**不固定**） | — |

**要点**

- `.workbuddy\` 与 `.workbuddy-ai\` 两个前缀下的**解释器是同一份二进制**（md5 `e212f6bc096e40a32b3555f6da694e78`），
  只是安装目录有两份副本。历史文档里的 `.workbuddy-ai\binaries\python\...` 仍可用，新文档统一写 `.workbuddy`。
- **基础解释器一个第三方包都没有**。报 `ModuleNotFoundError` 时，先确认该改用哪个 venv，
  而不是去 `pip install` 污染全局。
- 装包纪律：只装进上述 venv（`envs\default` / `envs\ocr-light`），**禁止** `pip install -g` 或全局安装。
- **没有 WorkBuddy 托管 Python 也能工作**：工作区的绝大多数脚本是纯标准库，系统 Python 3.8+ 即可。
  只有网络爬虫类脚本需要 `<PYX>`（requests/bs4/lxml）。

## 2. Steam / 游戏目录 —— 🚫 只读红线

| 路径（占位符） | 内容 | 约束 |
| --- | --- | --- |
| `<SW_GAME>\` = `<STEAM_LIB>\steamapps\common\Stormworks\` | 游戏根目录（`rom\data\definitions\*.xml` 部件定义、`sdk\data\game_constants.xml`、meshes） | **只读** |
| `<SW_WORKSHOP>\` = `<STEAM_LIB>\steamapps\workshop\content\573090\` | 创意工坊订阅物（载具 / 微控 / 汉化补丁） | **只读** |
| `<SW_LANG_TSV>` = `<SW_WORKSHOP>\<工坊物品ID>\language.tsv` | **简中汉化补丁**（术语表主数据源，4 列 TSV：id/description/en/local，UTF-8+CRLF） | 只读，由 Steam 自动同步 |

⚠ **注意**：`<STEAM_LIB>` 的**盘符与目录名都不固定**（`E:\SteamLibrary` 只是本机值，也可能是
`C:\Program Files (x86)\Steam`、`D:\Games\Steam` 等）；`<SW_WORKSHOP>` 下的**工坊物品 ID 也不固定**
（`2019972792` 只是当前汉化补丁的 ID），所以 `sw_paths.py` 是**按文件名 `language.tsv` 搜索**的，不认 ID。

严禁对上述路径写入/修改/删除/移动，也禁止在其下创建临时文件。破坏会导致游戏损坏或订阅丢失且不可恢复。
一切产出只写进 `<WS>`（临时文件也放 `<WS>\_work\` 或系统临时目录）。

## 3. Stormworks 用户数据目录 —— ⚠ 有条件

| 路径（占位符） | 内容 | 约束 |
| --- | --- | --- |
| `<SW_SAVE>\data\vehicles\*.xml` | 载具存档（含 `eng_test.xml` 模块化发动机台架） | 属用户数据，**改前先备份到 `<WS>\_work\`** |
| `<SW_SAVE>\data\microprocessors\*.xml` | 微控制器存档 | 同上 |

`<SW_SAVE>` 的位置随平台变化：Windows `%APPDATA%\Stormworks`；
macOS `~/Library/Application Support/Stormworks`；Linux `~/.steam/steam/steamapps/compatdata/573090/pfx`（Proton）。
**该目录只在游戏至少启动过一次后才生成**。

已知事实：

- `eng_test.xml` 只有一份，换台架会覆盖上一轮，**每轮结束先另存副本**。
- 载具 XML **不是合法 XML**（矩阵属性名以数字开头 `00="1"`），
  禁止直接 `ElementTree` 裸解析，用 `数据库\方块数据\脚本\sw_vehicle.py`（已做预处理）。
- 游戏内修改部件属性并保存后，XML 会被游戏重写——外部编辑后若又在游戏内改过，先确认磁盘文件是最新值。

## 4. 定时任务 —— 脱离任何 AI 平台运行

| 任务名 | `StormworksGlossarySync` |
| --- | --- |
| 状态 | Ready |
| 触发器 | 每天 10:00 |
| 动作 | `powershell.exe … -Command "& '<PY>' '<WS>\汉化相关\脚本\sw_check.py' --auto"` |
| 工作目录 | `<WS>\汉化相关` |

是否重建的判定：`距离 last_update > 7 天` **或** `主数据源 language.tsv 的 SHA-256 变化`。

管理用 PowerShell cmdlet（`schtasks.exe` 被本机安全策略拦截，不要用）：

```powershell
Get-ScheduledTask -TaskName 'StormworksGlossarySync'
Start-ScheduledTask -TaskName 'StormworksGlossarySync'
Disable-ScheduledTask -TaskName 'StormworksGlossarySync'
Unregister-ScheduledTask -TaskName 'StormworksGlossarySync'
```

> ⚠ PowerShell 工具在部分环境不回显 stdout，需要看输出时先 `Set-Content` 写文件再读。
> ⚠ 该任务里写的是**建任务那台机器**的解释器与工作区绝对路径。
> 换机器重建任务时必须用本机 `<PY>` 与 `<WS>` 的真实值，见 §7。

| `<HOME>\.workbuddy\SOUL.md` / `IDENTITY.md` / `USER.md` / `BOOTSTRAP.md` | 助手身份与用户画像文件，属应用层配置，**不纳入**工作区；其中「回复用简体中文」已写入用户级记忆 |

### 关于目录联结（junction）

`<WS>\.workbuddy\skills` 是指向 `<WS>\技能库` 的 NTFS 目录联结，
`<HOME>\.workbuddy\skills\sw-modular-engine-bench` 指向 `<WS>\技能库\sw-modular-engine-bench`。
作用是：WorkBuddy 仍按原路径加载这些技能，而**物理实体只有一份、放在工作区内**，不会产生副本漂移。

- 非 WorkBuddy 平台**完全不需要关心联结**，直接读 `<WS>\技能库\` 即可。
- 若要解除：删除联结目录本身（`rmdir`，**不要** `rm -rf` 递归删，否则会删掉 `技能库\` 里的真身）。

## 6. 网络可达性

- `stormworks.fandom.com` **本机可直连**（curl / requests 均通）。
  但其 `/robots.txt` 对非浏览器 UA 返回 403 —— 爬虫应单次直连 + 失败仅告警继续。
- Steam 新闻页是 JS 动态加载，WebFetch 拿不到正文；改用官方 API：
  `api.steampowered.com/ISteamNews/GetNewsForApp/v2/?appid=573090&count=10&format=json`（免登录）。
- `wikiwiki.jp`（日文）**不是 MediaWiki**，无 `api.php`，Fandom 那套爬虫用不了（`Disallow: /*?` 与 `/*/::*`）。
