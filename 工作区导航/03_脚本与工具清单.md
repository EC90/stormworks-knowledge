# 03 · 脚本与工具清单

## 0. 通用前置

### 0.1 先解析路径占位符（换机器必做第一步）

```bash
"<能跑的 python>" "<WS>/工作区导航/脚本/sw_paths.py"          # 打印所有占位符的真实值
"<能跑的 python>" "<WS>/工作区导航/脚本/sw_paths.py" --json   # 机器可读
"<能跑的 python>" "<WS>/工作区导航/脚本/sw_paths.py" --write  # 写入 路径配置.json
```

| 脚本 | 依赖 | 用途 |
| --- | --- | --- |
| `工作区导航\脚本\sw_paths.py` | **无**（纯标准库，Python 3.8+） | 探测 `<HOME>` / `<STEAM_LIB>` / `<SW_GAME>` / `<SW_WORKSHOP>` / `<SW_LANG_TSV>` / `<SW_SAVE>` / `<PY>` / `<PYX>` 的真实值。支持 `--json`、`--write`、`--set KEY=VALUE`、同名环境变量覆盖。退出码 `0` 全找到 / `1` 有关键项缺失 |

占位符含义与「找不到时怎么办」见 [`07_路径占位符约定.md`](07_路径占位符约定.md)。
**本文及全工作区文档都用占位符写路径**；`<PY>` / `<PYX>` / `<WS>` 等拿到真实值后再代入下面的命令。

### 0.2 解释器

```bash
# 基础解释器（纯标准库，无任何三方包）—— 大多数脚本用它
PY="<PY>"     # <HOME>/.workbuddy/binaries/python/versions/<版本>/python.exe

# 需要 requests/bs4/lxml/PIL 时用这个 venv
PYX="<PYX>"   # <HOME>/.workbuddy-ai/binaries/python/envs/default/Scripts/python.exe

# 需要 numpy/PIL 时用这个 venv
PYN="<HOME>/.workbuddy/binaries/python/envs/ocr-light/Scripts/python.exe"

WS="<WS>"     # 工作区根，如 D:\STORMWORKS（盘符不固定）
```

> 两个 `.workbuddy` 与 `.workbuddy-ai` 前缀的解释器**是同一份二进制**（md5 一致），
> 历史文档里写的 `.workbuddy-ai\binaries\python\...` 仍然可用；新文档统一用 `.workbuddy`。
> 详见 [`04_环境与外部依赖.md`](04_环境与外部依赖.md)。
> **没有托管 Python 也能用系统 Python 3.8+ 跑大多数脚本**（标注「依赖：无」的那些）。

**依赖约定**：本文每个脚本标注 `依赖: 无` 或 `依赖: requests/bs4/lxml` 等。
标注「无」的脚本只用标准库，任何 Python 3.9+ 都能跑，换平台也不会失效。

## 1. 术语对照表（`汉化相关\脚本\`）—— 依赖：无

| 脚本 | 用途 |
| --- | --- |
| `sw_check.py` | **新鲜度检查**。`--auto` 过期自动重建；`--json` 机器可读。退出码 `0` 最新 / `2` 待更新 / `3` 失败 |
| `sw_lookup.py` | 单条查询。`"英文词"` / `--zh 中文` / `--id def_xxx` / `--cat 引擎与动力` / `--exact "…"` / `--json` |
| `sw_batch.py` | 批量查询，输出 `HIT / FUZZY / MISS` 三态。`--terms "A,B,C"` 或传文件；`--no-fuzzy` / `--json` |
| `sw_find.py` | 同义词兜底检索，直接捞 `sw_glossary.jsonl`。`sw_find.py Motor Rocket --parts-only` |
| `build_glossary.py` | 只重建产物（不做增量比对） |
| `update_glossary.py` | 强制完整同步（默认不联网，只用工坊文件） |
| `sw_state.py` | 状态与源文件指纹维护（被 `sw_check.py` 调用，一般不手动跑） |
| `sw_locate.py` | **定位汉化补丁 `language.tsv`**（`<SW_LANG_TSV>`）。工坊物品 ID 与 Steam 盘符都不固定，故按文件名搜索；解析顺序：环境变量 → `路径配置.json` → 旧值 → `sw_paths.py`。单独运行可打印路径 |

```bash
"$PY" "$WS/汉化相关/脚本/sw_check.py" --auto
"$PY" "$WS/汉化相关/脚本/sw_lookup.py" "modular engine cylinder"
"$PY" "$WS/汉化相关/脚本/sw_batch.py" --terms "Motor Small, Wheel 3x3 Suspension"
```

⚠ 命中率低时**多半是 wiki 名 ≠ 游戏内名**（词序相反 / 括号位置不同）。
三级流程：`sw_batch.py` → `sw_find.py` → 仍无对应才标 `※` 自译。命中率 ~50% → 90%+。

```bash
S="$WS/数据库/方块数据/脚本"

"$PY" "$S/sw_defs.py" get "Modular Engine Crankshaft 1x1"   # 权威规格：mass/$/尺寸/逻辑节点/描述
"$PY" "$S/sw_defs.py" cat 7                                 # 按分类列全部（7=传感器）
"$PY" "$S/sw_defs.py" check                                 # 核对册里的部件名是否真实存在

V="<SW_SAVE>/data/vehicles/eng_test.xml"     # <SW_SAVE> 位置随平台变，见 07 号文档
"$PY" "$S/sw_vehicle.py" stats "$V"     # 部件中文统计（末尾附 JSON 摘要）
"$PY" "$S/sw_vehicle.py" list  "$V"     # 逐部件清单
"$PY" "$S/sw_vehicle.py" find  气缸     # 按中/英文关键词反查 d 值
```

> `sw_defs.py` 节点方向的 `mode` 语义：**mode=0 → 输出，mode=1 → 输入**（已用全量定义文件统计校正）。

### 7.1 选题排序器 `ws_rank.py`（2026-09-03 新增，**当前在用**）

批量/自动化时**先跑它**再决定学什么，避免按 `mostrecent` 硬啃到空壳作品。

- 三维度浏览（`trend` / `totaluniquesubscribers` / `lastupdated`）+ Steam Web API 元数据合成加权分；
  默认权重 `trend .28 · 总订阅位次 .24 · lastupdated 位次 .08 · 订阅数 log .15 · 新鲜度(半衰540天) .25`，
  另加成本加成（已订阅 +8 / 已暂存 +5 / 已提取 +3）。
- 常用：`--crawl N`（抓榜）→ `--top K`（取待办 id，已排除已学习）→ 喂 `ws_download.py`；
  `--show N` 看榜、`--refresh` 重算、`--browse mostrecent <游标页> <n>` 供完整性轨推进。
- 榜单 `_meta\ws_ranked.json`（跨轮累积）；进度账本 `_meta\ws_scan_progress.json`（双轨）。
- 403 限流不重试；路径不硬编码（读 `路径配置.json` → `sw_paths.detect()` → 回退常量）。

### 7.2 云端分流同步层（2026-09-03 新增，本机↔资料库）

本机离线时代由 WorkBuddy 云端「云上模式」代跑，产出投递资料库，本机上线后拉取合并。详见规程附录 C。

| 脚本 | 依赖 | 用途 |
| --- | --- | --- |
| `AI相关\_scripts\ws_sync.py` | 无（纯标准库）+ 资料库 Library skill（sandbox 免 token / client 经 `--token-stdin`） | 同步层。**push** 把 `ws_scan_progress.json`/`ws_ranked.json`/`_workshop_learned.json` 打包上传（原地替换）；**pull** 取云端产出包、字段级合并账本 + 复制 Lua 到 `_提取暂存\`；**cloud-pack** 把云端账本快照+提取 Lua 打成 `sw_out_*.zip` 上传队列目录；**cloud-check-heartbeat** 读本机心跳决定云端 SKIP/PROCEED；**init-anchor** 建队列目录；**pack-scripts** 打包脚本自举包供云端下载。离线自测：`--self-test` / `--merge-test` / `--round-trip-test` / `--heartbeat-test` 应全绿 |
| `AI相关\_scripts\cloud_probe.py` | 无（纯标准库） | 云端落地前探针：分测 `api.steampowered` / `steamcommunity_browse` / `steam_cdn` 可达性与耗时，探测 Python 版本/临时目录配额，尝试匿名下载 SteamCMD 与样例物品，并测资料库上传免 token。输出 `cloud_probe.json` 供判断云端能否做到「取材层」 |
