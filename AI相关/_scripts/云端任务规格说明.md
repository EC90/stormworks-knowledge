# 云端代跑任务规格说明（Stormworks 创意工坊 Lua 学习）

> 用途：本机离线时，由 WorkBuddy 云端（小程序「云上模式」）按《Steam 创意工坊 Lua 提取与示例编写规程》
> 代跑一轮，产出投递到资料库，本机上线后自动 `--pull` 合并。
> 本文件给出**本机一次性初始化**步骤 + **可直接粘贴进云上模式定时任务的提示词** + 排障要点。
> 架构、合并规则、红线详见 `AI相关\Steam创意工坊Lua提取与示例编写规程.md` 附录 C。

---

## 0. 架构一句话

- **心跳租约（时间互斥）**：本机每轮写 `last_seen`；云端启动先读它，2.5h 内直接 SKIP。两侧不并行。
- **双写分离**：云端只把「账本快照 + 提取的 Lua」打包推到资料库；**绝不改本地 md**。本机 `pull` 后合并、写例题。
- **幂等合并**：`merge_ledger()` 字段级合并（见附录 C），重复 pull 不重复处理。

## 2. 云端任务（粘贴进「云上模式」定时任务）

- 触发：每 2 小时（与本地同频即可，心跳保证不冲突；也可错峰）。
- 运行环境：WorkBuddy 云端沙箱（内置 Library skill，sandbox 模式**免 token**）。
- 把下面整段提示词作为任务指令粘贴即可。

```text
你是 Stormworks 创意工坊 Lua 学习流水线的「云端代跑」实例。本机离线时由你接手，产出投递到资料库，等本机上线后拉取合并。严格按以下步骤执行（单轮预算 ≤ 50 分钟，超时先落盘再停）。

0. 脚本就位
   - 你运行在 WorkBuddy 云端沙箱，已内置资料库（Library）skill，sandbox 免 token。
   - 脚本来自资料库里的「脚本自举包 sw_scripts_*.bin」（用户已上传；内部 zip 格式）。先把它下载解压到当前工作目录；若资料库不可达则报错退出（这是前提，非 best-effort）。
   - 跑自举包内的 sw_paths.py 拿到 <PY>；云端 <WS> 用当前工作目录。
   - 运行 ws_sync.py --status 确认 skill 字段非空；必要时设置环境变量 CODEBUDDY_SKILL_DIR 指向资料库 skill 目录。

1. 心跳判定（决定是否接手）
   运行：<PY> ws_sync.py --cloud-check-heartbeat
   - 输出 SKIP  → 本机仍在窗口内，本轮直接结束（不下载、不推送）。
   - 输出 PROCEED → 本机超 2.5h 未活动，你接手继续。

2. 准备「已学习」索引（⚠ 严禁 fallback 扫描）
   - 从资料库队列目录下载最新的 sw_pkg_*.bin（本机 push 的元数据包，内部 zip 格式），解包取出 _workshop_learned.json。
   - 后续所有 ws_reference.py 调用都带 --index <该文件> --no-build，绝不省略。

3. 选题（价值优先轨）
   <PY> ws_rank.py --crawl <pages_per_sort>        # pages_per_sort 取包内账本值，默认 4
   <PY> ws_rank.py --top <K> --index <已学习索引>  # K=6~10（云端预算更紧）
   若 --top 为空，转完整性轨：ws_rank.py --browse mostrecent <cursor_page> <n>

4. 下载与提取（SteamCMD 匿名免订阅）
   - 首次需下载并解压 SteamCMD（参考 cloud_probe.py 的 steamcmd 逻辑）；仅下载、不改用户订阅。
   - ws_download.py <ids...> 下载到云端暂存；extract_workshop_lua.py 提取到云端 _提取暂存\。

5. 仅提取，不写例题（双写分离）
   云端只负责 crawl+下载+提取，把产物打包推回；由本机合并后写例题，避免云端改写本地 md 冲突。
   因此：提取完成后直接进第 6 步，不调用 census/dedup/写指导书。

6. 打包并推送产出包
   <PY> ws_sync.py --cloud-pack --cloud-ledger <云端本轮账本json> --extracted <云端_提取暂存>
   （账本 json = 本轮跑完后的 ws_scan_progress.json 快照：含 ids_downloaded/extracted/learned、completeness、value.last_top_ids 等）
   该命令把账本快照 + 提取的 Lua 打成 sw_out_<UTC>.bin（内部 zip）并上传到资料库队列目录。

7. 收尾
   - 不写本机 md、不回写本机账本。
   - 记一笔 last_note：本轮下载/提取了哪些 id、是否遇到 403 限流。
   - 结束。

红线：只读红线（游戏目录与用户订阅只读）；资料库 token 不落地；单包 ≤100 MiB（zip/json 走 drive 原样存，勿传 .md/.csv）。
```

## 4. 已知待「真机验证」项（需真实云沙箱）

以下在桌面端无法验证，需用户在云上模式建好任务后跑一轮确认：

1. **云端外网可达性**：`api.steampowered.com` 与 `steamcommunity.com/browse` 是否分别可达（`steamcommunity` 有 403 限流）。先跑 `cloud_probe.py` 看三处网络结论。
2. **云端 SteamCMD 可用性**：能否匿名下 + 内容分发 CDN 主机可达（api 通 ≠ 能下）。
3. **云端 Python 版本 / 临时目录配额 / 任务时长上限**：用 `--crawl 4 + 下载 N 件 + 提取` 实测耗时对照时长上限。
4. **资料库 sandbox 免 token 上传是否成立**、预签名 URL 有效期（桌面端实测预签名 URL 约 2h有效，云端待复核）。

桌面端已验证（2026-09-03）：
- 离线四项全绿：`--self-test` / `--merge-test` / `--round-trip-test` / `--heartbeat-test`。
- **真实资料库链路全通**：`--init-anchor`（幂等复用）、`--push`（首传+原地替换+父目录自愈）、
  push→预签名下载 sha256 逐字节一致、`--cloud-check-heartbeat` 全链路（列表→下载→解包→读 last_seen）。
- 关键事实：drive 拒收 `.zip` 扩展名，`.bin` 可原样上传；drive 上传参数为 `--parent-id`+`--space-id`；
  `--node-id` 替换不改变父目录；node id 为 ~20 位 base62；drive 上传返回键名是 `node_block_id`。

## 5. 排障

| 现象 | 处理 |
| --- | --- |
| 云端一直 SKIP | 正常：本机在线（last_seen 新鲜）。关机超过 2.5h 才会 PROCEED |
| 云端重下了已学作品 | 检查第 2 步是否漏了 `--index/--no-build`；漏了会在空目录重建空索引 |
| `--cloud-check-heartbeat` 报 PROCEED 但本机其实在线 | 本机从未成功 `--push` 过账本（队列目录无 sw_pkg_*.bin），先按 §1 初始化 |
| push 上传成功但节点落在 space 根目录、不在队列目录 | drive CLI 参数是 `--parent-id`（须同时传 `--space-id`），不是 `--parent-node-id`；`--node-id` 替换不改父目录。ws_sync 已内置 move-node 自愈，老版本手跑 `space_api.py space.workspace.move-node --node-id <pkg> --target-parent-id <队列目录>` |
| drive 上传报「该文件类型不走网盘上传」 | 上传的是 `.zip` 扩展名；一律用 `.bin`（内部 zip，字节原样） |
| push/pull 报找不到 skill | 桌面端确认 Library skill 已安装；云端确认 CODEBUDDY_SKILL_DIR 指向内置路径 |
| 队列目录找不到 | 桌面端 `--init-anchor` 已在资料库建「SW工坊云同步」；云端会自动按名搜索该目录 |
